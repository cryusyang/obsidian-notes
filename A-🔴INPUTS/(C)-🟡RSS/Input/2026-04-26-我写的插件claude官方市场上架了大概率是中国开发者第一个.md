> [!example] AI 摘要
> 作者的两款AI编程插件AutoCode和Imprint通过Anthropic审核，成为Claude Code官方插件市场中首批且目前唯一的中国开发者作品。AutoCode提供47个结构化AI技能，支持零代码从需求到上线；Imprint则通过自然对话生成轻量级“AI行为基因文件”，实现跨模型的记忆与个性化适配。二者技术实现极简（纯Markdown文本），核心价值在于将作者多年工程经验方法论转化为AI可读、可执行的标准化知识。文章指出当前AI插件市场仍处早期，重API封装而轻原创skill，中国开发者在该赛道几近空白，而深度垂直场景的结构化经验正成为生态中最稀缺的资源。

 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   <span style="font-weight: bold;">
    一、这两个插件是什么
   </span>
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   AutoCode：你说想做什么软件，AutoCode帮你上线。47个AI技能，从零到项目上线全程自动。AI做所有技术决策，你只说行或不行。不用会编程，不用懂服务器，做完给你一个任何人都能访问的网址。基于I-Lang v3.0协议。免费开源。里面决策的逻辑是谁的逻辑？我的逻辑，让你一步登天，直接对项目与软件的理解达到跟我一样。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   Imprint：AI行为画像。通过自然对话学习你的工作方式，生成一个不到500 token的基因文件。一个文件替代11个专项技能。换模型不掉记忆，从Claude Code切到Cursor切到Codex，文件带着走。用越久越懂你。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   你可以理解为，如果你是程序员，我让你的AI懂你，同时有记忆，你换任何模型都一样马上继续工作。如果你是纯小白，没关系，我用我的经验跟思路，直接帮你完成所有的开发。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   <span style="font-weight: bold;">
    二、为什么上架Claude生态第一个的中国人是我？
   </span>
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   说实话，这两个产品的技术含量不高。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   没有复杂的后端架构，没有数据库，没有API服务。就是一堆精心设计的文本文件。纯Markdown，零依赖，零可执行代码。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   Anthropic审核的时候专门确认了这一点："No malicious content。"因为确实没有任何代码，只有文字。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   那凭什么能上架？
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   因为这些文字不是随便写的。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   AutoCode的47个技能文件，每一个都是我这些年做项目踩出来的方法论。怎么问问题、怎么做技术选择、怎么部署上线、怎么控制成本、出了bug怎么修。这些东西不需要代码实现，AI读完就会了。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   Imprint的基因文件，是我观察AI跟人协作三年之后提炼出来的行为模型。AI不需要知道你做过什么，它需要知道你怎么做事。这个区别听起来很小，用过的人都说差距巨大。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   技术不值钱。经验值钱。把经验结构化成AI能读懂的格式，这个能力值钱。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   <span style="font-weight: bold;">
    三、这个赛道为什么是空的
   </span>
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   Claude Code的插件市场今年才开放。整个生态还在早期，先进场的人有巨大的先发优势。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   看看现在市场上的插件，大部分是什么？MCP server的包装壳。把一个已有的API接上Claude Code，包一层就上架了。做的人很多，壁垒很低。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   真正做原创skill的人极少。因为skill不是接口封装，是方法论提取。你得先有方法论，才能写成skill。大多数开发者擅长写代码，但不擅长把自己的经验变成结构化的文字。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   中国的AI开发者更少关注这个方向。大家都在追模型、做应用、搞Agent框架。插件市场这种"小东西"看不上。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   但插件市场是离用户最近的地方。用户不会去研究你的Agent框架有多厉害，他会在Claude Code里搜一下有什么插件好用，装一个试试。你的插件装在他的开发环境里，每天跟他一起工作，这个粘性比任何应用都强。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   <span style="font-weight: bold;">
    四、接下来会发生什么
   </span>
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   Anthropic的插件市场会越来越大。OpenAI有GPT Store，Google有Gemini Extensions，Anthropic现在有Plugin Marketplace。每个AI巨头都在建自己的生态。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   生态里最稀缺的不是API封装，是垂直场景的深度skill。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>

  </span>
  <span>

  </span>
  <span>
   <br />
  </span>
  <span>
   独立开发者的从零上线skill，有没有人做？
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   现在没有。但迟早会有。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   问题是你是先占坑的人，还是后面跟的人。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
