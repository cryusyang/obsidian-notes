> [!example] AI 摘要
> 本文介绍了 Obsidian 插件“Reader Highlighter Tags”的功能与设置，该插件支持在阅读模式下对文本进行高亮、添加标签、插入脚注（批注）、复制引文及一键清除高亮，并提供侧边栏高亮导航与导出功能。插件高度可定制，支持悬浮工具栏位置调整、多色高亮、智能标签建议、引文模板、阅读进度追踪等丰富选项。文章还说明了插件作者、版本信息及获取方式，并提示读者点击“阅读原文”查看完整内容。

      设置说明
     </span>

 </section>
 <ul class="list-paddingleft-2" style="padding-left: 20px;">
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     <span>
      Toolbar Position
     </span>
    </span>
    <span>
     ：可选择悬浮工具栏是紧跟文字、位于屏幕上侧、下侧、左侧还是右侧
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     <span>
      Enable Color Highlighting
     </span>
    </span>
    <span>
     ：如启用，则可用 html 标签替代默认的 markdown 高亮语法==
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     <span>
      Highlight color
     </span>
    </span>
    <span>

    </span>
    <span style="color: rgb(40, 102, 186); text-decoration: underline;">
     <span>
      https://www.color-hex.com/
     </span>
    </span>
    <span>
     )
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     <span>
      Enable Color Palette
     </span>
    </span>
    <span>
     ：如启用，则悬浮工具栏会列出五种高亮颜色以供快速选择
    </span>
   </p>

   <p style="margin: 0px; padding: 0px;">
    <span>
     <span>
      Color Palette 1-5
     </span>
    </span>
    <span>
     ：自定义五种高亮颜色的 RGB、HSL 或 HEX 代码，并可为每种颜色设置专门的标签（可选）随高亮一并添加
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     <span>
      Default Tag Prefix
     </span>
    </span>
    <span>
     ：在空白栏中填入的标签将被视为与高亮绑定，在每次添加高亮时一并添加
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     <span>
      Smart Tag Suggestions
     </span>
    </span>
    <span>
     ：如启用，则在添加标签时，插件将根据最近标签、文件夹和笔记属性提供建议
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     <span>
      Quote Format
     </span>
    </span>
    <span>
     ：在空白栏中填入的文本将作为复制为引文时的模板，变量为{{text}}、{{file}}、{{path}}或{{date}}
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     <span>
      Enable Annotations
     </span>
    </span>
    <span>
     ：如启用，则可快捷为选中文本添加批注，实际上是添加为脚注
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     <span>
      Show Annotation Button
     </span>
    </span>
    <span>
     ：如启用，则悬浮工具栏中会显示添加批注按钮
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     <span>
      Track Reading Progress
     </span>
    </span>
    <span>
     ：如启用，则插件将记录阅读进度，在下次打开时自动跳转
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     <span>
      Clear Reading Positions
     </span>
    </span>
    <span>
     ：一键清除所有已储存的阅读进度
    </span>
   </p>

  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     <span>
      Show Tag Button
