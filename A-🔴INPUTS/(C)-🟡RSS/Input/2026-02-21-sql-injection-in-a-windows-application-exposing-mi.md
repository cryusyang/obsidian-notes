<h3>Introduction</h3><p>Hello everyone,</p><p>I’m <strong>Aland Dlshad</strong>, also known as <strong>HexaPHP</strong>. I’m a cybersecurity specialist with a focus on web application penetration testing. My work involves identifying vulnerabilities, improving security, and staying ahead of emerging cyber threats.</p><p>This write-up describes how I discovered a critical SQL injection vulnerability in a Windows desktop application that exposed millions of sensitive records.</p><h3>The Journey Begins</h3><p>During my analysis, I examined the internal structure of the Windows application using dnSpy.</p><p>After loading the executable into dnSpy, I noticed that the code was not obfuscated or encrypted, which allowed me to read and analyze the application logic.</p><p>During this process, I discovered a hardcoded resource link inside the application:</p><pre>https://temp.XXXXXXXXX.com/Editor/ReselerStart_protected.exe</pre><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*TDYs570XEgIm2tjiysJwUw.jpeg" /></figure><p>This discovery helped me understand how the application interacts with external components.</p><h3>Analyzing the Activation Process</h3><p>I downloaded the file ReselerStart_protected.exe and executed it. When opened, the application required an activation code to continue.</p><p>This indicated that the application communicates with a remote server for activation verification.</p><p>To analyze the activation process, I used HTTP Debugger to monitor network traffic.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*mUypHGgrLGCnmE2xcgIKag.jpeg" /></figure><p>By intercepting the traffic, I identified the following HTTP request:</p><pre>POST /insta.php HTTP/1.1<br />Content-Type: application/x-www-form-urlencoded<br />Host: XXXXXXXXXX.com<br />Connection: Keep-Alive<br />Content-Length: 56<br /><br />getaviable=89EC3D510A18A476AC58413582177304&amp;Code=hexaphp</pre><p>This request showed that the application sends user-controlled input to the backend server. The two parameters were:</p><ul><li>getaviable – likely a device identifier</li><li>Code – the activation code entered by the user</li></ul><p>Since these parameters contained user-controlled input, they became targets for further testing.</p><h3>Testing Using Burp Suite</h3><p>To further analyze the request, I transferred it to Burp Suite.</p><p>Using Burp Suite Repeater, I successfully resent the request and confirmed that I could modify and control the parameters.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*45My55yVZbw1XbLw4vTfDw.jpeg" /></figure><p>This allowed me to begin testing for SQL injection vulnerabilities.</p><h3>Confirming SQL Injection Vulnerability</h3><p>I tested the getaviable parameter using the following payload:</p><pre>' order by 111-- -</pre><p>The server responded with the following error:</p><pre>Unknown column '111'</pre><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*cSboFbw8QAA7ZMQCRhnBrQ.jpeg" /></figure><p>This error confirmed that the input was being processed directly in a SQL query without proper sanitization, indicating a SQL injection vulnerability.</p><h3>Extracting Sensitive Data</h3><p>To confirm exploitation, I used the following payload:</p><pre>' OR 1=1-- -</pre><p>The server responded with sensitive data from the database, including:</p><ul><li>WhatsApp numbers</li><li>Viber numbers</li><li>Device information</li><li>User records</li></ul><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*zKCK19-fhw2_DhMuPScakA.jpeg" /></figure><p>This confirmed that the SQL injection vulnerability allowed unauthorized access to sensitive information. The injected condition forced the database to return all available records.</p><h3>Conclusion</h3><p>This write-up demonstrated how reverse engineering, traffic analysis, and manual testing led to the discovery of a critical SQL injection vulnerability in a Windows application.</p><p>The vulnerability exposed millions of sensitive records and highlighted the importance of secure coding practices and proper input validation in application development.</p><h3>Contact</h3><p>If you’d like to connect or learn more about my work:<br /><a href="https://hexaphp.com/"><strong>https://hexaphp.com</strong></a></p><img alt="" height="1" src="https://medium.com/_/stat?event=post.clientViewed&amp;referrerSource=full_rss&amp;postId=f657a6de46ac" width="1" />
