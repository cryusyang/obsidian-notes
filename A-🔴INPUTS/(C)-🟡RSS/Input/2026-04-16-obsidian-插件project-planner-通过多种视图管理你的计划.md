> [!example] AI 摘要
> 本文介绍了 Obsidian 插件 **Project Planner** 的功能与使用方法：该插件以笔记文件为基础实现任务与计划管理，支持多视图展示、实时双向同步（启用 Markdown Sync 后）、任务属性标准化（如 id、title、status 等），并提供便捷的任务创建、日记快捷添加、信息面板编辑等功能。插件由 James Hawkins 开发，当前版本为 0.8.1，用户可通过官方或国内渠道下载安装。

 <p style="white-space: normal; margin: 0px; padding: 0px;">
  <span>
   <span>
    Project Planner
   </span>
  </span>
  <span>
   插件将
  </span>
  <span>
   <span>
    任务（Task）
   </span>
  </span>
  <span>
   视为一个基本单元，
  </span>
  <span>
   <span>
    任务
   </span>
  </span>
  <span>
   从属于
  </span>
  <span>
   <span>
    计划（Project）
   </span>
  </span>
  <span>
   ，它们本质上都是 Obsidian 库内的笔记文件和文件夹，插件只是通过它们的笔记属性将其可视化展现出来而已
  </span>
 </p>
 <p style="white-space: normal; margin: 0px; padding: 0px;">
  <span>
   <br />
  </span>
 </p>
 <p style="white-space: normal; margin: 0px; padding: 0px;">
  <strong>
   <span>
    一个任务笔记必须具有以下笔记属性：
   </span>
  </strong>
 </p>
 <ul class="list-paddingleft-2" style="padding-left: 20px;">
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     id：UUID v4
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     title：任务的展示名
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     status：进展情况
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     completed：属性值要填布尔值
    </span>
   </p>
  </li>
 </ul>
 <p style="white-space: normal; margin: 0px; padding: 0px;">
  <span>
   <br />
  </span>
 </p>
 <p style="white-space: normal; margin: 0px; padding: 0px;">
  <strong>
   <span>
    一个任务笔记可以具有以下笔记属性（非必须）：
   </span>
  </strong>
 </p>
 <ul class="list-paddingleft-2" style="padding-left: 20px;">
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     parentid：亲任务的 UUID
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     priority：任务的优先级
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     startDate：YYYY-MM-DD格式
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     createdDate：YYYY-MM-DD格式
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     lastModifiedDate：YYYY-MM-DD格式
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <span>
     collapsed：该任务的子任务在表格视图是否折叠
    </span>
   </p>
  </li>
 </ul>
 <p style="white-space: normal; margin: 0px; padding: 0px;">

  </span>

 </section>
 <section>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <strong>
    <span>
     如何打开Project Planner的插件界面？
    </span>
   </strong>
  </p>
  <ul class="list-paddingleft-2" style="padding-left: 20px;">
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      左侧功能区按钮：可右键点击以隐藏，也可长按拖拽调整视图按钮的顺序
     </span>
    </p>
   </li>
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      命令面板执行
     </span>
     <span>
      <span>
       Project Planner: Open Project Planner命令
      </span>
     </span>
     <span>
      ，或直接选择想要打开的视图
     </span>
    </p>
   </li>
  </ul>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <span>
    <br />
   </span>
  </p>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <strong>
    <span>
     如何创建计划？
    </span>
   </strong>
  </p>
  <ul class="list-paddingleft-2" style="padding-left: 20px;">
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      打开插件设置，点击第一个选项后的
     </span>
     <span>
      <span>
       Add Project
      </span>
     </span>
     <span>
      按钮，点击它即可创建
     </span>
     <span>
      <span>
       计划
      </span>
     </span>
    </p>
   </li>
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      在库内也会同步生成一个名为
     </span>
     <span>
      <span>
       Project Planner
      </span>
     </span>
     <span>
      的文件夹，并在其下生成与该计划同名的子文件夹
     </span>
    </p>
   </li>
  </ul>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <span>
    <br />
   </span>
  </p>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <strong>
    <span>
     如何创建任务？
    </span>
   </strong>
  </p>
  <ul class="list-paddingleft-2" style="padding-left: 20px;">
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      在每个视图的右上角，都会有一个
     </span>
     <span>
      <span>
       Add Task
      </span>
     </span>
     <span>
      按钮，点击它即可创建
     </span>
     <span>
      <span>
       任务
      </span>
     </span>
    </p>
   </li>
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      在
     </span>
     <span>
      <span>
       计划
      </span>
     </span>
     <span>
      文件夹里新建一个笔记文件，为其添加必须具有的笔记属性，
     </span>
     <span>
      <span>
       UUID
      </span>
     </span>
     <span>
      可通过在开发者模式（
     </span>
     <span>
      <span>
       ctrl+shift+i
      </span>
     </span>
     <span>
      调出）中运行
     </span>
     <span>
      <span>
       crypto.randomUUID()
      </span>
     </span>
     <span>
      命令或是于在线
     </span>
     <span>
      <span>
       UUID
      </span>
     </span>
     <span>
      创建器中快速创建
     </span>
    </p>
   </li>
  </ul>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <span>
    <br />
   </span>
  </p>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <strong>
    <span>
     什么是实时更新？
    </span>
   </strong>
  </p>
  <ul class="list-paddingleft-2" style="padding-left: 20px;">
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      由于
     </span>
     <span>
      <span>
       计划
      </span>
     </span>
     <span>
      和
     </span>
     <span>
      <span>
       任务
      </span>
     </span>
     <span>
      本质上是 Obsidian 库内的特定笔记文件夹和文件，所以只要在插件设置中启用了
     </span>
     <span>
      <span>
       Enable markdown sync
      </span>
     </span>
     <span>
      选项，无论是在插件界面还是在笔记文件中的修改，都会实时同步到另一处，建议每次只打开一处进行编辑，以免发生冲突
     </span>
    </p>
   </li>
  </ul>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <span>
    <br />
   </span>
  </p>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <strong>
    <span>
     如何在日记中快捷添加任务？
    </span>
   </strong>
  </p>
  <ul class="list-paddingleft-2" style="padding-left: 20px;">
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      在插件设置中启用
     </span>
     <span>
      <span>
       Enable daily note sync
      </span>
     </span>
     <span>
      ，在下面的
     </span>
     <span>
      <span>
       Tag pattern
      </span>
     </span>
     <span>
      中设置标签，并在
     </span>
     <span>
      <span>
       Default project
      </span>
     </span>
     <span>
      中选择一个
     </span>
     <span>
      <span>
       计划
      </span>
     </span>
    </p>
   </li>
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      在任何一篇日记中添加一个任务列表项并跟上设置好的标签，例：
     </span>
     <span>
      <span>
       - [ ] Finish quarterly report #planner
      </span>
     </span>
    </p>
   </li>
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      <span>
       Project Planner
      </span>
     </span>
     <span>
      插件会自动侦测并将该
     </span>
     <span>
      <span>
       任务
      </span>
     </span>
     <span>
      添加到选择好的
     </span>
     <span>
      <span>
       计划
      </span>
     </span>
     <span>
      中
     </span>
    </p>
   </li>
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      如果有想添加到其它
     </span>
     <span>
      <span>
       计划
      </span>
     </span>
     <span>
      中的
     </span>
     <span>
      <span>
       任务
      </span>
     </span>
     <span>
      ，可以在标签后用/添加该计划名，例：
     </span>
     <span>
      <span>
       - [ ] Book dentist appointment #planner/Personal
      </span>
     </span>
    </p>
   </li>
  </ul>

 <section style="font-size: 15px; color: rgb(47, 200, 255);">
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <strong>
    <span>
     仪表盘（Dashboard）
    </span>
   </strong>
  </p>
 </section>
 <p style="white-space: normal; margin: 0px; padding: 0px;">
  <span>
   仪表盘视图展示了
  </span>
  <span>
   <span>
    计划
   </span>
  </span>
  <span>
   和
  </span>
  <span>
   <span>
    任务
   </span>
  </span>
  <span>
   的完成情况，用户可以轻易地总览关键数据，查看多项不同计划的进度，并通过快速访问卡片一键访问最重要的任务
  </span>
 </p>
 <section style="text-align: center; margin-top: 10px; margin-bottom: 10px; line-height: 0;">
  <section>
   <img src="https://mmbiz.qpic.cn/mmbiz_png/dibCdrCystEXqzrUZqezzApibeHwjqkxKDp9YokCSX6OdNU8RBIDcZRpIicwxp6USe95W9cQd1zFpYicrTqcyBDQSQFic0uSDTCdO8sIpT2cqicCA/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=4" style="vertical-align: middle; width: 648px !important; height: auto !important;" />
  </section>
 </section>
 <section>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <span>
    仪表盘由一个或多个计划卡片组成，每个计划卡片以可视化的方式展示了该计划的进度条，其名下任务的进展情况、截止日期和优先级等信息，点击每张子卡片即可在浮窗中查看满足对应条件的任务
   </span>
  </p>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <span>
    <br />
   </span>
  </p>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <span>
    如要同时查看多个计划卡片以便进行对比，在左上角勾选
   </span>
   <span>
    <span>
     Show all projects
    </span>
   </span>
   <span>
    即可
   </span>
  </p>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <span>
    <br />
   </span>
  </p>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <strong>
    <span style="font-size: 15px; color: rgb(47, 200, 255);">
     <span>
      表格（Grid）
     </span>
    </span>
   </strong>
  </p>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <span>
    在表格视图中，可以预览、排序、筛选、或批量编辑任务
   </span>
  </p>
 </section>
 <section style="text-align: center; margin-top: 10px; margin-bottom: 10px; line-height: 0;">

  </section>
 </section>
 <section>
  <ul class="list-paddingleft-2" style="padding-left: 20px;">
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      可以点击右上角的Columns按钮唤出下拉菜单，自定义所需显示在表格列头的属性，可节约显示空间，在小屏上更简洁
     </span>
    </p>
   </li>
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      可点击Status或Priority唤出下拉菜单，对这两种属性进行筛选，也可以在二者之后的空白栏中直接填入文本进行搜索
     </span>
    </p>
   </li>
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      可长按行首或列头，对表格进行手动拖拽排序
     </span>
    </p>
   </li>
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      可直接点击行首的复选框，快捷变更任务未完成/完成状态
     </span>
    </p>
   </li>
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      对于包括标题、进展情况、优先级和日期等部分属性，用户可直接点击单元格进行编辑
     </span>
    </p>
   </li>
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      可右键点击某行唤出右键菜单，对该任务进行编辑、删除或快速访问
     </span>
    </p>
   </li>
   <li>
    <p style="margin: 0px; padding: 0px;">
     <span>
      右键点击任意一行唤出右键菜单，执行Make subtask命令，或是直接拖拽某行到另一行，可将该行任务降级为上一行任务的子任务，点击亲任务前的箭头，可折叠/展开子任务；对于子任务，在右键菜单中执行Promote subtask命令，可将其恢复到亲任务同一级别
     </span>
    </p>
   </li>
  </ul>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <span>
    <br />
   </span>
  </p>
  <p style="white-space: normal; margin: 0px; padding: 0px;">
   <strong>
    <span style="font-size: 15px; color: rgb(47, 200, 255);">
     <span>
      看板（Board）
     </span>
    </span>
   </strong>

  <p style="white-space: normal; margin: 0px; padding: 0px;">

   </span>

   </span>
  </p>

  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Date display format
     </span>
    </strong>
    <span>
     ：选择日期在插件界面中的显示格式，但插件内部的储存格式永远是YYYY-MM-DD
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Ribbon icons visibility
     </span>
    </strong>
    <span>
     ：选择是否在功能区中显示各视图的开启按钮
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Enable markdown sync
     </span>
    </strong>
    <span>
     ：如启用，则插件数据和任务笔记会通过笔记属性进行双向同步
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Project base folder
     </span>
    </strong>
    <span>
     ：空白栏中填入的文本将被视为存放计划的文件夹名称
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Auto create task notes
     </span>
    </strong>
    <span>
     ：如启用，则在插件界面添加或修改任务时，与之对应的笔记文件会同步动作
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Sync on startup
     </span>
    </strong>
    <span>
     ：如启用，则插件加载时会自动扫描库并同步任务笔记，如用户使用 OB 官方同步，则必须关闭以免发生冲突
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Sync all tasks now
     </span>
    </strong>
    <span>
     ：点击最右边的Sync now按钮以手动同步一切笔记文件
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Auto-schedule dependent tasks
     </span>
    </strong>
    <span>
     ：我看不懂自己看英文吧
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Auto-calculate parent task fields from subtacks
     </span>
    </strong>
    <span>
     ：如启用，则亲任务自动根据子任务的日期和完成率计算其数据
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Enable daily note sync
     </span>
    </strong>
    <span>
     ：如启用，则自动导入日记或其它 MD 文件中添加特定标签的任务
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Tag pattern
     </span>
    </strong>
    <span>
     ：在空白栏中填入的标签将用来识别任务，可以在标签后添加计划名将其自动归入某任务，例：#TagName/ProjectName
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Scan folders
     </span>
    </strong>
    <span>
     ：在空白栏中填入的文件夹名将被视为需要扫描的文件夹，多个文件夹用英文逗号分隔
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Default project
     </span>
    </strong>
    <span>
     ：在下拉菜单中选择一个计划，作为标签后未跟随计划名时默认分配的计划
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Scan now
     </span>
    </strong>
    <span>
     ：点击最右边的Scan now按钮以立刻扫描符合要求的任务并将其导入
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Open dependency graph
     </span>
    </strong>
    <span>
     ：点击右边的Open graph打开可交互的任务关系图表
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Create task notes
     </span>
    </strong>
    <span>
     ：点击右边的Create notes为当前计划中的所有任务各自创建笔记文件
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Tags
     </span>
    </strong>
    <span>
     ：点击右边的Add tag即可新建任务专属标签，在下方可管理已有标签，点击垃圾桶按钮删除
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Statuses
     </span>
    </strong>
    <span>
     ：点击右边的Add status即可新建进展情况，在下方可管理已有进展情况，点击垃圾桶按钮删除
    </span>
   </p>
  </li>
  <li>
   <p style="margin: 0px; padding: 0px;">
    <strong>
     <span>
      Priorities
     </span>
    </strong>
    <span>
     ：点击右边的Add priority即可新建优先级，在下方可管理已有优先级，点击垃圾桶按钮删除
    </span>
   </p>
  </li>
 </ul>
