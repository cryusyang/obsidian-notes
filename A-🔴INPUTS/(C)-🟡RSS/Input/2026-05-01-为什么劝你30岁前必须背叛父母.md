<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   “天下无不是的父母”这句话，害了很多人。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   很多人一辈子碌碌无为，从根源上来讲，是因为“原生家庭的感恩教育
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   ”
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   抽了他们最后一滴血。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   逢年过节的饭桌上，你看着对面那对老夫老妻。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们叹着气，数落着你的各种“罪行”，比如微博你那点的收入、挑剔你找的对象，一边往你碗里夹菜，一边细数当年为了你遭了多少罪、吃了多少苦。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们说了很多很多，最终目的是
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   把自己塑造成神，而把你贬低成狗。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你坐在那里，嘴里的饭菜变得索然无味，咽下去的全是罪恶感和憋屈。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你在外人面前花了好多年、费了老大劲从小孩变成大人，但只要你一回到这个家，只要他们一个眼神，一句阴阳怪气，你骨子里的自卑、胆怯和敏感就会被瞬间激活。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   由于他们那套感恩教育，你觉得你欠了他们的，这辈子都得替他们还债。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但流半仙告诉你，大错特错。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   不是你欠了父母，而是父母亏欠了你。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   这才是被传统道德教育所掩盖的最残酷的天道。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   那些把自己必做神明的父母，活了好几十年一事无成，在外人面前唯唯诺诺、卑躬屈膝，像条被打断脊梁的狗。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但只要一关上家门，面对自己的孩子，他们瞬间就换上了一副奴隶主的嘴脸。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   01
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   繁衍只是动物本能，别拿本能当皇恩浩荡
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   人本质上就是动物，所谓的生殖冲动就是发情期。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   很多父母在社会上毫无建树，生活全面崩盘，他们为什么要生你呢？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为生孩子，是他们在这个残酷世界里，唯一一次零成本称王称霸的机会。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们把你带到这个世界上，没有经过你的同意。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   给你的不是教育，而是打骂、贬低、情绪勒索。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们把在外面受的窝囊气，全部发泄在你身上。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   对外宣称自己这是在培养后代，实际上就是拿孩子当自己的出气筒。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以流半仙想说：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   没有实力的生育不是恩赐，而是一种罪孽；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   把孩子当情绪垃圾桶的父母，他们才是带着还不清的债。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   02
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   认知底层的“为你好”，本质上是一种诅咒
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   传统文化总骗你，父母做的决定就算不对，出发点也是好的，至少不会害你。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这纯粹是狗屁。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   一个人的行为，永远无法超越他的认知边界。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   如果你的父母一辈子在底层挣扎，满脑子都是“老实本分”、“找个稳定班上”、“忍一忍就过去了”，那他们嘴里吐出来的每一个字，都会悄无声息地把你引向平庸的末路。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们连坐下来倾听你真实想法的耐心和能力都没有，凭什么能指导你的人生？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你要是听了他们的话，那就是拿前朝的剑斩本朝的官。
  </span>
 </span>
</section>
<section style="text-align: center; margin-left: 8px; margin-right: 8px;">
 <img src="https://mmbiz.qpic.cn/mmbiz_jpg/icnJXVHKjGA3DTDNg3CrdlCsIRfBaEdhL37a7nIdM65ciaY4KRx9BFdsap3J6n17eWj0sTJ7N0NK6nWZAVp56WiciajRXrUUh053q4gCbcE6cuk/640?wx_fmt=jpeg&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=2" style="height: auto !important; width: 611px !important;" />
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你要是听信满脑子都是穷人思维的父母给你指路，无异于跟着他们一起跳崖
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你顺从蠢人的好意，那就是对自己的命格下死手。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   03
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   你是家族唯一的救世主，你不需要感恩任何人
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   看透天道的人都知道，是你的降生，给这个死水一潭的家庭带来了基因突变的可能性。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你是这个家的升级版硬件，是他们唯一的希望。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   可是结果呢？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   由于父母的懦弱和无能，他们硬生生把病毒植入了你的操作系统，造成了你一辈子的心理阴影。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   他们弄坏了你，他们凭什么让你感恩？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   只要你一天不卸下这沉重的道德包袱，你就一天要背负着他们的烂命，在泥潭里窒息而死。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以流半仙想说，
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   顺流而下是孝子，逆流而上是枭雄。不敢背叛原生家庭的人，永远赢不来世界。
  </span>
 </span>
</section>
