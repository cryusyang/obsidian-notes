> [!example] AI 摘要
> 本文介绍了阿里国际站新推出的多Agent协同平台Accio Work，并以“三省六部制”为灵感，演示如何用其构建高度拟人化、职能分明的AI代理团队，用于复杂协作与决策任务。作者通过搭建中书省（出方案）、门下省（审议把关）、尚书省（统筹分发）及六部（执行落地）等角色，生动展示了多Agent在产品设计（如心流码字器）中的分工协作与制衡机制。该平台对普通用户极为友好，无需邀请码、提供免费额度，虽定位跨境电商，却被广泛“挪用”为创意协作工具。文章强调其核心价值在于制度化的Prompt设计与天然适配OPC（一人公司）模式，让个体借助AI团队实现十人级生产力。

<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   整个感觉，给我冲击说实话，还是挺大的。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为我虽然在Claude Code里面用过Team Agnet，但是那个感觉其实没有特别强，而这是我第一次，这么直观的，感受到了，我靠这一群Agent，就像一群人一样在互相讨论，互相协同。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这可能，就是UI设计的力量吧。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这也是三省六部制最厉害的地方。它强迫每个环节的参与者只站在自己的角度往深了去思考，然后通过流程把这些不同角度的思考汇聚成一个整体决策。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   一个是1400年前极其古老的制度，一个是本世纪正当红的科技。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   很诡异但又出奇和谐地结合到一起。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这种多视角的并行思考，可能才是AI对OPC最大的赋能。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   除了三省六部搞OPC，我还把这里面所有的模型，拉进一个群里做了一个AI圆桌。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   三省六部是流程驱动的，有明确的决策链条，适合做执行类的任务。但有些事情不需要出PRD，需要的是把一个问题想透。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这个想法也是出自我日常和AI聊天的一个痛点。我经常和一个模型多轮对话，它会给我一篇很工整的分析，逻辑严密，论据充分。但我有的时候总觉得缺点什么，因为它只有一个视角。我追问几轮，它会顺着我的方向越走越深，越走越认同我，但没有人拽它回来，跳到另一个角度上去。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   毕竟AI的谄媚，大家也都有目共睹了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以我搭了一个7agent圆桌。
  </span>
 </span>
</p>
<section style="margin-left: 8px; margin-right: 8px;">
 <img src="https://mmbiz.qpic.cn/mmbiz_png/2jjfQoZLoqVnaX1RSUCWQFynUB2RRxyVZSFzZCQPfIAgVIQAPyalaJWWeVfokg2Gb4siaKjZo9vibWOAE7EMUKRcwHXTkvP4sVocznVNM5KEg/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=32" style="height: auto !important; width: 664px !important;" />

<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但真正参与讨论的只有6个，是Opus 4.6，GPT-5.4，Kimi K2.5，Qwen3 max，Gemini 3.1 pro，Minimax M2.5。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   再加一个主持agent只负责推进流程。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   每场圆桌的流程有五轮。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   第一轮，主持抛出议题，先让每个agent独立分析。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   然后进入交叉质疑环节，互相挑对方的毛病。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   第三轮进行回应修正，承认被打中的漏洞，反驳不成立的质疑。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   最后共识收集，看哪些点全场认了，哪些点还有分歧。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   接着，投票选举出来一个意见领袖，再由他写最终报告。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我一共跑了10场，扒了尽可能全面的议题，政治制度，费米悖论，基因伦理，情感人文，严肃的抽象的都有。让他们讨论。
  </span>
 </span>
</p>

 <img src="https://mmbiz.qpic.cn/sz_mmbiz_png/2jjfQoZLoqXlwicVqM798OibrRDY8LIo6PWmBxmZDEfBgRnUzRicLougSMwEF81FxZialjycgtxdgJQAlYNMYGF2o3WVXL7jgYGH3UhH0GjVdyM/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=33" style="height: auto !important; width: 664px !important;" />

<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   好奇这些议题最后圆桌得出什么结论的可以在评论里扣个数字。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   10场战报和得票数我放在这了。
  </span>
 </span>
</p>
<section style="margin-left: 8px; margin-right: 8px;">
 <img src="https://mmbiz.qpic.cn/sz_mmbiz_png/2jjfQoZLoqVzibcwlibcYC7NbBEvxmCeD2VHSeabEkEZUT2ljORx4SNIQW2JBSISJ7qv3s9FmANiciahTz55paf7z6gkk7XicQo3cLTBdHzfYjHY/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=34" style="height: auto !important; width: 664px !important;" />
</section>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   可以看出来Opus 4.6还是有点太全面了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   10场赢了6场，累计36票，基本上是碾压级别的存在。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   GPT-5.4赢了2场，剩下两场打平。Kimi K2.5和哈基米虽然0胜场，但还有agent投,剩下两位选手就没什么存在感了，重在参与了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   虽然规则里明确写了可以自己推荐自己，但全程大家都在推荐别人，除了这位。
  </span>
 </span>
</p>
<section style="margin-left: 8px; margin-right: 8px;">
 <img src="https://mmbiz.qpic.cn/sz_mmbiz_png/2jjfQoZLoqXIcwhCBLR88qHC0zY3j8xc88x6wneE5sAwec88KE5mGtBtS4CHqkibjpkhcvTco3EShkVibqn4k7Aekc2fUVspPoniaGsHeMk76I/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=35" style="height: auto !important; width: 664px !important;" />

<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   尽管在质疑环节他是被质疑的最多的。。。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   真的，这个多Agent协同的玩法，我真的越用越觉得有意思。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   如果你有想法，愿意深入折腾，我真的觉得，它能做的事情远比我展示的多。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   不过这几天玩下来，还是发现他在极限状态下，上下文工程上还有优化空间，没有Claude Code的Agent Team优化的好，特别是当我把9个opus 4.6放进去的时候，每个agent都在全力输出，虽然确实有点极限，但多轮对话后，对话的质量就不太稳定了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   Claude Code昨天架构也泄了，我觉得这块是可以值得优化一下的。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   最后，我还是想要强调一下，这个产品真正的领域，其实是跨境电商版的小龙虾，我之前也接触过蛮多外贸商家，相信我，这个对大家的赋能还是有用的，这不过我是纯邪修，给大家分享一下很好玩的用法。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   希望阿里国际站的人看到了以后不要眼前一黑来追杀我。。。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   现在也不用排队，人人都能用，免费额度用完就正常付token费就行，打折也挺狠，还挺便宜的，可以去体验下。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   最近agent产品、功能真的是在井喷。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   每天醒来都有新东西可以玩，这种兴奋感，像是回到了几年前刚开始写文章的那段时间。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   不过我很庆幸是现在这个样子。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   写不过来，恰恰说明这个领域在疯狂生长。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   如果有一天我觉得没什么可写了，那才是真的该焦虑。
