<p style="margin-left: 8px; margin-right: 8px;">

<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>

 </span>

<p style="margin-left: 8px; margin-right: 8px;">

 </span>

<p style="margin-left: 8px; margin-right: 8px;">
 <span>

  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">

 </strong>

  </strong>
 </span>

<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   郭帆导演因为正在忙着拍摄《流浪地球3》，没能来到现场，但他非常贴心地给在场的伙伴们准备了一条VCR，和大家见面。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <img src="https://mmbiz.qpic.cn/sz_mmbiz_jpg/2jjfQoZLoqXODPVQPbm5t2HE9AsXXaBuIwhYbfibEmBwXoDgDeqOv6Qorf8aUYJZZcLGO2byaT9JZAjib87Aep6vvqZJ0moAaEYnIcesichzE4/640?wx_fmt=jpeg&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=3" style="height: auto !important; width: 664px !important;" />
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>

  </span>
 </span>
</p>
<section style="text-align: center; margin-left: 8px; margin-right: 8px;">
 <img src="https://mmbiz.qpic.cn/sz_mmbiz_jpg/2jjfQoZLoqVG0rGUf3ThO3Ndau6xPsjfEKZO0MO7xL3raibHe9yE8icibFhReDuqZlu28o0Zt3Drudkb4qQiaDfofBEpP154MljfVYsmYsle8zU/640?wx_fmt=jpeg&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=4" style="height: auto !important; width: 664px !important;" />

<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   王智先给出了她的想法。她说作为演员，AI每天迭代的速度让她惊叹，多少都会有一些焦虑。但经历了一段心理波澜之后她想明白了一件事。
  </span>
 </span>
 <strong>
  <span>
   <br />
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    真正好的表演还是人来创作的，目前AI生成的所有作品里，那种有血有肉、有灵魂的活人感，还是没有办法被复刻的
   </span>
  </span>
 </strong>
 <span>
  <span style="font-size: 16px;">
   。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我也问了她，像人和是人之间，那个鸿沟到底是什么。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
 <strong>
  <span>
   <br />
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    是人，靠的是一个演员对于角色的阅历，和他对于生命的理解，那种细节，目前AI到达不了
   </span>
  </span>
 </strong>
 <span>
  <span style="font-size: 16px;">
   。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这是一种人和人之间心灵上的共鸣，AI还学不会。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   而晶晶则给我描述了一个非常具体的长镜头。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">

 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这种很新的、在边界上的东西，AI还做不到。而流浪地球之所以是流浪地球，恰恰是由千千万万这样的细节堆出来的。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">

<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    先要好好生活，好好感知自己想要传达的东西，当你活得足够通透的时候，你一定会做出好的作品
   </span>
  </span>
 </strong>
 <span>
  <span style="font-size: 16px;">
   。
  </span>
 </span>
</p>

 <span>
  <span style="font-size: 16px;">
   聊完这场我有一个特别强烈的感受。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">

  </span>
 </strong>

    <span>
     3. 方汉：一人公司时代来了，AI替你干活之后，你还能干什么
    </span>
   </span>
  </strong>
 </span>
</p>
<section style="margin-left: 8px; margin-right: 8px;">
 <img src="https://mmbiz.qpic.cn/sz_mmbiz_png/2jjfQoZLoqWFGCjliaCEZ7acMLMb9msYULAibZwxXWicvE9qfIKibgsybcXlyUG2ALVkZSdYJOP4TkUJ71Tg1NRcLVmOfOyyl3hiaSN1ff15eGlE/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=5" style="height: auto !important; width: 664px !important;" />

<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   下一位上台分享的，是昆仑万维的董事长兼CEO方汉。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他的演讲主题非常直接，
  </span>
 </span>
 <strong>
  <span>
   <span style="font-size: 16px;">
    一人公司时代全面到来，你能干什么？
   </span>
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他一上来就讲了个笑话，大家原本希望AI帮我们洗碗刷盘，让我们去干有创造力的事，结果现在AI在替我们做有创造力的事，我们还在洗碗刷盘。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这是个有些残酷的现实，但方汉不是来贩卖焦虑的。他给了一个非常有价值的判断，AI时代有五种人难以被替代。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    第一种是Storyteller，讲故事的人。
   </span>
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他关注过一个北影毕业的编剧，AI视频出来之后大多数从业者都抗拒，但这哥们特别拥抱。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为编剧是影视行业里最倒霉的人，上有导演改本下有大明星改本，现在他终于不用伺候任何人，可以自己生成一部剧。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   方汉说，AI短剧能不能爆，最后取决于的不是抽卡数，而是创始人手里那个本子是什么样的。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    第二种是Idea Maker，创造点子的人。
   </span>
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他强调有点子的门槛其实非常低。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   乔布斯之前HTC早就发明了触屏手机，而只有iPhone成了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以Idea Maker真正的门槛是执行力。现在有了Claude Code这类工具，一个人就能把idea变成结果。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    第三种是Beauty Designer，定义美的人。
   </span>
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他引用一个艺术家的话，说视频和图像生成模型本质上都是对人类艺术尸体的堆积，最后一定是个缝合怪。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   陶哲轩做过实验，把数学难题丢给AI，解出几道，回头一查发现历史上都有人用类似方法做过，只是人类自己记不住。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    第四种是System Builder，造流水线的人。
   </span>
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   一个好的Idea Maker不一定是好的System Builder，大家都在笑话OpenClaw代码是屎山，因为Peter过于友善了。要做System Builder必须tough、必须mean。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    第五种是
   </span>
  </span>
 </strong>
 <strong>
  <span>
   <span style="font-size: 16px;">
    范式
   </span>
  </span>
 </strong>
 <strong>
  <span>
   <span style="font-size: 16px;">
    架构师。
   </span>
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   严格定义下人类历史上只有牛顿和爱因斯坦。放宽一点，是Hinton、DeepMind掌门人和Transformer作者。AI暂时没法替代这批人，只能极大加速他们。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   最后他还给出了一个判断。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   现在最大的变化不是工种消失，而是学习曲线变得前所未有的陡。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>

    <span>
     5. 李勇：AI玩具不该是工具，而该是朋友
    </span>
   </span>
  </strong>
 </span>
</p>
<h1 style="margin-left: 8px; margin-right: 8px;">
 <span>
  <img src="https://mmbiz.qpic.cn/mmbiz_jpg/2jjfQoZLoqUA0vOlNjhNQ9V87iaib9bDHpeia3cJjvCMGXCshzdc8dzFkHo3rYMIXtE3mbXfnYJa3ZjwXcgd1TeWiaeWroWu30jazzsjAl9RfbI/640?wx_fmt=jpeg&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=8" style="height: auto !important; width: 664px !important;" />

<h1 style="margin-left: 8px; margin-right: 8px;">
 <span>
  <br />
 </span>
</h1>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   今上午最后一位上台分享的，是Haivivi的创始人李勇。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他的主题是用AI重塑玩具是种什么样的体验。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   李勇一上来就抛出了一个让我有点意外的判断。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他说现在市面上大多数AI玩具，本质上是一个会背唐诗的毛绒喇叭，或者一个能控制智能家居的入口。但Haivivi想给出的答案完全不同。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    一款真正好的AI玩具，不应该是工具，而应该是朋友。
   </span>
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   而把这件事压缩到最底层，他用了一个词，生命感。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   要想有生命感，他认为，用户长期喜欢一个AI玩具，从来不是因为它功能最多、回答最完整，而是在某个瞬间，忽然觉得它像一个活着的存在。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我印象最深的是他给生命感设的两个反直觉指标。
  </span>
 </span>
</p>
<p>
 <span>
  <font face="宋体">
   <span>
    一个是自主性。传统玩具是被动的，你按下按钮它给你反馈，你放下它它就归于沉寂。但
   </span>
  </font>
  <span>
   Haivivi想做的AI玩具是另一种东西。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   当孩子睡着了、当用户去忙别的事的时候，它依然在后台整理你们的对话，反思，成长。
  </span>
 </span>
</p>
<p>
 <span>
  <font face="宋体">
   <span>
    然后某一天它
   </span>
  </font>
 </span>
 <span>
  <font face="宋体">
   <span>
    或许
   </span>
  </font>
 </span>
 <span>
  <font face="宋体">
   <span>
    会突然对你说，
   </span>
  </font>
 </span>
 <span>
  <font face="宋体">
   <span>
    “
   </span>
  </font>
 </span>
 <span>
  <font face="宋体">
   <span>

   </span>
  </font>
 </span>
 <span>
  <font face="宋体">
   <span>

   </span>
  </font>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   那个瞬间，关系就被建立起来了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   李勇说，那一刻用户感受到的不是信息本身，而是原来在我没找它的时候，它也在成长，也在积累，把我放在心上。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这就是自主性带来的生命感。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    另一个是有限性。
   </span>
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   在所有人都在追求长上下文、追求海量记忆、追求消灭幻觉的今天，Haivivi 反而在做减法。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们对生命感的极致理解包含了“有限的记忆”。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   李勇说，全知全能的不是朋友，那是上帝。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   真实的朋友会忘记你上周二中午吃了什么，但他记得你害怕打雷。他会搞混你小学同学的名字，但他一眼能看出你今天不开心。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
