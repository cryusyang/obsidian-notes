<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   1、只要你想轻松自在，那你就不要碰车贷、房贷和传宗接代，再加上耳机一带，一个月三四干的工资，完全可以活得潇洒自在。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   有人一出生就在罗马，有的人一辈子也到不了罗马，还有些人一出生注定就是牛马。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   有的人什么都不用做，却幸福一生；而有的人，天生善良，却尝尽人间疾苦。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   2、不要脸的人更容易赚到钱，因为他们可以为了自己的利益和别人撕破脸皮，而别人往往无计可施。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为大部分人都是要脸的，不会用下三滥的方法对付他，反而他就钻的人是爱面子的空子，自己赚的盆满钵满。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   3、人性天生就是以自我为中心，根本不会为人着想，一切言行都是为了自己的利益，参透人性者，得天下。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   4、清理你的人际关系。与过多的人交往让你疲惫不堪，选择真正关心你的人，注重有效社交。只和志同道合的人深交。不要花太多时间在无效社交上。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   5、少思，少欲，少烦。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   万般带不走，唯有业随身，时时打断时时拉回，不进入颠倒梦想，久而久之必然越活越轻盈。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   想想有多少是身体和灵魂真正需要和能消耗的东西，有多少是欲念的熏染。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   有烦恼的时候，就读读书，只要你烦闷的当下能读进去的书都行。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   6、学会划清和别人的界限。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   别人怎么看你，跟你毫无关系，你要怎么活，也跟别人没有任何关系，撇清别人，才能精力旺盛。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   7、接受世事无常，人这一生所求所得皆是老天爷赏饭吃。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   见过太多天灾人祸世事变迁，方才深知并不是所有努力都会有回报。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因此顺风顺水的时候不会矫情也不会膨胀了，而是踏踏实实趁着东风努力赚钱存钱，晴天预备下雨柴，哪怕以后跌入谷底也能安心蛰伏。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   8、除了生老病死，你所感受到的痛苦，都是你的价值观带来的，而非真实的存在。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   万物都有缺口，那是阳光照过来的地方。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   难过归难过，生活归生活，关关难过关关过，事事难熬事事。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   9、我们与任何人的关系，可以期待，但不能看重，所有的人际关系都和纸一样薄，经不起任何风雨。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   在现如今的社会中，人与人之间的交往，都是用我的酒换你的烟，用你的油换我的盐，酒喝完，也就散了，盐吃完，也就淡了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   10、做人，胆子大一点，脸皮厚一点。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   不需要怕得罪这个，怕得罪那个的，大不了以后不打交道了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   考虑这个人的感受，考虑那个人的感受，那谁来考虑过你的感受？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   有些人，有些事，直接拒绝，可以解决很多不必要的麻烦。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   人性的本质就是：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你越是做事果断，我行我素，不服就干，就越有人欣赏你。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你越是老实善良，百依百顺，胆小怕事，就越有人欺负你。
  </span>
 </span>
</section>
