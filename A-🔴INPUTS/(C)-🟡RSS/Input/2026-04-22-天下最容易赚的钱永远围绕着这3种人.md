 <span>

   当消费者听到那个声音、闻到那个味道时，他们的大脑就已经被催眠了，压力在潜意识里就已经减轻了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   至于功效什么的，这时候都不要紧了，只要体验感拉满，他们就会像朝圣一样心甘情愿地被你收割。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   包装不仅对产品和服务有效，对人也同样有着奇效。不过这是另一个话题了，具体我在《
  </span>
  <a class="normal_text_link mp_article_text_link" href="https://mp.weixin.qq.com/s?__biz=MzA3Mjk5ODcwOQ==&amp;mid=2247491109&amp;idx=1&amp;sn=91b4e8b1745678453e3e8423d465d883&amp;scene=21#wechat_redirect" target="_blank">
   普通人高效“包装”自己的5个领域
  </a>
  <span style="font-size: 16px;">
   》里面聊过，大家可以去看看。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   有人可能会问了，这么忽悠人家，万一被人看穿了怎么办？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这好办，这时候权威就得派上用场了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   那些跨国巨头、名牌大厂，为什么每年花天价雇佣顶尖大学的研究员，搞一堆国际认证？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你以为他们真的是在追求学术真理吗？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   其实，那些光鲜亮丽的实验数据、盖着金印的检查报告，对提高疗效根本没半点用。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   做这件事，本质上是为了堵住大众悠悠之口的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   毕竟，消费者花了大价钱买那些智商税产品时，内心多少还是会有些疑虑的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这时候，你要是把顶尖大学的证明、国际机构的背书拿出来。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这时候，他的疑虑就全部消散了，他不仅买得心安理得，还会拿着这些报告去向别人炫耀。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以，这也是为什么流半仙经常说，那些所谓的权威，他们面向公众说的东西，你听听就好。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   很多时候，那都是给韭菜打的一针强效麻药，让他们在被放血的时候，手不动，心不痛，甚至是面带微笑的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <br />
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   庙堂之上，市井之中，所有人都在贩卖心安。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   既然如此，你为什么不能做那个售卖者，而要做消费者？
  </span>
 </span>
</section>
