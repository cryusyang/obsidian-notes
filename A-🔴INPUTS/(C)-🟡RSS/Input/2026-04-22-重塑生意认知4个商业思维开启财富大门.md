<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   很多人之所以要打一辈子工，是因为他们对创业、做生意、商人这几个词有着根本性的错误认知。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们把这些名词等同于铜臭味、肮脏和剥削。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以，他们美其名曰要守住自己的内心的一方净土，然后心安理得地去给人打一辈子工，受苦受穷一辈子。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但是呢，等他们急需用钱的时候，他们的那点清高，连特么一斤猪肉你都换不来。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   在这个人吃人的社会里，你以为你不碰生意就能独善其身吗？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   恰恰相反，你不主动去收割别人，别人一定会连皮带骨给你生吞活剥了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我知道，很多人也很焦虑，也想要破局。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但只要一动念头想去搞点买卖，脑子里以及身边的人的声音都出奇的一致：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   “没本钱怎么做生意啊？”
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   “做生意水太深了，套路太多了！”
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   “万一亏了那可多丢脸啊？”
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以，为了让自己内心得到安宁，美其名曰你要做个老实本分的打工人，做不来那些“坑蒙拐骗”的事来麻痹自己。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这表面看着你是在坚守底线，但实际上呢，你这是彻头彻尾的软弱。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你害怕不确定性，害怕失败，害怕直面人性中的贪婪和欲望。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你宁愿在温水煮青蛙的舒适区里慢慢发烂发臭，也不敢在充满机会的社会丛林里亮出你的獠牙。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你的结局，只有平庸至死这一条路，绝无第二种可能。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你觉得“生意”是肮脏的字眼对吗？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   流半仙想告诉你，等你真正下场摸爬滚打，你就会发现：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   这世上没有任何一门艺术，能比做生意更纯粹、更让人气血翻涌！
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   生意二字，你把它拆开来看——“生”，是生存，是生机；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   “意”，是意志，是意识。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   “生意”，可以理解为“生的意识”。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这让你在这残酷世界里，为了活下去、活得更好而迸发出的顶级生存智慧。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这是多么野蛮，灵动，且直击本质。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但很多人总爱拿“我根本不熟悉某个领域，我怎么做？”来当挡箭牌。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   可以说，这种想法害死了很多本该翻身的人。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   很多白手起家的老板，在他们的领域赚到大钱之前，也是完全不懂的小白。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但是呢，他们跟一般人不一样的是，他们不懂就去学、去拆解，去试错。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   而不是站在岸边逼逼赖赖，连特么下水的勇气都没有。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   还有人喜欢酸溜溜地说：“商人都是无奸不商的玩意儿，都是骗子！”
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这点，流半仙认为是一个极其可悲的
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   穷人幻觉
  </span>
  <span style="font-size: 16px;">
   。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们对于商人、对于有钱人的了解全都基于自己的幻想和脑补，但实际上跟他们想象中的差别非常大。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   “商”字的本意是什么？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   商量。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以，哪怕我就是所谓的“奸商”，那我也是在跟你充分“商量”之后，才把你给“奸”了的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   本质上就是一个周瑜打黄盖，一个愿打一个愿挨的游戏。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   不然，你看有钱人花大价钱买的各种豪车、豪宅、奢侈品，品牌溢价是肯定有的，但你觉得人家不知道，人家人傻钱多，要排着队给骗子送钱吗？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你永远记住，富人之所以能成为富人，是因为他们绝对是聪明人，而且绝对比你聪明。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你可以质疑富人的人品，但永远别质疑他们的智商。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <a class="normal_text_link mp_article_text_link" href="https://mp.weixin.qq.com/s?__biz=MzA3Mjk5ODcwOQ==&amp;mid=2247492892&amp;idx=1&amp;sn=679e64ea4a6a966c8cc3261bdcf2434f&amp;scene=21#wechat_redirect" target="_blank">
   <span style="font-size: 16px;">
    如果这些商人，甚至所谓的奸商不能提供人家想要的价值，不能精准拿捏人性，谁会心甘情愿地掏出真金白银呢？
   </span>
  </a>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   所以，与其说那是“奸”，不如说，那是对人性幽暗面的极致洞察。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以，如果你也想要拿到结果，那你必须完成一次彻底的思维重塑，建立属于自己的商业框架。
  </span>
 </span>
</section>
