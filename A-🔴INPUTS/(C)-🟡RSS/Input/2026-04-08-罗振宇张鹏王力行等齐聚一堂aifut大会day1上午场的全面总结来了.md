<p style="margin-bottom: 16px; text-align: left; margin-left: 8px; margin-right: 8px;">
 <span style="font-size: 20px;">
  <strong>
   <span style="font-size: 20px; letter-spacing: 0.578px; text-decoration: none; background-color: rgb(0, 0, 0); color: rgb(255, 255, 255);">
    <span>
     1.王磊：一座城市的未来，是一次次真实的探索和开放的协作，一点点创造出来的
    </span>
   </span>
  </strong>
 </span>
</p>
<section>
 <span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
 </span>
</section>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <img src="https://mmbiz.qpic.cn/sz_mmbiz_png/2jjfQoZLoqUKRNMJVKGl0FAYiadZsltLIvhPEvFEuAo1kaR3UXK8PGWSepaqoBAXggw1iaulmBB6FO2Jv9En89Ub3reO3msV6TbbImMbZmziaU/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=3" style="height: auto !important; width: 664px !important;" />
 </span>
 <span>
  <br />
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   在AIFUT大会上，
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   北京亦庄“城市主理人”王磊
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   给出了一份关于一个地区如何拥抱AI的答卷。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他把思考拆成了三个维度，产业、城市、人，一条自下而上的逻辑链。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   第一层是产业。 他的判断很直接，AI不仅仅在赋能某个行业，还在重构产业体系的底层逻辑。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   让AI成为产业的新底座，北京亦庄抓住数据、算力两个关键要素，强调场景应用，开放交通、医疗、制造等100个场景，让技术在真实环境里被打磨、被验证。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   第二层是城市，亦庄的提法是建设全域人工智能之城，让城市成为创新的孵化器。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   五年前就率先布局自动驾驶，如今600平方公里车路云一体化系统已铺开，自动驾驶成为居民的日常出行方式。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   下周日的人形机器人半马，报名队伍从去年的22支涨到100多支，超过三分之一采用自主导航。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   第三层回到人。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   最聪明的城市，必须最懂人，技术越进步，越要回归对人的服务。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   今天亮相的
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   模数
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   OPC社区，专为一人公司和超级个体设计，解决这群人缺工具、缺资金、缺场景、缺服务的痛点。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   从产业重构到城市演进，再到人的发展，这是一条完整的链条。 亦庄做的不是推动某项具体技术，而是构建一座能够持续验证技术、孕育产业、服务于人的城市。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <br />
 </span>
</p>
<p style="margin-bottom: 16px; text-align: left; margin-left: 8px; margin-right: 8px;">
 <span style="font-size: 20px;">
  <strong>
   <span style="font-size: 20px; letter-spacing: 0.578px; text-decoration: none; background-color: rgb(0, 0, 0); color: rgb(255, 255, 255);">
    <span>
     2.卡兹克：唯一不能被重新定义的，是我们的好奇心
    </span>
   </span>
  </strong>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <img src="https://mmbiz.qpic.cn/mmbiz_jpg/2jjfQoZLoqXCP1aNXJLmevh7XDp1aTr3OD2QNziacZmqYIzUrqLiajribN4QVxjyU04kvF8v2ofs2d0YZfeP2WetLmrhBjIUD6pAaAUFBTx2Xc/640?wx_fmt=jpeg&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=4" style="height: auto !important; width: 664px !important;" />
 </span>
 <span>
  <br />
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   开场的时候，我紧张到脚在底下抠地板。但我想讲的核心就一件事。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    所有人的身份，都在被重新定义。
   </span>
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我2015年入行做UI设计师，那时候UI、交互、用研分工清清楚楚。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   十年间这些岗位一路合并，我的职位从UI设计师变成全栈设计师，再到 AI 自媒体，到现在我自己都说不清职业是什么了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   当AI写完你的代码，你还是开发吗？当AI拍完你的电影，你还是导演吗？这不是质问，是我过去一年心里真实的疑惑。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   2011年硅谷说软件吞噬世界，现在是AI吞噬软件。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   GUI时代人操作软件，Agent时代你委托Agent去干活。你甚至不在乎它用了什么工具，只在乎结果。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   飞书就是活例子。以前为办公而生，现在为Agent而生，CLI一开源，一句指令就能操控整个飞书。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我以前坐飞机每次都想问飞机为什么能飞，不好意思开口，怕被笑。现在任何问题我可以直接问AI，任何想法可以直接让Agent帮我做。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我们以前有太多想法死在了算了吧三个字上，现在不用了。这是创造力最好的时代。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   全世界可能还有84%的人没跟AI说过一句话，更别说真正拿它做过创造的。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    我给自己的定位，就是 AI 殿堂门口的门童，把更多人带进来。
   </span>
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这也是我们办AIFUT的原因。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这两天的大会分成两种气质，今天偏理性，聊技术和产品，罗振宇、张鹏、傅盛都在。明天偏感性，聊影视和创造，流浪地球的团队会来分享。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   理性加感性，人文与科技的十字路口，这就是AIFUT想做的事。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   在这个所有东西都在被重新定义的时代，唯一不能被重新定义的，是我们自己的好奇心。愿大家永远对世界保持好奇。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <br />
 </span>
</p>
<p style="margin-bottom: 16px; text-align: left; margin-left: 8px; margin-right: 8px;">
 <span style="font-size: 20px;">
  <strong>
   <span style="font-size: 20px; letter-spacing: 0.578px; text-decoration: none; background-color: rgb(0, 0, 0); color: rgb(255, 255, 255);">
    <span>
     3.罗振宇：未来人类只剩下一件事，告诉AI你要什么
    </span>
   </span>
  </strong>
 </span>
</p>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
 </span>
</section>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   罗振宇是AIFUT大会第一位演讲嘉宾。
  </span>
 </span>
</p>
<section style="margin-left: 8px; margin-right: 8px;">
 <img src="https://mmbiz.qpic.cn/sz_mmbiz_png/2jjfQoZLoqWyyU9oAmUPCPDzmAkia39KqHRZ5xJtVrGhrxbwIvB7QLPzTFfKcefGDg4Xbwtpa6Csmlar4OREh6QKiavUe9NibAyNWnteibJSPg4/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=5" style="height: auto !important; width: 664px !important;" />
</section>
<section>
 <span>
 </span>
</section>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他开场就自嘲是个50岁开外的老登文科生，讲AI只能追得气喘吁吁。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但文科生有自己的自救方法，底层来自经济学的一条铁律，
  </span>
 </span>
 <strong>
  <span>
   <span style="font-size: 16px;">
    价值来自稀缺性
   </span>
  </span>
 </strong>
 <span>
  <span style="font-size: 16px;">
   。哪里热闹，哪里就不稀缺，而热闹本身会在别处制造新的稀缺。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   带着这个视角看 AI，他给出了第一个判断：
  </span>
 </span>
 <strong>
  <span>
   <span style="font-size: 16px;">
    我们叫它人工智能，但它真正的身份是实现智能。
   </span>
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   过去几年总有人说创造力、审美、品味、判断力永远属于人，但他越来越不信。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   在他看来，过去人类文明最大的矛盾，其实是人有一堆想法却拿它没办法。整个教育、资本市场、社会组织，都是围绕把想法实现搭建起来的，我们崇拜工程师、政治家、创业者，是因为他们能把念头变成大桥、变成共识、变成公司。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   而AI颠覆的恰恰就是这一点。
  </span>
 </span>
 <strong>
  <span>
   <span style="font-size: 16px; font-weight: normal;">
    实现，正在变得低门槛、易得、不值钱。
   </span>
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以他抛出了第二个更大胆的推想。
  </span>
 </span>
 <strong>
  <span>
   <br />
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    人最后的稀缺性和价值，是你想要什么。
   </span>
  </span>
 </strong>
 <span>
  <span style="font-size: 16px;">
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   当AI成为这个世界最好的设计师、医生、律师、电影导演，人唯一的用处，就是告诉AI
  </span>
 </span>
 <strong>
  <span>
   <span style="font-size: 16px; font-weight: normal;">
    我们要什么
   </span>
  </span>
 </strong>
 <span>
  <span style="font-size: 16px; font-weight: normal;">
   。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   顺着这条线，他给出了把自己作为产品的三级台阶。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    第一级是独特性。
   </span>
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他用书画界的规矩举例。朋友求字，老师可以写、可以签名，但那枚章在师母手里，不给钱就盖不了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   没有那枚章，字就没有流通价值。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   而你这个人，就是未来给所有 AI 生成的作品盖章的那个章。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   要想实现独特性，他的答案是行动。给自己出一张独属于你的卷子，做一件独属于你的事。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    第二级是丰富性。
   </span>
  </span>
 </strong>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他强调丰富不是多，而是参数多、变量多。他自己今年开始做视频日记，说这件事倒逼他出门、倒逼他把参数打开。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我的视频日记是我的展示窗口，这就是我的生产车间。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <strong>
  <span>
   <span style="font-size: 16px;">
    第三级是魅力。
   </span>
  </span>

   2008年的房价是后者，互联网泡沫和现在的AI是前者。高科技行业发展的前期，有一定泡沫反而是有利的。
