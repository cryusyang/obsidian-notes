 <h1 class="rich_media_title" id="js_text_title">
  分享一下2026我最常用的AI产品。
 </h1>
 <p>
  自去年8月之后，时间又过了大半年，我觉得我又可以来分享一下我现在最常用的AI产品了。
  <br />
  AI圈的变化，实在是太快了。
  <br />
  <br />
  毕竟，马上五一假期了。
  <br />
  我相信很多朋友肯定不出去玩，要在家里学AI的对吧？肯定的吧？
  <img src="http://res.wx.qq.com/mmbizappmsg/zh_CN/htmledition/js/images/pic/pic_blank7db1df.gif" />
  <br />
  所以咧，出一期这个，也能帮大家，在五一假期学习AI
  <img src="http://res.wx.qq.com/mmbizappmsg/zh_CN/htmledition/js/images/pic/pic_blank7db1df.gif" />
  。
  <br />
  <br />
  坦诚的讲，我用的大部分都是海外版的产品，因为从能力和质量上来说，目前海外版的一些产品确实能力更强，但也更贵。
  <br />
  但考虑到很多人的不方便，所以如果国内有水平差不多的，我也会推荐一个国内的产品，方便大家使用，如果某项能力差很多的，我就不推荐了。
  <br />
  <br />
  那么，咱们开始。
  <br />
  <br />
  1. 知识问答：
  <br />
  GPT-5.5（幻觉极低）
  <br />
  豆包（国内）
  <br />
  <br />
  2. 内容创作与知识管理：
  <br />
  Claude Opus 4.6（独一档的夯，别用Opus 4.7，真的拉）
  <br />
  DeepSeek V4 Pro（国内）
  <br />
  <br />
  3. 数据分析：
  <br />
  Codex + GPT-5.5
  <br />
  Claude Code + GLM-5.1（国内）
  <br />
  <br />
  4. 前端设计：
  <br />
  Gemini 3.1 Pro
  <br />
  Kimi K2.6（国内）
  <br />
  <br />
  5. 架构规划：
  <br />
  Claude Code + Claude Opus 4.7
  <br />
  Claude Code + GLM-5.1（国内）
  <br />
  <br />
  6. 代码开发执行：
  <br />
  Codex + GPT-5.5
  <br />
  Claude Code + GLM-5.1（国内）
  <br />
  PS：我现在一般是cc + Opus 4.7做完规划以后，Codex + GPT-5.5去进行详细开发和执行。
  <br />
  <br />
  7. 深度研究：
  <br />
  ChatGPT DeepResearch
  <br />
  豆包（国内）
  <br />
  <br />
  8. 图片与平面设计：
  <br />
  GPT-image-2（独一档的夯）
  <br />
  即梦Seedream-5.0-lite（国内）
  <br />
  <br />
  9. 视频生成与编辑：
  <br />
  Seedance 2.0（运动质感）
  <br />
  可灵3.0（电影质感，原生4k夯爆了）
  <br />
  PS：两个都是国内的。
  <br />
  <br />
  10. 音乐生成：
  <br />
  Suno v5.5
  <br />
  MiniMax Music 2.6（国内）
  <br />
  <br />
  11. 3D生成：
  <br />
  TripoAI
  <br />
  <br />
  12：AI输入法：
  <br />
  豆包输入法（语音输入夯爆了）
  <br />
  <br />
  13：AI硬件：
  <br />
  飞书录音豆（帮我拿我自己每天的语音对话Context进飞书会议纪要）
  <br />
  GetSeed录音卡（帮我每天发芽获得新的认知）
  <br />
  <br />
  14：AI热点资讯获取：
  <br />
  AIHOT（我自己做的，浓缩了三年做AI自媒体的经验，五一我在家里再优化一下成本和服务器还有安全啥的，预计五一节后可以给所有人免费开放使用，做都做了，不如给大家一起玩）
  <br />
  <br />
  感觉我几乎常用的就这些了，有点想不起来别的了。。。
  <br />
  如果大家有自己想知道的其他场景的好用的AI产品，也可以在评论区提问，玩了这么多，知无不言。
  <br />
  <br />
  大概就是这样。
  <br />
  大家五一快乐！
  <br />
  <br />
  如果没啥大热点的话，那咱们节后再见啦👋
 </p>
</div>
