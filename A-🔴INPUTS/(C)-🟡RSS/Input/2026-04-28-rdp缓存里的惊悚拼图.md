> [!example] AI 摘要
> 本文揭示了Windows远程桌面（RDP）默认启用的“位图缓存”功能所引发的安全隐患：该功能会自动将远程会话中屏幕显示内容切割为带坐标的图像碎片，持久化存储于本地用户目录，极易被低权限攻击者读取并拼接还原出敏感信息（如文件名、代码片段、登录框等）。这种隐蔽、默认开启且常被忽视的机制，已成为勒索软件团伙横向移动和情报收集的关键跳板，威胁企业核心数据安全与合规性。文章强调，便利性优化背后潜藏巨大风险，安全防护需重视此类“默认设置”带来的隐性攻击面。

 <h1 style="margin-top: 30px; margin-bottom: 15px; padding: 0px; font-weight: bold; color: black; font-size: 24px;">
  <strong style="font-weight: bold; color: black;">
   <span>
    引言
   </span>
  </strong>
 </h1>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <span>
   想象一下这个场景：小李在午休时，用公司电脑远程桌面（RDP）登了一下家里的机器，想确认昨晚下载的电影好了没。他迅速退出，深藏功与名。他以为这就像浏览器关掉“无痕模式”，一切了无痕迹。
  </span>
 </p>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <strong style="font-weight: bold; color: black;">
   <span>
    大错特错。
   </span>
  </strong>
 </p>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <span>
   他的屏幕上闪过的那一秒《沙丘2》海报、那个挂着“私人文件”标题的文件夹图标...这些视觉碎片，已经被Windows系统悄悄地地
  </span>
  <strong style="font-weight: bold; color: black;">
   <span>
    拍下“快照”
   </span>
  </strong>
  <span>
   ，并永存在他的工作电脑中。而这些“快照”，未来或许会被任何一位不怀好意的访客，像拼拼图一样，完整地复原出来。
  </span>
 </p>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <span>
   这不是危言耸听，这是每一台连过远程桌面的Windows电脑，都在默默上演的“现实版《窃听风云》”。
  </span>
 </p>
 <hr style="height: 1px; margin: 10px 0px; border-width: 1px medium medium; border-style: solid none none; border-color: black currentcolor currentcolor; border-image: none;" />
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <strong style="font-weight: bold; color: black;">
   <span>
    引用权威观点
   </span>
  </strong>
  <span>
   网络攻防里，最可怕的威胁往往不是那些高精尖的零日漏洞，而是那些
  </span>
  <strong style="font-weight: bold; color: black;">
   <span>
    被所有人遗忘在角落的“默认设置”
   </span>
  </strong>
  <span>
   。
  </span>
 </p>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <span>
   根据Palo Alto Networks最新的《攻击面威胁报告》，远程桌面（RDP）问题，竟然占到了全球企业安全风险的三成以上！像臭名昭著的“散装蜘蛛”（Scattered Spider）这类勒索软件团伙，都把“搞到RDP权限”作为入侵企业的首选敲门砖。
  </span>
 </p>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <span>
   <img src="https://mmbiz.qpic.cn/mmbiz_png/TKdPSwEibsZjDWPJbHXkGtsyrZdooSccglZtvmCkfAEb1SCCibcibIsyUyJiadia8ltFg4VDeEMzGBLXr5pe5IbZYo7PDicTrkaSaWFEQHs2QxCdQ/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=1" style="height: auto !important; width: 660px !important;" />
  </span>
 </p>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <span>
   为什么？因为这东西用得太普遍，而它留下的“后遗症”，却鲜有人知。
  </span>
 </p>
 <hr style="height: 1px; margin: 10px 0px; border-width: 1px medium medium; border-style: solid none none; border-color: black currentcolor currentcolor; border-image: none;" />
 <h1 style="margin-top: 30px; margin-bottom: 15px; padding: 0px; font-weight: bold; color: black; font-size: 24px;">
  <strong style="font-weight: bold; color: black;">
   <span>
    案例
   </span>
  </strong>
 </h1>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <span>
   我们来复盘一个典型的故事，它可能正在任何一家公司发生：
  </span>
 </p>
 <ol class="list-paddingleft-1" style="margin-top: 8px; margin-bottom: 8px; padding-left: 25px; color: black;">
  <li>
   <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1, 1, 1); font-weight: 500;">
    <strong style="font-weight: bold; color: black;">
     <span>
      “无害”的访问
     </span>
    </strong>
    <span>
     ：一位工程师小张，通过公司电脑的远程桌面，紧急连上了一台存放着敏感设计文档的服务器。他快速查阅了几个文件后退出，整个过程不到5分钟。
    </span>
   </section>
  </li>
  <li>
   <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1, 1, 1); font-weight: 500;">
    <strong style="font-weight: bold; color: black;">
     <span>
      “隐形”的入驻
     </span>
    </strong>
    <span>
     ：在后台，Windows的“位图缓存”功能（一个原本为了让你下次连接更快的小优化），已经把他屏幕显示的每一块区域，切割成上千个微小的图片磁贴，存进了电脑硬盘一个固定的文件夹里。它就像一台延时摄影机，把小张屏幕上闪过的一切——
    </span>
    <strong style="font-weight: bold; color: black;">
     <span>
      包含了文件命名、部分代码片段甚至可能飘过的账号输入框
     </span>
    </strong>
    <span>
     ——全部定格保存。
    </span>
   </section>
  </li>
  <li>
   <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1, 1, 1); font-weight: 500;">
    <strong style="font-weight: bold; color: black;">
     <span>
      “路过”的窃贼
     </span>
    </strong>
    <span>
     ：一周后，攻击者通过某个钓鱼邮件，控制了小张同事的电脑。他不需要什么管理员权限，就像逛自家后院一样，溜达到
    </span>
    <span>
     <span>
      %localappdata%\Microsoft\Terminal Server Client\Cache
     </span>
    </span>
   </section>
  </li>
 </ol>
 <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1, 1, 1); font-weight: 500;">
  <span>
   这个“景点”。把整个“景点”拍个照（压缩打包），大摇大摆地通过日常的HTTPS网络流量发走，全程波澜不惊。
  </span>
 </section>
 <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1, 1, 1); font-weight: 500;">
  <span>
   <img src="https://mmbiz.qpic.cn/sz_mmbiz_png/TKdPSwEibsZhhKIbMjfbNwzAsGfn4990XR6EnqsiatXR2Z3SUN76QvYnxZ21OyemYnrO7RRDnMtic5vtiaFDUicgoN81auh5fyrz0Z9J1I7Ty3UI/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=2" style="height: auto !important; width: 660px !important;" />
  </span>
 </section>
 <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1,1,1); font-weight: 500;">
  <strong style="font-weight: bold; color: black;">
   <span>
    4. “拼图”的秘密
   </span>
  </strong>
  <span>
   ：攻击者收到“照片包”后，只需要使用两款在GitHub上免费开源的工具（
  </span>
  <code>
   <span>
    bmc-tools
   </span>
  </code>
  <span>
   和
  </span>
  <code>
   <span>
    RdpCacheStitcher
   </span>
  </code>
  <span>
   ）。一个负责拆解图片碎片，一个负责自动拼接。不出十分钟，小张当时查看文档的
  </span>
  <strong style="font-weight: bold; color: black;">
   <span>
    屏幕截图
   </span>
  </strong>
  <span>
   ，就能被部分甚至完整地重构出来！
  </span>
 </section>
 <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1,1,1); font-weight: 500;">
  <span>
   <img src="https://mmbiz.qpic.cn/sz_mmbiz_png/TKdPSwEibsZjypWeprph4aJw8RUaGSt6XqQPA29F7F2VtdW3x18bZJr7QgJXYiahNjHH9PsKnicPTG1KX6V8mtljicHJZnwdIgqia2D1OxTy0NUU/640?wx_fmt=png&amp;from=appmsg&amp;watermark=1&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=3" style="height: auto !important; width: 660px !important;" />
  </span>
 </section>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0; line-height: 26px; color: black; font-size: 14px;">
  <span>
   你看，整个过程，没有触发任何高危警报，没有触碰任何核心数据库。攻击者只是“捡”走了所有人都没在意的“垃圾”，却从中淘出了通向核心业务的“金矿地图”。
  </span>
 </p>
 <hr style="height: 1px; margin: 0; margin-top: 10px; margin-bottom: 10px; border: none; border-top: 1px solid black;" />
 <h1 style="margin-top: 30px; margin-bottom: 15px; padding: 0px; font-weight: bold; color: black; font-size: 24px;">
  <strong style="font-weight: bold; color: black;">
   <span>
    理论拆解
   </span>
  </strong>
 </h1>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0; line-height: 26px; color: black; font-size: 14px;">
  <span>
   别被“位图缓存”这个词唬住。你完全可以把它理解为
  </span>
  <strong style="font-weight: bold; color: black;">
   <span>
    “Windows系统的视觉记忆体”
   </span>
  </strong>
  <span>
   。
  </span>
 </p>
 <ul class="list-paddingleft-1" style="margin-top: 8px; margin-bottom: 8px; padding-left: 25px; color: black;">
  <li>
   <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1,1,1); font-weight: 500;">
    <strong style="font-weight: bold; color: black;">
     <span>
      为什么要有它？
     </span>
    </strong>
    <span>
     为了让你下次远程连接时，那些不变的元素（比如软件按钮、桌面背景）能快速加载，不用重新从网络传一遍，提升体验。初衷是好的。
    </span>
   </section>
  </li>
  <li>
   <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1,1,1); font-weight: 500;">
    <strong style="font-weight: bold; color: black;">
     <span>
      它记住了什么？
     </span>
    </strong>
    <span>
     它记下的，是屏幕上每一个
    </span>
    <strong style="font-weight: bold; color: black;">
     <span>
      像素块
     </span>
    </strong>
    <span>
     。只要你当时屏幕上显示过的，无论窗口是不是最小化，只要是RDP会话内渲染的，它都可能记下一份。这就像你家监控录像不只拍门口，还把客厅电视里播放的画面也存下来了。
    </span>
   </section>
  </li>
  <li>
   <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1,1,1); font-weight: 500;">
    <strong style="font-weight: bold; color: black;">
     <span>
      为什么能拼回去？
     </span>
    </strong>
    <span>
     因为这些“像素块”都带有自己的坐标信息。像拼乐高一样，只要按坐标把碎片放回原位，哪怕不能100%还原，也能拼凑出大致的画面。
    </span>
    <strong style="font-weight: bold; color: black;">
     <span>
      一个登录框、一封邮件的标题、一份财务报告的摘要
     </span>
    </strong>
    <span>
     ……对于攻击者来说，“点滴”信息都是宝贵的“侦察情报”。
    </span>
   </section>
  </li>
 </ul>

 <h1 style="margin-top: 30px; margin-bottom: 15px; padding: 0px; font-weight: bold; color: black; font-size: 24px;">
  <span>
   <strong style="font-weight: bold; color: black;">
    <span>
     技术特点
    </span>
   </strong>
  </span>
 </h1>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0; line-height: 26px; color: black; font-size: 14px;">
  <span>
   我们来给这个“沉默的告密者”画个像：
  </span>
 </p>
 <ol class="list-paddingleft-1" style="margin-top: 8px; margin-bottom: 8px; padding-left: 25px; color: black;">
  <li>
   <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1,1,1); font-weight: 500;">
    <strong style="font-weight: bold; color: black;">
     <span>
      默认开启，无处不在
     </span>
    </strong>
    <span>
     ：只要用过远程桌面，缓存就会生成。这是微软的默认行为，全球数亿台电脑都如此。
    </span>
   </section>
  </li>
  <li>
   <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1,1,1); font-weight: 500;">
    <strong style="font-weight: bold; color: black;">
     <span>
      权限要求极低
     </span>
    </strong>
    <span>
     ：普通用户权限就能读取，攻击者进入内网后“顺手牵羊”毫无阻碍。
    </span>
   </section>
  </li>
  <li>
   <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1,1,1); font-weight: 500;">
    <strong style="font-weight: bold; color: black;">
     <span>
      隐蔽性极高
     </span>
    </strong>
    <span>
     ：文件存放在用户目录，非标准文档格式，日常安全扫描极易忽略。窃取过程伪装成普通压缩和网络传输，极难察觉。
    </span>
   </section>
  </li>
  <li>
   <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1,1,1); font-weight: 500;">
    <strong style="font-weight: bold; color: black;">
     <span>
      信息维度特殊
     </span>
    </strong>
    <span>
     ：它
    </span>
    <strong style="font-weight: bold; color: black;">
     <span>
      不记录你敲了什么键（那是键盘记录器干的），而是记录了你当时看到了什么
     </span>
    </strong>
    <span>
     。这是一种独特且极具场景感的信息泄露。
    </span>
   </section>
  </li>
 </ol>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0; line-height: 26px; color: black; font-size: 14px;">
  <span>
   更讽刺的是，这个缓存甚至在攻击者
  </span>
  <strong style="font-weight: bold; color: black;">
   <span>
    撤退时
   </span>
  </strong>
  <span>
   也会成为线索。一台正常使用RDP的电脑，缓存文件夹突然空了？这就像小偷离开前特意擦掉了指纹——
  </span>
  <strong style="font-weight: bold; color: black;">
   <span>
    “没有证据”，恰恰就是最可疑的证据。
   </span>
  </strong>
 </p>
 <hr style="height: 1px; margin: 0; margin-top: 10px; margin-bottom: 10px; border: none; border-top: 1px solid black;" />
 <h1 style="margin-top: 30px; margin-bottom: 15px; padding: 0px; font-weight: bold; color: black; font-size: 24px;">
  <strong style="font-weight: bold; color: black;">
   <span>
    安全与业务关系
   </span>
  </strong>
 </h1>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0; line-height: 26px; color: black; font-size: 14px;">
  <span>
   这绝不只是IT部门的一个技术参数问题。它直接关系到：
  </span>
 </p>
 <ul class="list-paddingleft-1" style="margin-top: 8px; margin-bottom: 8px; padding-left: 25px; color: black;">
  <li>
   <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1,1,1); font-weight: 500;">
    <strong style="font-weight: bold; color: black;">
     <span>
      核心机密泄露
     </span>
    </strong>
    <span>
     ：拼接出的截图可能直接暴露尚在研发中的产品设计、未公布的财务数据、敏感的客户信息。
    </span>
   </section>
  </li>
  <li>
   <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1,1,1); font-weight: 500;">
    <strong style="font-weight: bold; color: black;">
     <span>
      内网纵深失守
     </span>
    </strong>
    <span>
     ：攻击者拿到截图，就像拿到了公司内部的“导览图”。他们能知道哪些系统重要、命名规则是什么、甚至从截图里找到更多可用的账号信息，进行横向移动。防御方的“迷宫”，在攻击者眼里变成了“导航直达”。
    </span>
   </section>
  </li>
  <li>
   <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1,1,1); font-weight: 500;">
    <strong style="font-weight: bold; color: black;">
     <span>
      合规风险
     </span>
    </strong>
    <span>
     ：对于金融、医疗、政务等受严格监管的行业，这种未加密的敏感信息留存，本身就是严重的合规违规。
    </span>
   </section>
  </li>
  <li>
   <section style="margin-top: 5px; margin-bottom: 5px; line-height: 26px; text-align: left; color: rgb(1,1,1); font-weight: 500;">
    <strong style="font-weight: bold; color: black;">
     <span>
      品牌与信任危机
     </span>
    </strong>
    <span>
     ：一旦因此导致数据泄露，公众和客户不会理解什么“位图缓存”，他们只会认为这家公司的安全“形同虚设”。
    </span>
   </section>
  </li>
 </ul>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0; line-height: 26px; color: black; font-size: 14px;">
  <span>
   开启这个缓存，或许能换来1%的连接速度提升；但留下的安全隐患，可能需要100%的代价去弥补。这买卖，划算吗？
  </span>
 </p>
 <hr style="height: 1px; margin: 0; margin-top: 10px; margin-bottom: 10px; border: none; border-top: 1px solid black;" />
 <h1 style="margin-top: 30px; margin-bottom: 15px; padding: 0px; font-weight: bold; color: black; font-size: 24px;">
  <strong style="font-weight: bold; color: black;">
   <span>
    总结
   </span>
  </strong>
 </h1>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0; line-height: 26px; color: black; font-size: 14px;">
  <span>
   技术世界里，没有“无痕模式”。每一个为了便利而留下的“缓存”，都可能成为照亮你秘密的“聚光灯”。安全，往往就输在这些被遗忘的细节里。
  </span>
 </p>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0; line-height: 26px; color: black; font-size: 14px;">
  <span>
   真正的安全感，不是相信攻击者找不到门，而是确保即使他路过门口，也找不到任何有价值的地图碎片。
  </span>
 </p>
