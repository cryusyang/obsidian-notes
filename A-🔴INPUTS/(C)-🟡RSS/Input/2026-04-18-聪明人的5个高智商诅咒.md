<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   小时候，如果大人摸着你的头说一句“这孩子真聪明”，那是一种嘉奖。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但在当下的社会里，如果你到了三十五岁，还在被人夸聪明，那这大概率是一句包裹着糖衣的骂人话。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   它的潜台词是：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   这人除了脑子转得快，兜里比脸还干净，混得啥也不是。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这些年大环境不好，最先被优化的往往是那些名牌大学毕业、履历光鲜、智商超群的“聪明人”。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们拿着看似体面的死工资，背着三十年的房贷，每天在各大社交平台上点评宏观经济、讨论AI如何重塑人类未来，转头却在打车软件上为了三块钱的优惠券算计半天。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   为什么那些脑容量惊人、对什么事都能一眼看穿本质的聪明人，到了中年大多活成了一头拉磨的驴，始终无法跨越阶层，过上真正自由富足的生活呢？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为“聪明”和“成事”中间，还隔着十万八千里。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   在这个草台班子拼凑起来的世界里，聪明非但不是通行证，反而是一种要命的诅咒。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我前几天在《
  </span>
  <a class="normal_text_link mp_article_text_link" href="https://mp.weixin.qq.com/s?__biz=MzA3Mjk5ODcwOQ==&amp;mid=2247492857&amp;idx=1&amp;sn=c61199ec47bcaffa6b7137cb06ea932a&amp;scene=21#wechat_redirect" target="_blank">
   <span style="font-size: 16px;">
    底层里聪明的孩子，是最悲催的物种
   </span>
  </a>
  <span style="font-size: 16px;">
   》里简单聊过，今天跟大家深入剖析一下。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我总结，底层里的聪明人身上，往往带有以下5个高智商诅咒，如果你身上也有类似的毛病，我劝你趁早扒了自己这层皮。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   否则，任凭你智商180，这辈子也就是个高级耗材的命。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; color: rgb(171, 25, 66); font-weight: bold;">
   一、聪明人容易被“完美主义”拖死
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   聪明人最大的绝症，是“什么都懂，却什么都不干”。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为学东西快，聪明人往往是个万事通。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   今天看好跨境电商，明天研究短视频带货，后天又觉得搞个人IP是风口。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们的硬盘里存着几百个G的教程，收藏夹里塞满了干货，脑子里的商业模式能写出一本《资本论》。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   然后呢？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   然后，就没有然后了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们的精力、注意力被分的太散了，什么都略懂一点，结果却什么都不精，最终就是连新手村的大门都没卖出去过。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   聪明人，太迷恋“规划”带来的多巴胺。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们把事情想得太透彻，以至于在起步之前，就已经把所有的困难、风险、甚至失败后的退路都推演了800遍。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   举个例子，搞自媒体。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   如果是个没什么思考能力的莽夫，今天决定干，今晚就拿个破手机开播了，哪怕在镜头前结巴、出洋相，人家一个月后好歹积攒了真实的挨骂经验。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   换成聪明人是怎么干的？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们得先花一周时间搞赛道调研，画思维导图，分析受众心理学；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   再花半个月买设备、调光线、设计花里胡哨的Logo；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   最后还要纠结第一篇文案的排版到底是用宋体还是黑体。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   结果一个月过去，热点早就凉透了，风口早就吹过了，他们看着别人粗制滥造的视频月入十万，只能酸溜溜地骂一句：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   “这届网友真没品味。”
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   流半仙想说，自媒体时代的容错率其实非常低，执行力才是你的第一要务。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   为什么很多大老板连拼音都认不全，却能让一群高学历人才给他打工？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为人家懂得粗暴破局。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: normal;">
   他们不追求完美，而是追求
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   先搞起来。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你想当掌局者，就得学会把专业的事扔给专业的人。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   注册、税务、法律合同，这些花钱就能买到的服务，你非要自己去啃厚厚的法条，这就叫穷忙。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   掌局者的精力，永远只盯在一个点上：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   怎么搞流量，怎么把钱收进自己的口袋。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   一旦你把精力浪费在那些“展示你很聪明”的细枝末节上，你的现金流离断裂也就不远了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; color: rgb(171, 25, 66); font-weight: bold;">
   二、聪明人都是算计过头的孤家寡人
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   有一种聪明，叫作“精明到让人恶心”。
  </span>
 </span>
</section>
