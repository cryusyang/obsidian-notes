> [!example] AI 摘要
> 文章批判了当前主流AI工具普遍缺乏长期记忆能力的问题，指出现有解决方案（如Mem0和Nowledge Mem）存在准确率低或配置复杂等缺陷。作者提出极简方案：仅用两个Markdown文件（soul.md和memory.md）配合私有GitHub仓库，实现跨AI工具、跨项目的本地化、可版本控制的记忆管理。该方案无需服务器、无订阅费用、完全隐私可控，支持一键迁移和多项目隔离，强调用户对自身AI记忆数据的绝对所有权与持久掌控。

 <h1 style="display: table; padding: 0px 1em; border-bottom-width: 2px; border-bottom-style: solid; border-bottom-color: rgb(15, 76, 129); margin-right: auto; margin-bottom: 1em; margin-left: auto; color: rgb(63, 63, 63); font-size: 19.2px; font-weight: bold; text-align: center; margin-top: 0px !important;">
  <span>
   市面上最强大的AI记忆系统
  </span>
 </h1>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   你跟Claude聊了三小时，把项目架构、技术选型、个人偏好全交代了一遍。提示你窗口要满了，需要你继续开新窗口，你照做了，结果新窗口不认识你了，一切重来。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   换Cursor试试？一样。换GPT？一样。换Gemini？还是一样。每一个AI工具都有阿尔兹海默。你每次开口都得重新自我介绍，重新说你讨厌分号，重新解释你上次改到哪个文件。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   这不是bug，这是所有AI工具的出厂设定。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   市面上有人在解决这个问题吗？
   <span style="font-weight: bold;">
    有。两类方案。
   </span>
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   第一类叫Mem0，五万颗星，把你的记忆存到他们的云端向量数据库里。先不说隐私，就说效果：独立测试显示它的事实回忆准确率只有17.5%。你告诉它你住上海，下次问它你住哪，五次里答对不到一次。我告诉你什么叫向量，就是大概，但是听起来很高大上，其实一坨屎。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   第二类叫Nowledge Mem，本地优先，听起来不错。但你要下载一个应用，配置MCP服务，给每个AI工具装专属插件，后台还要跑一个LLM做知识整理。折腾完半天过去了。就为了让AI记住你喜欢tabs不喜欢spaces？
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   两个方案，一个不准，一个太重。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   我的方案：两个markdown文件加一个git仓库。没了，安装几秒钟。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   <img src="https://mmbiz.qpic.cn/sz_mmbiz_png/ibQqpoickzFcxckyjPIW6NquH2AByqtB7ibxYPrtNgrMe193JAlek01dkawWKibPxz048gMWRcT2DIfg9A3CRK4FibPPABdpEzVnia955FnHEibxMI/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=0" style="width: 664px !important; height: auto !important;" />
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   整个工具就是一个GitHub Template仓库。里面预埋了五个文件，每个AI工具打开仓库的时候会自动读取属于自己的那个：
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   Claude Code读CLAUDE.md，Cursor读.cursorrules，Codex读AGENTS.md，Copilot读copilot-instructions.md，Gemini CLI读GEMINI.md。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   五个文件内容一样，只是文件名不同。因为每个工具认的"开机自启"文件不一样。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   你要做的事情超级简单，访问我们的工具仓库：点使用此仓库模板，Use this template，复制一个自己的仓库，设为Private，因为你的提示词工作这些隐私当然得私有，同时放心，能够黑GH的黑客要么没有，要么不屑看你这些玩意。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   然后用你习惯的AI工具打开这个仓库。AI会读到指令，主动问你几个问题：你做什么的？你怎么工作？你有什么偏好？问完之后它把你的画像写进.ilang/soul.md，把后续每次对话中的决策、教训、事实写进.ilang/memory.md。每次更新完立刻commit加push，不等你关窗口。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   下次打开，它先读这两个文件，完整上下文恢复。你什么都不用重复。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   换工具呢？比如你从Cursor换到Claude Code。给新工具说一句话：
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   "我的记忆仓库在github.com/你的用户名/mem-forever，PAT是ghp_xxx，去读一下。"
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   完事。一句话，满血恢复。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   多个项目呢？再用一次模板。mem-forever-work，mem-forever-research，mem-forever-client-x。每个仓库是独立的记忆，互不干扰。你要知道Github免费用户足够你开NN个仓库，完全够用，如果还不够，多注册几个GH账户也可以解决问题，一切都是免费。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   ChatGPT网页版和Claude.ai网页版不能跑git怎么办？把soul.md上传到项目知识文件里。粗暴，但有效。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   GitHub私有仓库免费。没有服务器。没有订阅。没有API费用。没有Pro版本。没有"升级解锁更多记忆"。外面居然把这些功能做了一个SaaS，对用户收费。
  </span>
 </p>
