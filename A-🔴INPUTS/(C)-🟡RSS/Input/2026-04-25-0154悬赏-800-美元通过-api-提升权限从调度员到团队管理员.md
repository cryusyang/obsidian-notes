  </section>
 </li>
</ul>
<p style="margin-top: 0px; margin-bottom: 0px;">
 <span>
  👉 导致混淆和潜在的误用
 </span>
</p>
<p style="margin-top: 0px; margin-bottom: 0px;">
 <span>
  <br />
 </span>
</p>
<h2 style="margin-top: 0px; margin-bottom: 0px;">
 <span>
  <span style="font-size: 20px; font-weight: bold;">
   根本原因
  </span>
 </span>
</h2>
<h2 style="margin-top: 0px; margin-bottom: 0px;">
 <span>
  <br />
 </span>
</h2>
<p style="margin-top: 0px; margin-bottom: 0px;">
 <span>
  这个漏洞归根结底是一个典型的错误：
 </span>
</p>
<blockquote>
 <p style="margin-top: 0px; margin-bottom: 0px;">
  <strong>
   <em>
    <span>
     授权仅在用户界面中强制执行，后端 API 中未强制执行。
    </span>
   </em>
  </strong>
 </p>
</blockquote>
<ul class="list-paddingleft-1">
 <li>
  <section style="margin-top: 0px; margin-bottom: 0px;">
   <span>
    UI → 正确限制了调度程序
   </span>
  </section>
 </li>
 <li>
  <section style="margin-top: 0px; margin-bottom: 0px;">
   <span>
    API → 盲目接受请求
   </span>
  </section>
 </li>
 <li>
  <section style="margin-top: 0px; margin-bottom: 0px;">
   <span>
    <br />
   </span>
  </section>
 </li>
</ul>
<p style="margin-top: 0px; margin-bottom: 0px;">
 <span>
  这种不匹配正是大多数
 </span>
 <strong>
  <span>
   BAC（访问控制漏洞）
  </span>
 </strong>
 <span>
  漏洞存在的原因。
 </span>
</p>
