 <span>

   <section>
    <span style="font-size: 16px; letter-spacing: 0.034em;">
     正月初八，大部分公司开工大吉的日子，我也没闲着，安静的呆了一天，没干别的，就一直在思考自己的2026该如何过。
    </span>
    <br />
   </section>
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   一年之计在于春，“做对的事情”比“把事情做对”重要一万倍，想好2026做什么更正确，更利于自己人生的复利至关重要，对我如此，对你也如此。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   我在2024年的计划里曾提到过，AI、出海、自媒体是普通人的最佳创业方向，如何做那是下一步的事，但重要的不要再去干无限循环规模不经济的“坏生意”。
  </span>
 </span>
</section>
<section>
 <span>
  <a class="normal_text_link mp_article_text_link" href="https://mp.weixin.qq.com/s?__biz=MzI1NDkxNDg3OQ==&amp;mid=2247507898&amp;idx=1&amp;sn=9d21f2cfd3bced78442680ee31190608&amp;scene=21#wechat_redirect" target="_blank">
   <span style="font-size: 16px;">
    兄弟，想轻松赚钱和娶老婆，还是出海吧！
   </span>
  </a>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   现在看来，AI不是普通人可以创业的领域，但是可以全面拥抱的时代机会，可以说，未来谁会用AI，谁能用AI解决现实问题，谁就可以上牌桌收大池。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   在我看来，AI是任何领域都可以应用的，其革命性不亚于电的发明，是真正的生产力革命、人类发展的奇点，建议所有人要重视再重视，我也承认自己重视的还是不够，2026年我会把我认为好的AI应用全部用起来，在一线感受“炮火”。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   当然，我能也最想做的就是出海。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   2026年是我的出海年，我计划每月去一个国家，用腿和眼睛去看更大的世界，发现更多的机会，我想，这个2026应该很精彩。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   我一再强调，目前的出海最普通的就是中国供应链出海，其实能获得最大结果的应该像20年前很多外资来中国扎根一样去到某个国家深耕细作，相当于建立了又一个“基地”。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   初步计划是印尼、韩国、新加坡、西班牙、日本先去，而后再去欧美，我美签过期了，要下半年了。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   这也是我2026年最大的“项目”：
  </span>
  <span style="font-size: 16px; color: rgb(111, 200, 218); font-weight: bold;">
   章鱼哥出海游学。
  </span>
 </span>
</section>
<section>
 <section style="font-size: 17px;">
  <section style="display: inline-block;">
   <img src="https://mmbiz.qpic.cn/sz_mmbiz_jpg/pnic2Bq38kOYica6OvAtX42oictXaj76ComMERJU96Jic8NLGaMicibxgt8PD4LV7wY4hEu0lw1zgbibH0Anqj2ZuoOuLHyT3OKkibzavGic49FQOuFE/640?wx_fmt=jpeg&amp;watermark=1&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=1" style="height: auto !important; width: 680px !important;" />

 </section>
 <span style="font-size: 17px;">
  <br />
 </span>
</section>
<section>
 <span style="font-size: 17px;">
  <span style="font-size: 16px;">
   带着一群上市公司的高管、老板、董秘去全球发现投资和并购的机会，“再造”一个大陆奇迹。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   除了每月去一次海外之外，我还会访谈一些上市公司老板，了解下他们出海的需求还有经验，分享给“章鱼出海私董会”的同学们。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   出海，对于我们这一代人来说，是一次进一步海阔天空的机会，万万不可错失。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   哪怕你看苍老师在日本都不知名，但因为最先来中国拥抱中国还学汉字，妥妥的成了最赚钱的日本女优，现在也算把衣服穿了回来，多励志、多智慧。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   再说回自媒体，其实很多人虽然知道自媒体重要，但还是没有把自媒体或者内容提升到战略性的位置。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   现在最好的营销不是投广告，而是“内容营销”。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   无论是“发布会”还是搞老板个人IP，效果都好过投流，因为投流极难建立品牌，ROI一不行了，就没有了销量，无法建立真正的心智和信任，来的快也去的快。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   对于普通人而言更是如此了，这个社会，没有什么比自媒体更低成本创业的了，一部手机就可以写文章拍短视频，几乎零成本。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   现在最怕重资产创业，因为这种投资不可逆，无法小成本试错和迭代，转型相当于推倒重来，我见过太多开餐馆的生意一不好就重新装修搞新菜品的投资了，看得都心疼。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   我2024给自己订的2025计划到现在我也觉得牛逼，
  </span>
  <a class="normal_text_link mp_article_text_link" href="https://mp.weixin.qq.com/s?__biz=MzI1NDkxNDg3OQ==&amp;mid=2247508846&amp;idx=1&amp;sn=684056027785acd46e96cc90031b7bd3&amp;scene=21#wechat_redirect" target="_blank">
   张桓:一个普通投资人的2024
  </a>
  <span style="font-size: 16px;">
   虽然因为一个合伙伙伴的原因搁浅了，但2026重新启航依然不晚，还真的是念念不忘，必有回响。
  </span>
 </span>
</section>
