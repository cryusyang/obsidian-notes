> [!example] AI 摘要
> 文章批判了“勤劳致富”的传统认知，指出多数人虽勤奋工作却陷入“为他人财务自由而奋斗”的困境，根源在于被系统性剥削（资本、税收、金融体系三重收割）和错误的认知框架。作者强调，将职业误认为事业、混淆资产与负债（如自住房、豪车实为负债），导致普通人丧失财富主动权；真正的出路在于“双轨并行”：一方面理性利用主业获取现金流与资源，另一方面用业余时间与资金持续构建能产生被动收入的真正资产。核心结论是：财富自由的关键不在于更努力打工，而在于升级认知、区分资产与负债、延迟满足，并以战略耐心完成从“出卖时间”到“让钱生钱”的范式跃迁。

<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   绝大部分人，终其一生都在极其高效地
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   为别人打工
  </span>
  <span style="font-size: 16px;">
   、
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   为别人还债
  </span>
  <span style="font-size: 16px;">
   、
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   为别人的财务自由
  </span>
  <span style="font-size: 16px;">
   而自己吃尽了苦头。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   而自己的人生却过得一塌糊涂、满地鸡毛。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你要说他们不勤奋吧，他们其实蛮勤奋的，吃苦耐劳、任劳任怨，但为什么就是没能如愿过上自己想要的人生呢？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   有一个黑暗的真相是：
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   你的勤奋，正在让你变得越来越穷。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这个观点可以颠覆了很多人的认知，之前听到的都是“勤劳致富”之类的，但为什么我说的却恰恰相反？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   那你不妨回想一下你每天的真实状态。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   每天被刺耳的闹钟强制唤醒，拖着疲惫的身体去通勤、上班。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   好不容易熬到发薪日，看着手机屏幕上弹出来的那一串数字，你的多巴胺分泌了短暂的几秒钟。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   紧接着呢？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   房贷/房租扣走了一部分，车贷划走了一部分，剩下的钱刚交完水电煤气、还完为了所谓的“精致生活”而透支的花呗，你的账户又比脸还干净了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你还非常擅长安慰自己：
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; color: rgb(136, 136, 136); font-style: italic;">
   “没事，我还年轻，我还有上升空间，只要我升职加薪，一切都会好起来的。”
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但处于这种状态下的你：
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你敢生病吗？你敢随时掀桌子不干走人吗？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你不敢。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你看着社交媒体上别人动辄“年入百万”、“喜提豪车”的繁荣，内心充满了恐慌和焦虑，于是你只能更加卖力地加班，试图用战术上的勤奋，来掩盖你战略上的极度无能。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   在你眼里，你觉得这是在职场上披荆斩棘，感觉自己的能力特别大，未来可期。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但实际上，你充其量只是在一个没有尽头的仓鼠轮里狂奔。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   停下脚步的那一刻，就是你断水断粮的死期。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   为什么你明明这么拼命，却依然是个穷人？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为你的认知基础，从一开始就是被社会的顶层设计者恶意
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   篡改
  </span>
  <span style="font-size: 16px;">
   过的。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你觉得老板给你发工资，是对你劳动成果的一种
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   恩赐
  </span>
  <span style="font-size: 16px;">
   。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但实际上，你真正创造的“价值蛋糕
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   ”
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   ，早就被分割成了3块。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   第一块，被你的老板，也就是资本方叼走了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   商业的本质就是剥削剩余价值，你替公司赚了十万，老板最多给你一万，剩下的九万是他用来试错、扩张以及购买迈巴赫的资本。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   第二块，被系统收缴了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你的钱还没焐热，个人所得祱、各类保险就已经在源头把你洗劫了一遍。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   第三块，被金融寡头，也就是银行吸干了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你为了在这个城市有个
  </span>
  <a class="normal_text_link mp_article_text_link" href="https://mp.weixin.qq.com/s?__biz=MzA3Mjk5ODcwOQ==&amp;mid=2247490464&amp;idx=1&amp;sn=d7b96fce41c94f54959e14d1bd0840e8&amp;scene=21#wechat_redirect" target="_blank">
   <span style="font-size: 16px; text-decoration: underline;">
    水泥盒子
   </span>
  </a>
  <span style="font-size: 16px;">
   ，为了看起来体面一点，签下了长达30年的卖身契。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你每个月辛辛苦苦赚来的血汗钱，大半交给了银行当利息。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   大家看懂了吗？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你这本质上是在用你唯一不可再生的资源——生命和时间，
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   去滋养这三头永远喂不饱的巨兽
  </span>
  <span style="font-size: 16px;">
   。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你以为是在为自己赚钱，但实际上那点钱顶多算是“工具保养费”。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   目的是为了你这个“工具”能够正常、好使、不添乱、不造反。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   普通人最大的悲哀，是把职业当成了事业。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你问一个每天出入高档写字楼的白领：“你的事业是什么？”
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他会西装革履、无比自豪地告诉你：“我是某某大厂的高级总监。”
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   而实际上呢？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这其实是“高级包身工”罢了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你在这个大厂里打工，你是在用你的肝脏和脑细胞，去构建大厂老板的商业帝国。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你拥有这家公司吗？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这家公司的底层代码是你写的吗？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   如果明天老板把你扫地出门，你的“事业”还在吗？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <br />
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   学校，这个世界上最大的驯化场，它教会了你怎么做一个温顺的员工，怎么做一个流水线上的合格螺丝钉。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   它教你会计、教你法律、教你编程，但它唯独不教你这世界最核心的技能——
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   如何搞钱，如何建立属于自己的收入渠道。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   难道“规则设计者”们不知道这件事吗？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   当然知道，但就是不想告诉你罢了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   因为如果你们羊群都觉醒了，我狼吃什么？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   在这个世界上，只有两条路。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   一条是绝大多数穷人走的路：出卖时间换取生存资料。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这条路看似安全、体面，实则天花板极低，且毫无抗风险能力。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你的时间是绝对有限的，哪怕你把自己劈成八瓣，一天也只有24小时。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   只要你的收入必须依赖你的“肉身在场”，你就是被绑在火药桶上的蚂蚁。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   另一条路，是那些站在食物链顶端的高手走的路：
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   构建资产，让钱为你24小时不间断地繁衍。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   那么，房子是资产吗？车子是资产吗？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   其实判断一个东西是资产还是负债，有一个很简单的标准：
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   它是不是在你不干活的时候，还能帮你赚到钱？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你想想，你贷款买的自住房，每个月都在抽干你的现金流，这本质上就是你的负债。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你为了装点门面分期买的豪车、名表，买到手的那一瞬间就在疯狂贬值，每年还要交各种各样的保险、各种祱、各种费。本质上也是负债。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   真正的资产，一定是你在呼呼大睡、在度假时，依然在为你产生利润的系统。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   打工，是主动且上限极低的单次博弈；
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   而构建资产，是前期痛苦但后期拥有无限复利的高维碾压。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   大多数人宁愿在熟悉的粪坑里吃屎，也不愿在未知的旷野里去拼搏，这就是为什么穷人永远是穷人的根本原因。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们害怕风险，殊不知，把自己的命运完全交给一个随时可能倒闭的公司或者系统，才是这个世界上最大的风险。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   话说到这个份上，有些情绪上头的韭菜可能已经准备明天去把老板的桌子掀了，高喊着“我要创业，我要建立资产！”去拥抱星辰大海了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   如果你真这么干了，那我只能说，你不仅穷，还蠢得无可救药。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   冲动，是弱者加速灭亡的催化剂。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   商业世界不是童话，它的淘汰率非常高。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   90%的新公司会在前几年死得连渣都不剩，剩下的哪怕活下来了，绝大多数也会在接下来的几年内灰飞烟灭。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   没有资本、没有认知、没有手腕，你凭什么去跟那些在商海里厮杀多年的老狐狸抢食？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   流半仙说过，真正厉害的人都是
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   雌雄同体
  </span>
  <span style="font-size: 16px;">
   的，都是极其精明的潜伏者。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们懂得破局的关键不是All in，而是
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   双轨并行，暗度陈仓
  </span>
  <span style="font-size: 16px;">
   。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   哪两轨呢？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   第一条轨：冷酷地对待你的主业，把它视为你的“血包”。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   千万不要随随便便辞职。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   生存，是第一法则。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你的那份薪水，不管多微薄，都是你在这个世界立足的粮草，是你孕育未来资产的本金池。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你应该用一种
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   绝对功利、极其厚黑的心态
  </span>
  <span style="font-size: 16px;">
   去对待你的工作：
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   公司不是你的家，老板也不是你的兄弟。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你是在利用这个平台，榨取它的资源，学习它的运转逻辑，最重要的是，拿着它发给你的工资，去养活你自己的“私军”。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   工作只是你的现金流工具，绝对不要在那些毫无意义的职场斗争中耗费你的核心精力。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   表面上你是个合格的打工人，暗地里，你要随时准备抽干它的养分来肥沃你自己的土地。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   第二条轨：开始建立自己的资产
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你的下班时间，不是用来刷无脑短视频、看泡沫剧、打游戏或者在酒桌上吹牛逼的。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你省下来的每一分钱、挤出来的每一分钟，都必须投入到资产的构建中去。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   具体，有4条铁律需要你严格执行：
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   ① 区分资产与负债
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   停止一切自欺欺人的消费主义陷阱。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   那些不能给你带来正向现金流的东西，全都是商家忽悠你接盘的负债。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   新款的电子垃圾、溢价极高的所谓潮牌，这些东西除了让你在穷人堆里获得一秒钟的虚荣心之外，毫无价值。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你真正要投资的，首当其中的就是自己的大脑。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   一个人赚不到他认知以外的钱。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你的思维认知尚处在较低的水平，现在哪怕给你一个巨大的历史机遇，你别说抓得住了，你甚至都识别不出来。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   ② 切断所有不必要的欲望
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   砍掉那些伪装成生活必需品的开支，每一块钱的结余，都是你买向自由的一张赎身契。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   穷人为什么无法翻身？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为他们总是用明天的钱，来装点今天的虚荣。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   只有狠人，才能真正领悟延迟满足的恐怖力量。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   在你的资产没有强大到足以覆盖你的奢靡生活之前，你无比要把钱花在刀刃上，砍掉所有不必要的支出。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   比如无意义的社交、最新款的电子设备、同事朋友的红白事等等。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   哪些钱是可以花的呢？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   大家可以去看这篇文章《
  </span>
  <a class="normal_text_link mp_article_text_link" href="https://mp.weixin.qq.com/s?__biz=MzA3Mjk5ODcwOQ==&amp;mid=2247485019&amp;idx=1&amp;sn=13a61d15d874296aa18d4c0e7d42971a&amp;scene=21#wechat_redirect" target="_blank">
   <span style="font-size: 16px;">
    花钱的3个黄金法则
   </span>
  </a>
  <span style="font-size: 16px;">
   》
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   ③ 让资产去为你买单，而不是透支你自己。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   很多人稍微赚了点小钱，第一反应就是去换个好车，买个名表，生怕别人不知道他脱贫了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这是典型的暴发户心理，也是重返贫穷的最快路径。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   而那些真正厉害的人是怎么干的？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们哪怕赚了钱，依然保持极度的克制。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们会把利润继续砸进资产池里，进行复利滚动。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   直到有一天，他们名下资产所产生的“被动收益”，已经多到花不完的时候，他们才会用这些“利息的利息”去买奢侈品。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你要记住，奢侈品从来不是用来装逼的工具，而是你成功建立资产后，对自己进行的一点微不足道的奖赏，仅此而已。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   ④ 不要完美主义
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   “等我有了一百万再说”、“等我看懂了这个市场再投”，这是弱者最喜欢用的理由。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但实际上，等你什么都看懂了，等你彻底准备好了，那是连口汤都不会给你剩下的。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   买不起整栋楼，你可以先租一个小办公室；
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   做不了庞大的商业系统，就先从一个个小型的变现渠道开始试水。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   哪怕你每个月只能拿出几百块钱来投资自己、去跟高手学习，你也已经超越了90%只会在原地抱怨的废柴。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   财富的裂变，往往是从最不起眼的滚雪球开始的。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   行动的粗糙，永远胜过完美的静止。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <br />
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   财务自由，从来都不是一个带有温度的词汇，它一定是一场无比血腥的自我革命。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   它不意味着你要成为亿万富翁，但它绝对意味着，当你对这个操蛋的世界竖起中指，当你决定今天绝不去那个憋屈的办公室看老板的脸色时，你的银行账户依然能源源不断地涌入足够你潇洒活下去的现金。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   通过出卖肉体和时间去换取微薄的薪水，是一条看似毫无门槛、实则极其被动的绝路——你在这条路上，永远只是别人棋盘上的一只随时可弃的卒。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我在昨天那篇《
  </span>
  <a class="normal_text_link mp_article_text_link" href="https://mp.weixin.qq.com/s?__biz=MzA3Mjk5ODcwOQ==&amp;mid=2247492819&amp;idx=1&amp;sn=9ec514403a9fd0adae3d53d34351dfa4&amp;scene=21#wechat_redirect" target="_blank">
   <span style="font-size: 16px;">
    底层死于愤怒，中层活于算计，顶层呢？
   </span>
  </a>
  <span style="font-size: 16px;">
   》也说过，你在别人所搭建的平台、规则体系下，你很难能有大的起色。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你必选开始算计、开始极度的自律去构建你的资产。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这是一条前期极其痛苦、充满撕裂感，但后期却能让你真正掌控命运的神坛之路——
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   你将从棋子，蜕变为下棋的人。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以，我建议你别期待着自己的工资什么时候能涨了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你真正该问自己的是：
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   如果明天全世界所有的公司都倒闭了，你手里的那些所谓资产，能让你像个人一样活几天？
  </span>
 </span>
</p>
