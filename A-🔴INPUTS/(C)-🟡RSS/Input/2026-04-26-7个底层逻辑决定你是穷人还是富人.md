<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   绝大多数人都以为，穷人和富人的差距，是一辆保时捷和一张地铁卡的差距。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但其实还差了一个太平洋和一个北冰洋。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   为什么两个人的起点一样，但五年、十年过去，有人白手起家当上小老板，而有的人依然原地踏步，这辈子都得泡在底层发烂？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为很多人都把阶层的上升通道想得太简单。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   打个比方，你以为坐在同一个格子间，喝着同样9块9的瑞幸，骂着同一个老板，你就真以为你们是同一个阶层了吗？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   只能说，你们的起点是一样的，但如果别人每一步都是使尽浑身力气，而你每一步都绵软无力，那么你们之间的差距只会越来越大。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   那么在生活中，哪些细节可以体现两种思维的差异呢？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   比如，很多人为了点个外卖省5块钱配送费，能在三个APP之间来回切20分钟，算优惠券组合比特么考研还认真；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   为了省下50块钱的专业咨询费，你在百度上硬生生翻了三天的垃圾信息，最后还做出了一个错误的决定。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   为此，蠢而不自知的你还沾沾自喜，美其名曰是“精打细算”、“会过日子”、“理性至极”。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但事实上，你的这种“理性”，是亲手杀死你未来的元凶。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你像个守财奴一样护着手里那点碎银，眼睁睁地看着真正的机会一个个从身边溜走。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   可以这么说，穷人和富人之间财富的鸿沟，都是你自己一锹一锹挖出来的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   决定你最终会成为穷鬼或富人的关键，在于以下这
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   7
  </span>
  <span style="font-size: 16px;">
   个底层逻辑：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 20px; color: rgb(171, 25, 66); font-weight: bold;">
   01
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; color: rgb(171, 25, 66); font-weight: bold;">
   拿时间换钱，还是拿钱换时间
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   查理芒格说过一句话：只要你还在用时间换钱，你就不可能真正富有。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   穷人把钱当命，把时间当屎。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你宁愿坐四个小时的绿皮火车，也不肯多花两百块买张高铁票，你以为你省了钱，其实你贱卖了自己。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我一个朋友是做电商的，他刚开始开店的时候，根本赚不到多少钱，利润少得可怜。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但他依然舍得花钱买采购工具、付费学习运营课程，还专门找人帮忙打包发货。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   道理很简单，因为他不想把时间耗在打包、回复客服这些杂事上。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   而是把琐事全部外包，一门心思钻研选品、做流量、维护客户这些真正核心的事情上。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   就短短半年时间，原本不起眼的小网店，直接做成了小众爆款店铺，营收一路暴涨。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   还有个
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   短视频
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   博主也是，早期的时候自己拍自己剪，每天要花四五个小时耗在拍摄、剪辑、字幕、封面琐事上。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   刚有点微薄收入，就立马花钱外包剪辑和运营。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   原因也是她选择把这些低效杂活给外包出去，把全部的时间放在打磨脚本、拆解爆款逻辑、深耕选题上。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   后面账号很快就起量了，一条商单就是很多普通人一个月的工资。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你连别人的时间都不敢买，你就活该一辈子给别人当牛做马。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   还有，你用打折的价格贱卖你的生命，你可别指望着有一天能按原价把光阴赎回来。
  </span>
 </span>
</section>
