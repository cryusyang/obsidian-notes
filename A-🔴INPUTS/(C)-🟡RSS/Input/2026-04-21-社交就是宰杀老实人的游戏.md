<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   1、社交就是宰杀老实人的游戏
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   老实人在社交中为什么总是吃亏？因为他们根本没有意识到一个残酷的真相：社交就是对老实人的宰杀。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   人与人之间的交往，就是一次次争夺主导权的博弈。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   一旦你在社交生活中给别人留下了“老实”的印象，那么你必然会因为你的老实而屡屡遭受别人的利用和伤害。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   最要命的是，你还很难维护自己的正当权益，因为话语权都在强势的人手里。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   2、对工作祛魅、对领导祛魅、对世界祛魅。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   打工千万不能入戏太深。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   打工的唯一目的是偷师出道，其本质就是拿钱办事。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   所以，不要恋战，你工作的目的不是为了养老，而是为了在获得资源并熟悉脉络之后，升职或跳槽。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   你上班只是为下一步晋升做准备，不要在同事和上级的赞赏中迷失了自我，只有浑噩噩的庸人才以摸鱼为荣。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   3、这个社会，讲的其实只有两样东西，一是实力，二是利益，没有这两者，其他一切意义都不大。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   如果你有足够的实力，你可以一力降十会，根本不用投机取巧；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   如果你能提供足够的利益，不用任何花言巧语，也会让人对你服服贴贴。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   4、这个世界的一切人际关系，本质都是价值交换。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   价值交换，不单单是物质上的，还有生理需求、情绪需求、利益需求。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   在社交过程中，人们通过分享各自拥有的有价值的信息、资源和智慧，来获取自己所需的资源，从而实现互利共赢，这就是现实。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   5、人与人之间的交往，都有一个界限感。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   这才是把握两个人能说什么、能做什么的关键。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   你和亲近的人可以什么玩笑都开，但是和不熟的人这么开玩笑可能就不礼貌。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   很多人口无遮拦的毛病，就是因为他们没有这个概念。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   6、生活是自己的，与他人无关，如果快乐分享错了人，就成了显摆，招人嫉妒，如果感慨分享错了人，就成为了矫情，会成为了笑话。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   7、不要炫耀自己的本事，不管你有什么过人之处，人们往往只敬重谦虚的人，对显摆鄙夷。这里边也涉及了一些妒忌心理。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   8、学会在很多场合保持沉默，这不代表会被别人忽视，相反，你开了口，暴露了实力，反而让那些高段位的人，直接选择了忽视你。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   所以，沉默本身是对弱者的一种保护。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   9、世界上最可怕的不是鬼，而是人性的丑陋。看清这一点，才能避免被伤害。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   10、永远不要让跟你接触的任何人，免费从你这里得到任何东西。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   这个是人性，越是免费的东西越不被珍惜。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px; text-indent: 0px;">
 <span>
  <span style="font-size: 16px;">
   为什么会上演东郭先生和狼以及农夫和蛇的故事，你是东郭先生还是农夫，你是不是觉得不让对方付出就叫善良，我告诉你，吃不透人性的人，最后都会踩很多坑。
  </span>
 </span>
</section>
