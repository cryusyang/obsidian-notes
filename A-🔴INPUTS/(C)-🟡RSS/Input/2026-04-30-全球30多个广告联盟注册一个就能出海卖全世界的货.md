   发出来以后，很多人问了同一个问题：返利平台的钱从哪来的？
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>

  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   返利网是终端，广告联盟才是源头。返利网从联盟拿佣金，抽一层以后分给用户。你直接接联盟，中间商那层利润全是你的。
  </span>
 </p>

  <span>
   今天把全球主流广告联盟全部扒出来，和昨天的返利网数据库配套使用。
  </span>
 </p>
 <h2 style="display: table; padding: 0px 0.2em; margin: 4em auto 2em; color: rgb(255, 255, 255); background: rgb(15, 76, 129); font-size: 19.2px; font-weight: bold; text-align: center;">
  <span>
   什么是广告联盟
  </span>
 </h2>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   如果你做过直播带货，你一定知道MCN。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   你想在
  </span>
  <span>
   直播平台，比如视频号
  </span>
  <span>
   上帮品牌卖货，你不会直接找Nike谈合作。你通过MCN机构，MCN里面有几千个品牌的推广计划，你挑一个适合你的，拿到专属链接，卖出去了MCN给你结佣金。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   广告联盟就是海外版的MCN。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   区别在于，国内的MCN不透明。佣金多少、结算周期、扣不扣量，全看MCN心情。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: rgb(63, 63, 63);">
  <span>
   国外的广告联盟是完全透明的。佣金比例公开标在那里，点击和转化数据实时可查，结算周期写在合同里，到日子直接打款。没有中间人吃差价，没有"运营经理"帮你对接，你自己注册，自己选品，自己拿链接，自己收钱。
  </span>
 </p>
 <section style="text-align: center;">
  <img src="https://mmbiz.qpic.cn/sz_mmbiz_png/ibQqpoickzFczeU1ooV4DJ8u7MDltsgbhttOKCtjiaxuyrb7R2z5icfsgnmpkvADnszjqkgJoicdoMg5xicyBDHE64b4I5VCtFMa6INBf220Uh2As/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=0" style="width: 680px !important; height: auto !important;" />
 </section>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   这就是为什么做海外affiliate比国内带货舒服。规则透明，数据真实，佣金直达。
  </span>
 </p>
 <h2 style="display: table; padding: 0 0.2em; margin: 4em auto 2em; color: #fff; font-size: 19.2px; font-weight: bold; text-align: center;">
  <span>
   目前最火的玩法：品牌词套利
  </span>
 </h2>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   说到广告联盟就不得不提一个目前最火爆的变现方式：Brand Bid，谷歌套利的一种玩法，友商们培训得比较多。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   原理很简单。用户在Google搜"品牌名+优惠券"或者"品牌名+discount"，你买这个关键词的广告，用户点进来，通过你的affiliate链接完成购买，你赚佣金。广告费可能花了5美金，但佣金赚了50美金。中间差45美金就是你的利润。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   这个模式跑通以后可以无限复制。一个品牌词赚钱了，加十个。十个品牌词赚钱了，加一百个。全部自动化投放，规模化套利。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   但这里有一个巨大的坑：很多广告主明确禁止你用Brand Bid的方式推广。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   你在CJ Affiliate上申请了某个品牌的推广计划，兴高采烈地去Google投了品牌词广告，跑了一周赚了不少佣金。然后突然收到一封邮件：你的账号被封了，佣金全部冻结，理由是违反了广告主的推广政策。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   这种事情每天都在发生。不是你的方法有问题，是你不在广告主的白名单里。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   我们做培训最大的区别就是这个。我们跟广告主有直接的合作关系，参加我们培训的学员都是走白名单通道。同样的品牌词套利，别人做被封号，我们的学员做了顺利收到钱。方法一样，通道不一样，结果完全不一样。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   这不是技术问题，是资源问题。
  </span>
 </p>
 <h2 style="display: table; padding: 0 0.2em; margin: 4em auto 2em; color: #fff; font-size: 19.2px; font-weight: bold; text-align: center;">
  <span>
   怎么选联盟
  </span>
 </h2>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   联盟分四种，适合不同的人。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <strong style="color: #0F4C81; font-weight: bold; font-size: inherit;">
   <span>
    综合巨头
   </span>
  </strong>
  <span>
   ：什么品类都有，从鞋到酒店到软件，适合刚入门不知道推什么的人。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <strong style="color: #0F4C81; font-weight: bold; font-size: inherit;">
   <span>
    数字产品联盟
   </span>
  </strong>
  <span>
   ：卖课程、电子书、软件，佣金率极高，最高75%。一单赚几百美金很正常。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <strong style="color: #0F4C81; font-weight: bold; font-size: inherit;">
   <span>
    SaaS/B2B联盟
   </span>
  </strong>
  <span>
   ：专门推软件工具，很多是递归佣金，用户每月续费你每月都赚。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <strong style="color: #0F4C81; font-weight: bold; font-size: inherit;">
   <span>
    区域性联盟
   </span>
  </strong>
  <span>
   ：专注某个地区的市场，比如北欧、法国、荷兰、俄语区、亚太。做小语种市场的首选。
  </span>
 </p>
