<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   1、越穷的人，越不能靠自己。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   穷人要是能靠自己，早就发达了，何必等到今天。时至今日还没发达，说明自己最靠不住。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   成功靠别人，靠父母，靠再生父母，靠老婆，靠老板，靠合伙人。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你的出身决定了你的起点，你和谁同行，决定了你的终点。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   好风凭借力，送我上青云。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   人，自己可以不强大，但一定要学会借力，万物不为我所有，但万物皆可为我所用。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   不要在低纬度的勤奋上自我感动，过渡依赖“自我奋斗”的人，往往只会把自己囿于一方天地，错过了很多改变命运的机会，结局只会是把自己累出一身毛病还困在贫困之中。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   2、用时间和生命换来的钱，根本就没有没有任何意义。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   应该思考的是，用你的思维和能力来换钱。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   太着急赚钱的人，越是赚不到，反而会把自己搞废掉。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   3、不要把人际关系看得太重。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   其实没有朋友，你也能过得很好，而那些把人际关系看得太重的人，都是内心缺乏安全感的人，渴望通过所谓的人际关系填补自己的空虚。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   其实，当你自己的实力强大起来的时候，人际关系自然会变好，良好的人际关系不是经营得来的，而是实力碾压获得的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   4、有很多大运都是晚发的，如果现在没有那么钱也不用着急。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   一般晚发的人，基本都是三十五岁以后，或最早也要三十岁开始有苗头。所以发财不着急，晚发的人更能压得住。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   5、人一定要对搞钱有极高的热情。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你不理财，财不理你，财富喜欢优秀的人，喜欢漂亮的人，喜欢积极的人，喜欢喜欢它的人。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你要在搞钱的路上大胆的去尝试。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   即使没有很快拿到结果，也学到了很多经验，打开了思维，找到了方法。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   舍得花钱提升自己钱要花在最正确的地方，你得有本事，有口才，有素养，有实力，有手段，有好人品。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你要学的东西很多，你要树立好自己的形象。让自己变得强大，值钱，然后走出夫链接优秀的圈子。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   6、这个世界的一切人际关系，本质都是价值交换。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   价值交换，不单单是物质上的，还有生理需求、情绪需求、利益需求。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   在社交过程中，人们通过分享各自拥有的有价值的信息、资源和智慧，来获取自己所需的资源，从而实现互利共赢，这就是现实。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   7、道德准则，是专门为穷人制定的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   越是贫穷的人越喜欢遵守和谈论道德。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所谓马无夜草不肥，人无横财不富，大部分富人赚到的第一桶金都是灰色的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   想要致富，首先就得摆脱道德准则的约束。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   规则一直都是强者制定的，而相对的弱者在规则内相互竞争。
  </span>
 </span>
</section>
