<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   人类的互相吸引，抛开文明层面的外衣，
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   从基因层面来看，本质上就是一堆廉价、随时可能发情的生物电流。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   如果你不想在两性关系里过多消耗你的心力，那么你必须要看懂人的这套
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   吸引代码
  </span>
  <span style="font-size: 16px;">
   。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   相信很多人在学生时代都会发现这么一种现象：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   女生总是更容易对体育生这个群体“动心”。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   那些体育生普遍身材矫健、样貌俊朗，非常具有阳刚之气。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但在表皮之下，他或许是一个满嘴跑火车、毫无内在的莽夫，但这丝毫不影响女生们对他们的
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   喜欢
  </span>
  <span style="font-size: 16px;">
   。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   而别的虽然在外貌上不具备这种优势，但在其他方面有特长的男生就觉得很不理解：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; color: rgb(136, 136, 136); font-style: italic;">
   “为什么女生会喜欢那种垃圾呢？”
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   流半仙要告诉你，“喜欢”并不是一个多么神圣的词。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   实际情况还恰恰相反：
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   在人性里，“喜欢”是一个非常贱的东西。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   它廉价、短视、毫无意义，且极度容易被操纵。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   女人之所以天然会对那种身材矫健的男人“动心”，那都是刻在基因里的本能反应，这个行为并不是大脑理性思考后的选择。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你想想，在远古时期，雌性为什么要选择这种雄性呢？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   很简单，因为强壮的雄性更容易捕到猎物，从而能够给自己和孩子足够的食物和庇护。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   那些基因里天然就喜欢强壮雄性的雌性都因此而活了下来，所以我们今天的雌性，几乎都是天生喜欢就强壮雄性的生物。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但人类文明进化得太快了，几百万年前强壮的雄性或许是决定性的优势，但放在现代人类文明，强化的外在只能算是一个优点，并不直接跟这个男人在社会上获取资源的能力挂钩。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但现在的女人可不会理性思考一番后再做决定是否要喜欢一个男人，没有独立思考能力的她们，几乎只受动物脑的驱使。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这在远古时期是一种优势，但在今天，用处已经大不如从前了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   如果一个男人四肢发达，头脑简单，没有任何独立思考的能力，那么他最终的归宿就是干苦力，顶多就是比别人多搬两块砖，根本拉不开决定性优势。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以，如果你是个男人，你没能在身材外貌上让女人天然就对你产生极大的兴趣，也不要因此而灰心，那不代表你在这个时代没有竞争力。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   那些只因为你的外在而直接一票否决你的女人，也不值得你太放心上。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但有的男人则走了歪路，他们在学生时期花了大量的时间读书，根本没跟女生有过接触，导致毕业后想谈恋爱，自己不仅没有外貌上的优势，也没有能让女生喜欢的人格魅力。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们想起学生时期的体育生、看到身边那些壮汉，都能轻松获得女生的喜欢，所以就从一个极端走向另一个极端，得出结论：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; color: #888888; font-style: italic;">
   “原来读书没用，当个四肢发达的流氓才是王道。”
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   ......
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   流半仙想说，这个世界并不是非黑即白的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   从来没有哪个人，会因为一种绝对纯粹的特质就被彻底定性。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   人以及人的感情都是极其复杂的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   绝大多数人的命运轨迹，都是顺着人性的滑梯，在各种复杂因素的裹挟下，混着混着，就滑到了那个位置。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   今天被荷尔蒙支配，明天被利益诱惑，后天被危机逼迫，最后形成了一个混沌的结果。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这个世界，压根就不存在一根筋的生物。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   流半仙一直以来所传达的价值观都很明显，那就是实用主义。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我们只活这一辈子，那么我一定要想办法赢、多赢。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以说，你的任务不是去分析人性为什么这么贱，而是
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   利用这种贱，去为自己谋利。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   既然人类就是容易被直接的、粗暴的特质吸引，那你还在等什么？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   去掠夺这些特种不可以吗？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你别去鄙视那些靠身体、靠嘴皮子、靠票子吸引人的人，你要把他们的武器“抢
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   ”
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   过来，装在自己身上。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   如果你发现强壮的体魄能让女人新生喜欢，那你可以去练；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   如果你发现财富能让人对你俯首称臣，那就收起你的清高，像饿狼一样去搞钱；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   如果你发现巧言令色也能让人神魂颠倒，那你就去学如何掌控人性、如何输出情绪价值。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你要利用这股不甘心的原始冲动，把它当成燃料。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   不断打磨自己的身体和各种技能，你会发现：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   你不仅征服了别人，你还会不可救药地爱上这个强大到可怕的自己。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   还有，永远不要试图去读懂某一个特定的人，而是要去读懂
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   人性
  </span>
  <span style="font-size: 16px;">
   这个大盘。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   世界上每个人都是独一无二的，你只读一个人，换个人你什么都看不懂了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但这个世界上哪个国家、地区的人，他们的人性都是相同的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   如果你试着去读懂他们身上共通的人性，那么你将会有如神助。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   既然人性有共通之处，那么我们就需要通过广泛接触不同的人，来深入理解和运用人性。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   去见识高雅的伪善，也去体验底层的真实。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   当你见的人足够多，你就会明白：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   没有谁是坚不可摧的，也没有谁是单一维度的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   一个看似只看重外表的人，在极度虚弱时会被一点点利益收买；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   一个满口仁义道德的人，在绝对的安全屋里也会暴露出野兽的行径。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   不要用静态的眼光看人，要用动态的、多维度的眼光去审视这个系统。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你手里握着的牌越多，如比你的学识、你的手腕、你的体能、你的资产——那么你在面对任何猎物时，就越能游刃有余地戳中他们的软肋。
  </span>
 </span>
</section>
