I used commands like:</p><blockquote>cat subs.txt | waymore | tee ends00.txt<br />cat subs.txt | gauplus | tee ends01.txt<br />cat subs.txt | waybackurls | tee ends03.txt</blockquote><p>Additionally, I employed Katana, another useful project available [here](<a href="https://github.com/projectdiscovery/katana">https://github.com/projectdiscovery/katana</a>).</p><p>After removing duplicate URLs and identifying active ones, I stumbled upon an API URL that led me to sensitive information like email addresses and names.</p><p>remove duplicate urls and look for active one:</p><blockquote>cat ends* | sort | uniq | httpx | tee Aends.txt</blockquote><p>while checking the endponts that i’ve found i notice and API url was something like :https://target.com/api/settings/settings?classKey=231, i went to chrom browser and opened the urls and i’ve found the reponse containing something like :</p><p>{“useopenedge”:false,”email”:”<a href="mailto:email@victimemail.com">email@victimemail.com</a>”, “firstname”:”john” , “lastname”:”doe”, “billphonenumber”:”444–654–2544&quot;}</p><p>and when you modfiy ?classKey= you get an other user data , without any authentification ,i could’ve report it right away , but i kept looking for other urls they might disclose some other information too: <br />so using this command :</p><blockquote>cat Aends.txt | grep “/api” | tee apis.txt</blockquote><p>i find all the api paths , while opening them some share 404 and some are just text files</p><h4>Using AI to find all API json responses :</h4><p>To streamline the process, I utilized a bash script that crawled through URLs and filtered for JSON responses. Here’s the script:</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/401/1*H9-wLl6a5lCp3eWWnl4vYg.png" /></figure><blockquote>#!/bin/bash</blockquote><blockquote># Function to check if a string is valid JSON<br />is_valid_json() {<br /> echo “$1” | jq . &gt;/dev/null 2&gt;&amp;1<br />}</blockquote><blockquote># Create a file to store the results<br />touch json_results.txt</blockquote><blockquote># Loop through each URL in apis.txt<br />while IFS= read -r url; do<br /> # Send a GET request to the URL and store the response in a variable<br /> response=$(curl -s “$url”)</blockquote><blockquote># Check if the response is valid JSON<br /> if is_valid_json “$response”; then<br /> echo “URL $url has a valid JSON response:” &gt;&gt; json_results.txt<br /> echo “$response” &gt;&gt; json_results.txt<br /> else<br /> echo “URL $url does not have a valid JSON response.” &gt;&gt; json_results.txt<br /> fi<br />done &lt; apis.txt</blockquote><figure><img alt="" src="https://cdn-images-1.medium.com/max/961/1*53lmcvJPXvMjMGjXR6PwsA.png" /></figure><p>After running the script, i got all the api with a json format and I discovered more private data like full addresses and zip codes , ssn , settings configurations .</p><h4>POC Time</h4><p>I decided to create a website with a search engine where users could input a user ID and retrieve all their data.
