> [!example] AI 摘要
> 文章披露了nginx-ui工具中一个CVSS评分为9.8的高危漏洞CVE-2026-33032，根源在于/mcp_message端点缺失身份验证且IP白名单默认为空，导致攻击者无需认证即可调用12个危险MCP工具，实现Nginx服务完全控制。该漏洞已被在野利用，影响全球2689台暴露实例，主要分布在中国、美国等地。官方已在v2.3.4版本修复，通过为/mcp_message添加middleware.AuthRequired()实现强制身份验证。文章强调应立即升级或临时禁用MCP/配置有效IP白名单以缓解风险。

 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <span>
   近日，一款流行的基于Web的Nginx管理工具nginx-ui中发现了一个关键安全漏洞，并且已被在野利用。该工具在GitHub上拥有超过11K星标和43万+的Docker拉取量。漏洞
  </span>
  <code>
   <span>
    CVE-2026-33032
   </span>
  </code>
  <span>
   的CVSS得分为9.8，使攻击者能够完全控制Nginx服务器。
  </span>
 </p>
 <h2 style="padding: 12px 0px; font-size: 22px; text-align: center; font-weight: bold; color: black; line-height: 1.1em; margin: 70px 30px 30px; border: 1px solid rgb(0, 0, 0);">
  <span>
   <span>
    场景理解
   </span>
  </span>
 </h2>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <span>
   nginx-ui使用了mcp-go库中的SSE传输。以下是两个重要的端点：
  </span>
 </p>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <code>
   <span>
    GET /mcp
   </span>
  </code>
  <span>
   - 打开一个持久的SSE流。用于建立持久的Server-Sent Events连接以接收JSON-RPC响应并启动会话。
  </span>
 </p>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <code>
   <span>
    POST /mcp_message
   </span>
  </code>
  <span>
   - 用于向MCP服务器发送命令。
  </span>
 </p>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <span>
   当一个客户端发送GET请求到
  </span>
  <code>
   <span>
    /mcp
   </span>
  </code>
  <span>
   端点以打开流时，服务器会响应一个会话ID，如下所示：
  </span>
 </p>
 <pre><code><span>data: /mcp_message?sessionId=9a7f3d21-6c5e-4b8a-9d72-3f1e8c4b2a11</span><span><br /></span></code></pre>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <span>
   之后，通过POST请求调用工具到
  </span>
  <code>
   <span>
    /mcp_message
   </span>
  </code>
  <span>
   端点，并携带有效的
  </span>
  <code>
   <span>
    sessionId
   </span>
  </code>
  <span>
   ，响应通过SSE流发送回客户端。这里，nginx-ui使用
  </span>
  <code>
   <span>
    node_secret
   </span>
  </code>
  <span>
   对MCP连接进行身份验证。
  </span>
 </p>
 <p style="padding-top: 8px; padding-bottom: 8px; margin: 0px; line-height: 26px; color: black; font-size: 14px;">
  <span>
   但你现在肯定在想这有什么问题，到目前为止一切看起来都正常。我们来看看。
  </span>
 </p>
