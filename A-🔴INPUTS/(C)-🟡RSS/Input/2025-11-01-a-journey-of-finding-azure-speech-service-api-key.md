<p>Helllo everyone👋</p><p>Past few months back I’ve been hunting on one of the massive Indian payment company.</p><p>Sorry… here I can’t disclose the program name due to their policy :/</p><p>I’ve submitted few reportes to them like MySQL cred. leak.. But that report was marked as low severity as they said we are not using that credentials now :(</p><p>I decided I won’t hunt another program until I find one valid bug here.</p><p>That’s where my journey begins..</p><p>My usual recon approach is finding as many subdomain as I could find here I used subfinder, Amass, findomain etc.</p><p>Then run httpx to find out alive domain.</p><p>Here the catch was when I visited one of the subdomain there was nothing like it was blank simple page. Below is the POC.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*RwSG_hQgWTRYcjxgweKmdA.png" /></figure><p>Here what most people do is skip this domain or fuzz.</p><p>I also tried fuzzing the domain but got nothing.</p><p>After that I started gathering all the js file I could find about this subdomain. You can use katana tool for that.</p><p>That’s where I found hidden treasure.</p><a href="https://medium.com/media/7a7b05ef958c750c18bc9771230ebe52/href">https://medium.com/media/7a7b05ef958c750c18bc9771230ebe52/href</a><p>Here treasure was <strong>Azure Speech Service API key.</strong></p><p>Well… what the hell is Azure Speech Service API key?</p><p><strong>According to google:</strong> An Azure Speech Service API key is a credential used to authenticate requests made to the Azure Speech Service. This service is part of Azure AI services and provides capabilities such as speech-to-text, text-to-speech, and speech translation.</p><p>So… you got it right?</p><p>Now lets time to exploit..</p><p>I did little bit research like how can I exploit this API key? As an attacker perspective how can I use for my own good?</p><p>Didn’t find that much.</p><p>Now I asked the some questions to our friend chatgpt. And guuess what!!</p><p>That time it gave me command to verify the key whether it was valid or not. Below you can find that command.</p><pre>curl -X POST &quot;https://centralindia.tts.speech.microsoft.com/cognitiveservices/v1&quot; \ -H &quot;Ocp-Apim-Subscription-Key: Your_key&quot; \ -H &quot;Content-Type: application/ssml+xml&quot; \ -H &quot;X-Microsoft-OutputFormat: audio-16khz-32kbitrate-mono-mp3&quot; \ -H &quot;User-Agent: curl&quot; \ --data-binary @&lt;(cat &lt; Hello, this is a test of the speech service API. EOF ) --output output.mp3</pre><p>What above key will do is when you have valid key so just type whatever you want to hear. It will give result in mp3 file.</p><p>Impact?</p><p>If this key falls into the wrong hands, it could lead to direct financial loss for the business, as increased unauthorized API usage would result in higher operational costs.</p><p>Time to report.</p><a href="https://medium.com/media/5509a36d39eb75a061838163f867c08d/href">https://medium.com/media/5509a36d39eb75a061838163f867c08d/href</a><p>Immidiatly I reported to the seucrity team and within few days they fixed and awarded me with ₹₹₹₹₹ 😁😁</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*zvLnTpZgRsm4PP4i6u0zUQ.png" /></figure><p>If you learned something from my blog don’t forget to hit clap button until system says stop.</p><p>Thank you for reading ❤️.
