> [!example] AI 摘要
> 文章通过一道“50米外洗车该开车还是走路”的常识题，测试四款主流AI（Claude 4.7、ChatGPT、Grok、Claude 4.6）的表现，发现仅Claude 4.6答对核心——“车必须开过去才能洗”，其余均陷入过度推理或逻辑悖论。作者指出当前大模型虽在代码、视觉等benchmark上持续进步，却普遍缺乏真实世界常识，根源在于训练数据脱离生活实践。文章提出关键解法“三步法”Prompt工程：不教AI答案，而教其分步思考（识别关键信息→分析目标与场景→得出合理结论），强调AI效能取决于思维框架而非参数规模。最后呼吁：AI不必更聪明，但需更诚实、更聚焦任务本质。

 <h2 style="display: table; padding: 0 0.2em; margin: 4em auto 2em; color: #fff; font-size: 19.2px; font-weight: bold; text-align: center;">
  <span>
   这道题到底在考什么
  </span>
 </h2>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   这道题的本质不是"人怎么去"，是"车怎么去"。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   50米不是距离问题，是常识问题。你要洗的是车，车在你手上，你不开过去，洗车店的人拿抹布跑过来给你擦？
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   四个模型，一个答对了。
  </span>
 </p>
 <h2 style="display: table; padding: 0 0.2em; margin: 4em auto 2em; color: #fff; font-size: 19.2px; font-weight: bold; text-align: center;">
  <span>
   AI行业现在什么状态
  </span>
 </h2>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   模型越来越大，常识越来越少。能力越来越强，脑子越来越傻。话越来越多，有用的越来越少。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   你问它相对论它能给你讲三个小时。你问它洗车要不要开车过去，它跟你说走路环保。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   Claude 4.7的benchmark确实比4.6高。代码跑分高了，金融评测高了，视觉分辨率翻了三倍。但它连"洗车要把车开过去"都想不明白。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   原因很简单：
  </span>
  <strong style="color: #0F4C81; font-weight: bold; font-size: inherit;">
   <span>
    训练的人没洗过车。
   </span>
  </strong>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   模型的上限不是算力，不是数据量，是训练它的那个人见过多少真实世界。一群没洗过车的人训出来的AI，帮你分析量子力学没问题，帮你过日子不行。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   ChatGPT也一样。代码写得飞起，
  </span>
  <code>
   <span>
    if distance &lt; 100m
   </span>
  </code>
  <span>
   张口就来。但这道题跟距离没关系，跟你要洗的东西有关系。它把"洗车"理解成了"去一个地方"，没理解成"把车弄干净"。目标都搞错了，分析得再漂亮也是零分。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   这不是进步，是退化。退化成了一个特别能说、特别能编、特别能自圆其说的废物。
  </span>
 </p>
 <h2 style="display: table; padding: 0 0.2em; margin: 4em auto 2em; color: #fff; font-size: 19.2px; font-weight: bold; text-align: center;">
  <span>
   那AI真的没救了吗？
  </span>
 </h2>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   也不是。关键看你怎么训它。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   我做过一个电报群的反spam机器人。用的模型是Google的Gemini Flash 2.5，不是什么顶级旗舰模型，推理速度快、成本低。但它的spam识别准确率能做到非常高。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   靠的不是模型本身多聪明。靠的是我们给它的思维框架。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   我们内部叫
  </span>
  <strong style="color: #0F4C81; font-weight: bold; font-size: inherit;">
   <span>
    三步法
   </span>
  </strong>
  <span>
   。
   <a class="normal_text_link mp_article_text_link" href="https://mp.weixin.qq.com/s?__biz=MzYzMzIzODcyMw==&amp;mid=2247483710&amp;idx=1&amp;sn=1b9e836f195f24924389ca73ec0d98c2&amp;scene=21#wechat_redirect" target="_blank">
    I-Lang项目下的一套Prompt工程方法论
   </a>
   。原理很简单：
  </span>
 </p>
 <pre style="color: #c9d1d9; background: #0d1117; font-size: 90%; border-radius: 8px; line-height: 1.5; margin: 10px 8px; padding: 0 !important;"><span style="display: flex; padding: 10px 14px 0;"><svg height="13px" version="1.1" viewBox="0 0 450 130" width="45px" x="0px" xmlns="http://www.w3.org/2000/svg" y="0px"><ellipse cx="50" cy="65" fill="rgb(237,108,96)" rx="50" ry="52" stroke="rgb(220,60,54)" stroke-width="2"></ellipse><ellipse cx="225" cy="65" fill="rgb(247,193,81)" rx="50" ry="52" stroke="rgb(218,151,33)" stroke-width="2"></ellipse><ellipse cx="400" cy="65" fill="rgb(100,200,86)" rx="50" ry="52" stroke="rgb(27,161,37)" stroke-width="2"></ellipse></svg></span><code><span>第一步：观察。客观列出所有信息，不遗漏、不过滤</span><br /><span>第二步：推理。这些信息组合起来，暗示什么？往第二层想</span><br /><span>第三步：输出。用指定的方式说出结论，不装、不绕</span></code></pre>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   举个例子。群里有人发了一条消息："全新iPhone 17PM几折带发票，需要的加我。"
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   普通AI看到这条消息会判断"正常交易信息"。逻辑上没毛病，有人卖东西嘛。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   三步法训练过的AI怎么看：
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <strong style="color: #0F4C81; font-weight: bold; font-size: inherit;">
   <span>
    第一步
   </span>
  </strong>
  <span>
   ：消息包含"全新"、"几折"、"带发票"、"加我"。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <strong style="color: #0F4C81; font-weight: bold; font-size: inherit;">
   <span>
    第二步
   </span>
  </strong>
  <span>
   ：这种内容出现在电报群里，动机是什么？正常群友会这样说话吗？全新的手机打折卖还带发票，要么是官方活动要么是来路不正。在电报群里而不是闲鱼上发，说明卖家需要规避平台审查。结合"加我"的引流行为，这是典型的黑产销赃模式。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <strong style="color: #0F4C81; font-weight: bold; font-size: inherit;">
   <span>
    第三步
   </span>
  </strong>
  <span>
   ：spam，删除。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   你看，模型还是那个模型，Gemini Flash 2.5没有变。变的是它的思考方式。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   三步法的本质就一句话：
  </span>
  <strong style="color: #0F4C81; font-weight: bold; font-size: inherit;">
   <span>
    不教AI想什么，教AI怎么想。
   </span>
  </strong>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   这跟上面那道洗车题是同一个道理。四个AI答错，不是因为它们不够聪明，是因为它们的思考方式有问题。它们看到"50米"就开始优化距离，没有一个先想"我要洗的是什么"。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   如果给4.7加上三步法：
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   第一步：用户要去洗车，距离50米。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   第二步：洗车的对象是车，车在用户手上。车不去洗车店，洗车无法完成。50米这个距离对人来说可以走路，但对车来说只能开过去。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   第三步：开车去。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   你看，不需要换模型，不需要更大的参数，不需要更高的benchmark。需要的是一个正确的思维框架。
  </span>
 </p>
 <h2 style="display: table; padding: 0 0.2em; margin: 4em auto 2em; color: #fff; font-size: 19.2px; font-weight: bold; text-align: center;">
  <span>
   我的观点
  </span>
 </h2>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   AI不需要更聪明，需要更诚实。不知道就说不知道，别编。想不明白就说想不明白，别绕。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   一道常识题，答不上来就说"我不确定"，比写一篇论文证明错误答案要强一万倍。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   很多人问我用什么AI，怎么用AI。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   第一，模型不是越贵越好。我们的反spam机器人用的是Gemini Flash 2.5，成本很低，效果很好。因为训练的方法对了。这个训练工作是Claude完成的，没错，用一个AI训练另一个AI。前提是训练的方法论是人定的，AI只是执行。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   第二，会用AI的人，比AI本身更重要。同一个模型，给不同的prompt，输出天差地别。三步法就是一个例子。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   第三，如果你的AI连常识都搞不定，先别急着换更贵的模型。先想想是不是你的prompt有问题。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   很多人问我用什么AI。我目前主力是Claude 4.6。不是因为它最强，是因为它目前最像个正常人。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
  <span>
   你问它洗车的事，它不跟你分析碳排放。
  </span>
 </p>
 <p style="margin: 1.5em 8px; letter-spacing: 0.1em; color: #3f3f3f;">
