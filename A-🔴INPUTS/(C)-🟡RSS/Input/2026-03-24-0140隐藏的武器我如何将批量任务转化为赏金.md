<h3 style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  📖 什么是批量分配？
 </span>
</h3>
<h3 style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  <br />
 </span>
</h3>
<p style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  在现代 Web 开发中，框架（如 Ruby on Rails、Spring 或 NodeJS）试图通过自动将传入的 HTTP 请求数据（如 JSON 或表单参数）直接绑定到内部数据库对象来简化开发人员的工作。
 </span>
</p>
<p style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  <br />
 </span>
</p>
<p style="margin-bottom: 0px; margin-top: 0px;">
 <strong>
  <span>
   <span style="font-weight: bold;">
    批量赋值
   </span>
  </span>
 </strong>
 <span>
  是指开发者允许用户更新对象，而没有明确定义
 </span>
 <strong>
  <em>
   <span>
    哪些
   </span>
  </em>
  <span>
   字段可以
  </span>
 </strong>
 <span>
  更新。如果数据库表包含
  <span style="font-weight: bold;">
   role
  </span>
 </span>
 <span>
  <span style="font-weight: bold;">
  </span>
  或
  <span style="font-weight: bold;">
   is_admin
  </span>
 </span>
 <span>
  <span style="font-weight: bold;">
  </span>
  列，且开发者没有进行过滤，攻击者只需在 JSON 请求体中传递
  <span style="font-weight: bold;">
   "role":"admin"
  </span>
 </span>
 <span>
  ，框架就会盲目地将其赋值。
 </span>
</p>

 <span>
  <br />

<p style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  这个目标有点棘手。该应用只允许用户通过
 </span>
 <strong>
  <span>
   OAuth
  </span>
 </strong>
 <span>
  （Google/Apple）登录。因此，你在应用中的
 </span>
 <strong>
  <span>
   个人资料名称
  </span>
 </strong>
 <span>
  与你的 OAuth 用户名完全绑定，
 </span>
 <strong>
  <span>
   无法在用户界面中更改
  </span>
 </strong>
 <span>
  。
 </span>
</p>
<p style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  <br />
 </span>
</p>
<p style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  该应用有一个
 </span>
 <strong>
  <span>
   “邀请”功能
  </span>
 </strong>
 <span>
  ，用户可以发送电子邮件和自定义消息来邀请好友。我测试了消息字段的 HTML 注入漏洞，希望能让
 </span>
 <code>
  <span>
   &lt;a&gt;
  </span>
 </code>
 <span>
  标签出现在受害者的电子邮件中。邮件
 </span>
 <strong>
  <span>
   内容已正确过滤
  </span>
 </strong>
 <span>
  。
 </span>
</p>
<p style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  <br />
 </span>
</p>
<figure>
 <p style="margin-bottom: 0px; margin-top: 0px; text-align: center;">

   </span>
  
 </p>

<p style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  <br />
 </span>
</p>
<p style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  我靠在椅背上想：
 </span>
 <em>
  <span>
   如果我
  </span>
 </em>
 <strong>
  <em>
   <span>
    改个名字
   </span>
  </em>
 </strong>
 <em>
  <span>
   ，然后把 HTML 代码注入进去呢？邮件发送时，会显示“[我的名字]邀请”，然后代码就会触发！
  </span>
 </em>
</p>
<p style="margin-bottom: 0px; margin-top: 0px;">
 <em>
  <span>
   <br />
  </span>
 </em>
</p>
<p style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  我进入
 </span>
 <strong>
  <span>
   “设置/帐户”页面
  </span>
 </strong>
 <span>
  ，拦截了后台请求。我发现了一个用于更新次要帐户设置的
 </span>
 <strong>
  <span>
   PUT 请求
  </span>
 </strong>
 <span>
  ：
 </span>
</p>
<section>
 <ul class="code-snippet__line-index code-snippet__js">
  <li>
  </li>
 </ul>
 <pre class="code-snippet__js"><code><span>PUT /api/users/current</span></code></pre>
</section>
<p style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  由于没有用户界面选项可以更改我的名字，我只好采用之前的方法。我使用 Param Miner 和我的 GAP 字典对这个 PUT 请求的 JSON 主体
 </span>
 <strong>
  <span>
   进行了模糊测试
  </span>
 </strong>
 <span>
  。
 </span>
</p>
<p style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  <br />
 </span>
</p>
<p style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  Param Miner 标记了一个
 </span>
 <strong>
  <span>
   <span style="font-weight: bold;">
    隐藏参数
   </span>
  </span>
 </strong>
 <span>
  ：
 </span>
 <code>
  <span>
   name
  </span>
 </code>
 <span>
  。
 </span>
</p>
<p style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  <br />
 </span>
</p>
<p style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  我拦截了该请求并注入了我的有效载荷：
 </span>
</p>
<section>
 <ul class="code-snippet__line-index code-snippet__js">
  <li>
  </li>
  <li>
  </li>
  <li>
  </li>
  <li>
  </li>
  <li>
  </li>
  <li>
  </li>
  <li>
  </li>
  <li>
  </li>
 </ul>
 <pre class="code-snippet__js"><code><span><span>PUT</span> <span>/api/</span>users<span>/</span>current</span></code><code><span><span>Host</span>: exmple.com</span></code><code><span><span>Content</span><span>-</span><span>Type</span>: application<span>/</span>json</span></code><code><span>{</span></code><code><span>  <span>"name"</span>: <span>"&lt;a href=</span><span><span>\"</span></span><span>evil.com</span><span><span>\"</span></span><span>&gt;click here to join&lt;/a&gt;"</span>,</span></code><code><span><span>...</span></span></code><code><span>  other_setting</span></code><code><span>}</span></code></pre>
</section>
<p style="margin-bottom: 0px; margin-top: 0px;">
 <span>
  令我惊讶的是，服务器竟然接受了！由于开发者未能过滤允许更新的字段，批量赋值功能让我得以覆盖我受 OAuth 保护的用户名。当我发送邀请邮件时，
 </span>
 <strong>
  <span>
   HTML 注入
  </span>
 </strong>
 <span>
  完美地在
 </span>
 <strong>
  <span>
   受害者的收件箱
  </span>
 </strong>
 <span>
  中执行完毕。
 </span>
</p>
