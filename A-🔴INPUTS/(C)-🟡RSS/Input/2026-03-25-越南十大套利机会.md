   他说去赚毛穷人钱，要赚有钱人的钱，你看日本的551包子都卖10元/个。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   好吧，这就是典型的两种出海思路。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   我6月份应该也去漂亮国，但不是为了工作，是纯粹陪女儿去看世界杯，我这个女儿天生爱看各种比赛。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   说回章鱼哥出海。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   我在
  </span>
  <a class="normal_text_link mp_article_text_link" href="https://mp.weixin.qq.com/s?__biz=MzI1NDkxNDg3OQ==&amp;mid=2247509971&amp;idx=1&amp;sn=1c2de0b840dd6603abc57baf0cd5fcfb&amp;scene=21#wechat_redirect" target="_blank">
   <span style="font-size: 16px;">
    为何是越南？
   </span>
  </a>
  <span style="font-size: 16px;">
   提到了一些理由，但很多隐性的还没说，今天隐晦的一下，懂得都懂。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   1、人家至少不是局域网，即你在越南，可以完全不受限制的使用所有网站，tiktok、X、ins就不用说了，open claw也是不用翻墙就可以访问，这才是真正与世界接轨；
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   2、越南，可能是最拥抱数字货币支付的国家，现在很多地方，都可以用数字货币进行支付购买生活用品了，法币和U可以自由切换，这也是一种对未来的拥抱；
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   3、因为越南盾每年都贬值，但也造成了他们的存款利率很高，好多银行已经到了8%的年化，其证券业及金融业正处于发展的初期，有很多“机会”；
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   4、当地的快消品还处于草莽期，基本上还是宝洁、联合利华的天下，本土品牌几乎没有，这也是很大的机会，更不用说什么零食饮料了，当地有“农夫山泉”或“娃哈哈”的战略机会；
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   5、咖啡馆当地遍地都是，但奶茶店还有大量的机会，这是一个和韩国一样，极度对咖啡因、茶多酚上瘾的国度，奶茶品牌在中国没啥机会了，但越南有，或者中国奶茶供应链出海，赋能当地奶茶品牌，也是一个战略级的机会；
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   6、餐饮连锁更不用说了，很多餐饮品牌把重心放在了漂亮国和新加坡、印尼，对越南重视程度不够，恰恰留了市场空白，注意，中国餐饮品牌出海一定本土化、越南化；
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   7、一个魅KTV的越南代理商说他们生意特别好，很奇怪一个类似多年前东莞的一个娱乐市场，绿色KTV竟然也受欢迎，只能用一个原因解释，那就是越南年轻人真的和成都长沙年轻人一样是典型的消费主义；
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   8、经朋友介绍，发现越南竟然也有本土的名创优品，且利润率和周转率比名创都高，而且都已经几百家店的连锁了，得去好好学习；
  </span>
 </span>
</section>
<section>
 <section>
  <section style="display: inline-block;">
   <img src="https://mmbiz.qpic.cn/sz_mmbiz_jpg/pnic2Bq38kOaL2OyNLCATUbArDsA2ANScX6Unw7B2q590pia73ya40GRI5z5YcdMoGFwVLwVMfXtuljN72IGHwEibunafZqiahic6XhadCiaib7vzk/640?wx_fmt=jpeg&amp;watermark=1&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=1" style="height: auto !important; width: 680px !important;" />

 </section>
 <span>
  <span style="font-size: 16px;">
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   9、美妆连锁beauty hut也不过几百家店，距离中国的屈臣氏，或者植物医生还差得远，这些都是机会，你想想，现在中国美妆的产品开发及直播带货已经全球领先，打造一个适合越南人的美妆，其实并不难；
  </span>
 </span>
</section>
<section>
 <section>
  <section style="display: inline-block;">
   <img src="https://mmbiz.qpic.cn/mmbiz_jpg/pnic2Bq38kOZVXHEzgicTFSP0UhN34dl6MAAAx1ZW5p5aEm9ntibqt5O0pTcmzbajhWFM40weWmYhbGZ7iaBWyoGGCMLIicib0F9ntqlEFGRRRVGE/640?wx_fmt=jpeg&amp;watermark=1&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=2" style="height: auto !important; width: 680px !important;" />
  </section>
 </section>
 <span>
  <span style="font-size: 16px;">
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   10、最最传统的，把中国的供应链输出到越南做跨境电商，已经被证明屡试不爽，且已经有无数的中国团队在越南扎根了，比起中国的卷，人家活得不要太好。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   ……
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   以上，都是我知道的一些“利好”消息，任何地方肯定也有很多利空，比如ZF的腐败等，但你查一下，人家的契约精神还是有的，且现在的年轻人也早就抛弃了各种主义，就想赚钱，属于2000年我们的蓬勃发展期。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   欲成大事，必须讲究天时地利人和。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   我以为，现在去越南就是最好的天时和地利，至于适不适合你，则需要你去了才知道，因为道听途说是没有用的。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   真正的“机会”都在现场，PPT和报告里的宏大叙事都是幻觉。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   最后，和大家同步一下4月7日越南考察团的进展：
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   目前已有8人，最多不超过18人，5天4夜，既有企业参访，也有当地ZF领导的接待，但最终要的是我们十几个人每天的商业碰撞，集思广益，我自己这次的目的是看当地金融业的机会，我们会根据参加人的具体目的来优化考察的项目，不是走马观花，而是深入沟通互动可以洽谈合作、合资、并购的那种。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   这也是我为何不单独收费，而是一次性收9.8万/年的私董会费用的原因，因为我们2026年要考察好几个国家，看不少项目和机会，是个长期主义的事，一次成功的概率太低了。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   2026年如果你真想出海，下定了决心，那可以加入我们，如果只是随便看看，走马观花，其实可以报名其它的游学团，不适合我们。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   关于此次越南行，这是我写的第二篇，也是最后一篇文章，截止报名时间是本月底，月底拉群公布具体的行程。
