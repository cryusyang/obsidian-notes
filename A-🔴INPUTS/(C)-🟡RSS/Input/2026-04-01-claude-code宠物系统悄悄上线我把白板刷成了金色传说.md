> [!example] AI 摘要
> Anthropic 在 Claude Code 中悄然上线“宠物模式”（/buddy），用户可孵化出唯一绑定账户的虚拟宠物，具备物种、外观（骨架层）、性格（灵魂层）及五大互动属性，且支持闪光稀有变体。  
因源码泄露暴露设计细节，该功能实为精心策划的愚人节彩蛋，并巧妙衔接复活节主题。  
技术爱好者发现可通过篡改本地配置中的 userID 绕过账户绑定机制，配合暴力枚举脚本实现“重roll”理想宠物（如传说级闪光卡皮巴拉）。  
文章强调 Anthropic 将游戏化思维融入开发工具，以无实际功能但充满趣味与情感共鸣的设计，体现其独特的产品哲学与人文温度。

   然后他就给了我一段流程，我感觉有点不对，我就把帖子截图就发给了Claude Code。
  </span>
 </span>
</p>
<section style="text-align: center; margin-left: 8px; margin-right: 8px;">
 <img src="https://mmbiz.qpic.cn/mmbiz_png/2jjfQoZLoqXaoG8VsGKSzYly2QfHLM04HRS4r7FJ0ned9NP4R1ZPyxjI4ibV9pGu96n2HMXKMCkQLbPbmKU1jhfGibugzxDdcCNB9ZxOv3vhw/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=14" style="height: auto !important; width: 664px !important;" />
</section>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   它告诉我，直接告诉他，你想要什么就行了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我就超级大声的来了一句：
  </span>
 </span>
</p>
<section style="text-align: center; margin-left: 8px; margin-right: 8px;">
 <img src="https://mmbiz.qpic.cn/sz_mmbiz_png/2jjfQoZLoqWFgg7PBj6fPgxONnunrrFibkrlgHvLm0rsjWr2iaYTrC1cVvo2Lh5Y06EAGlic9en7j0SmEDYIWxuLX4Bgg2e21z2YUTliacKiaHQ8/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=15" style="width: 664px !important; height: auto !important;" />
</section>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我要传说闪光卡皮巴拉！！！
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   然后，Claude Code直接开干了。
  </span>
 </span>
</p>
<section style="text-align: center; margin-left: 8px; margin-right: 8px;">
 <img src="https://mmbiz.qpic.cn/sz_mmbiz_png/2jjfQoZLoqWeSNh0gmfwY6O3Tb280JEEVyDTqiaIyu4G3Bm1yCYw2d2cpRqb4fRib9pX0icPTTVWh8Mt3NtZicr0KicCXBZYMlUmnnVbR21HUlWM/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=16" style="height: auto !important; width: 664px !important;" />
</section>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   然后我token还粘错了，瞎特么给了一个URL链接。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   Claude Code说，这个Token也不是必须的，有更方便的方式能跳过，于是，自己就给自己改了。
  </span>
 </span>
</p>
<section style="text-align: center; margin-left: 8px; margin-right: 8px;">
 <img src="https://mmbiz.qpic.cn/mmbiz_png/2jjfQoZLoqVEiapzCuQxP8TrFnWQlZn97JcicLNrtOK6Fnczr4nGBdic4zbWsdgibOASSDFBsTtHe4tkwlyeGErRxlwliaxMgSyHXgoNLbbWFu4w/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=17" style="height: auto !important; width: 664px !important;" />
</section>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   然后就让我重启，重启完，我重新打开Claude Code，输入/buddy，我的金色传说闪光卡皮巴拉。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   就直接出现了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我后面又翻了下帖子，其实原理也挺简单的，因为UserID是唯一的随机值，所以。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <b>
  <span>
   <span style="font-size: 16px;">
    改 userID = 改宠物。
   </span>
  </span>
 </b>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为我是Claude Max会员，在正常官方登录流程中，Claude Code会把你的
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   accountUuid
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   （Anthropic 账户唯一标识）写入
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   ~/.claude.json
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   。
  </span>
 </span>
 <span>
  <br />
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   /buddy
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   命令优先使用
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   accountUuid，作为种子，这个值绑定你的账户，无法伪造。
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <b>
  <span>
   <span style="font-size: 16px;">
    但这哥们发现了一个非常骚的逻辑漏洞。
   </span>
  </span>
 </b>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <b>
  <span>
   <span style="font-size: 16px;">
    用 CLAUDE_CODE_OAUTH_TOKEN 这个环境变量登录的时候，Claude Code 不会把 accountUuid 写进 ~/.claude.json。
   </span>
  </span>
 </b>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   没有 accountUuid，/buddy 就会退而求其次，去读 ~/.claude.json里的userID字段。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   而userID这个字段，你可以随便改。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你敢信？？？
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   先用 claude setup-token 搞到OAuth token，然后把 ~/.claude.json删了，清掉旧的accountUuid。再写一个最精简的配置文件进去，就留个 hasCompletedOnboarding和theme两个字段就够了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   然后用环境变量的方式启动 Claude Code，这一步的关键就在于，它不会往配置文件里写 accountUuid。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   接下来就是暴力美学时间了。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这哥们写的那个叫buddy-reroll.js的脚本，干的事情其实特别简单粗暴，随机生成一个 32 字节的hex字符串当假userID，然后用跟Claude Code 完全一样的算法，hash一下，过Mulberry32，roll一下，算出来这个ID对应什么宠物。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   循环5000万次，总能撞上你想要的那只传说闪光卡皮巴拉。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   找到以后，把这个userID塞进 ~/.claude.json，重新打开Claude Code，输入/buddy。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   白板仙人掌变传说闪光卡皮巴拉。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   太牛逼了，我佩服的五体投地。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   如果你没用官方登录的方式，用的是三方API的方式，也可以这么玩，原理差不多。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这个卡皮巴拉，会在你写代码的时候，跟你互动。
  </span>
 </span>
</p>

 <span>

   太好玩了。

   他们是真的在用做游戏的心态做开发者工具。
