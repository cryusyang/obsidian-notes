<section style="margin-bottom: 24px;">
 <span style="font-size: 16px;">
  <span>
   下面我分享三种挖掘SQL注入的方法：
  </span>
 </span>
</section>
<section style="margin-bottom: 24px;">
 <span style="font-size: 18px;">
  <span>
   0x01 Header 里的“隐身”注入：别只盯着 Body
  </span>
 </span>
</section>
<section style="margin-bottom: 24px;">
 <span style="font-size: 16px;">
  <span>
   很多人抓到包，改改参数没反应就放了。我第一件事就是去搓 Header。
  </span>
 </span>
</section>
<section style="margin-bottom: 24px;">
 <span style="font-size: 16px;">
  <span>
   尤其是
  </span>
 </span>
 <span style="font-weight: bold; font-size: 16px;">
  <span>
   X-Forwarded-For
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   、
  </span>
 </span>
 <span style="font-weight: bold; font-size: 16px;">
  <span>
   X-Real-IP
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   这些取 IP 的头。很多开发觉得 IP 是系统传的，肯定安全，拿来就直接往日志表里塞，或者进风控、黑白名单里做 SQL 查询。
  </span>
 </span>
</section>
<section style="margin-bottom: 24px;">
 <span style="font-weight: bold; font-size: 16px;">
  <span>
   我的操作：
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   永远用
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   '
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   和
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   ''
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   成对去试。
  </span>
 </span>
</section>
<section style="margin-top: 0px; margin-bottom: 0px; margin-left: 72px;">
 <span>
  <br />
 </span>
</section>
<section style="margin-bottom: 24px;">
 <span style="font-size: 18px;">
  <span>
   0x02 路径里的
  </span>
 </span>
 <span style="font-size: 18px;">
  <span>
   注入
  </span>
 </span>
</section>
<section style="margin-bottom: 24px;">
 <span style="font-size: 16px;">
  <span>
   大家都习惯在 URL 最后的参数位 Fuzz。但我习惯在目录中间横插一杠子。
  </span>
 </span>
</section>
<section style="margin-bottom: 24px;">
 <span style="font-size: 16px;">
  <span>
   比如有个路径是
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   /a/b/c
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   。 我会试：
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   /a/'
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   对比
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   /a/''
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   ；然后再试
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   /a/b/'
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   对比
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   /a/b/''
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   。
  </span>
 </span>
</section>
<section style="margin-bottom: 24px;">
 <span style="font-weight: bold; font-size: 16px;">
  <span>
   为啥要这么干？
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   现在的后端路由五花八门。有些中间件会把 URL 里的某一段路径直接抠出来，拼进 SQL 去查权限或者查资源。
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   <br />
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   <br />
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   SRC案例：
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   <br />
  </span>
 </span>
 <span style="font-size: 16px;">
  <section style="display: inline-block; text-indent: 0px;">
   <img src="https://mmbiz.qpic.cn/mmbiz_png/7xtecWUgCRwt1b8HR7x2NvHia2y43RGuvm1FCibtS72hOG8RMrsxAr2d6DS5JRMjkziaCDTup6Chdthozes0GKqGIX3vLogGhf2R6RtPpHFvAQ/640?from=appmsg&amp;watermark=1&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=1" style="width: 678.765625px !important; height: auto !important; background-color: transparent;" />
  </section>
 </span>
 <span style="font-size: 16px;">
  <span>
   <br />
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   <br />
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   还有就是在目录中添加单引号可能会引发系统报错，若是泄露系统路径，国外src也会给个俩百刀左右。
  </span>
 </span>
</section>
<section style="margin-bottom: 24px;">
 <span style="font-size: 18px;">
  <span>
   0x03 隐藏参数：把 A 接口的参数“喂”给 B 接口
  </span>
 </span>
</section>
<section style="margin-bottom: 24px;">
 <span style="font-size: 16px;">
  <span>
   这是我最核心的一招：
  </span>
 </span>
 <span style="font-weight: bold; font-size: 16px;">
  <span>
   跨接口的参数。
  </span>
 </span>
</section>
<section style="margin-bottom: 24px;">
 <span style="font-size: 16px;">
  <span>
   假如我抓到一个正常接口是
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   /api/v1/user?limit=1&amp;xxxid=100
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   。 这时候我会从 JS 资产里
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   提取所有接口
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   ，比如
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   /api/internal/config
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   。
  </span>
 </span>
</section>
<section style="margin-bottom: 24px;">
 <span style="font-weight: bold; font-size: 16px;">
  <span>
   重点来了：
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   我会把
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   ?limit=1&amp;xxxid=100
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   这一整串参数，强行拼到那个接口后面。 然后再去试：
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   limit='&amp;xxxid='
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   和
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   limit=''&amp;xxxid=''
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   ，看返回包有没有差别。
  </span>
 </span>
</section>
<section style="margin-bottom: 24px;">
 <span style="font-weight: bold; font-size: 16px;">
  <span>
   实战逻辑：
  </span>
 </span>
 <span style="font-size: 16px;">
  <span>
   很多后端函数是公用的。虽然前端代码里没传这些参数，但后端其实一直在“等”这些参数。这些隐藏参数因为没人调，开发往往忘了加过滤，直接裸奔进数据库。
  </span>
 </span>
</section>
<section style="margin-bottom: 24px;">
 <span style="font-size: 24px;">
  <span>
   总结
  </span>
 </span>
 <span style="font-size: 14px;">
  <span>
   <br />
  </span>
 </span>
 <span style="font-size: 14px;">
  <span style="font-size: 16px;">
   现在常规的sql注入几乎很难有了，还得是需要一些新的思路。我分享的这些思路大家可以让ai写burp插件。
