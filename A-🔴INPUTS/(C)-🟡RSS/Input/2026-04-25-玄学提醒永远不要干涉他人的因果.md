 <span>
  <span style="font-size: 16px;">
   人这辈子经历的所有背叛、破产、被坑、被吸血，根本原因都在于：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你妄图去拯救一个原本就该下地狱的人。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这个世界，哪有什么天降横祸，也没有无辜的受害者。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   一切的灾难，全是他妈的自作自受。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   说几个典型的例子。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你看到某个朋友身陷囹圄，债务缠身，你看了感到特别心疼，感叹天道不公，怎么专挑苦命人折磨。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   于是你圣母心大发，对他是各种帮助、借钱给他填补那个窟窿。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   结果，人家不仅没把你当恩人，反而觉得你给的不够多；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   等你后来落难想求他帮把手时，他跑得比狗都快，甚至还要反咬一口，到处败坏你的名声。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   著名歌手丛飞，11年资助了183个贫困孩子，结果全成了白眼狼。
  </span>
 </span>
</section>
<section style="text-align: center; margin-left: 8px; margin-right: 8px;">

  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   “明明说好的要资助的，怎么资助了一半就中断了，这不是坑人吗？
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   ”
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   ......
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   还有伴侣的例子。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你谈了个满身原生家庭创伤、一事无成的伴侣。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你看对方楚楚可怜，一副被世界抛弃的模样，你觉得你的到来，就是那束照进他生命里的光。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   于是，你非常自我感动无底线包容、退让、砸钱、给资源，试让他感受到世间的大爱。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但绝大多数的结局都是，你被榨干了最后一滴血，被折磨的抑郁焦虑，而对方在你的精心栽培下，的确变好了，但由于你的犯贱行为，他不会想着报恩，而是拍拍屁股走人，寻找下一个宿主。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   很多人老实了大半辈子的人，想破头也想不明白，为什么自己明明把心都给掏出来了，为什么受伤的还是我？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   流半仙想说，这些都是你的一厢情愿、自我感动罢了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   你以为自己是在普度众生，但实际上，你这是在对抗天道。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   大众教育非常习喜欢给人灌输一种毒瘤思想——“同情弱者，帮扶可怜人”。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   流半仙告诉你，这根本就是
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   弱者为了剥削强者而发明的道德牌坊
  </span>
  <span style="font-size: 16px;">
   罢了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   这些人之所以是弱者，之所以被称之为“可怜人”，很多时候并不是命运不公，更多的是他们自身的认知系统和人格基因，布满了毒瘤。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这些人因为吃亏、上当而身陷囹圄，你可千万别觉得是因为他们“太善良”、“太单纯”。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这根本就是扯蛋。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你扒开他们的表面你机会发现，里面全都是留着脓水的
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   贪婪
  </span>
  <span style="font-size: 16px;">
   。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   就比如，如果不是为了那点根本不属于自己的高息回报，如果不是妄图走捷径一夜暴富，又怎么可能被骗子那种拙劣的花言巧语套牢呢？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   那叫被骗吗？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   完全就是贪婪遇上镰刀，天作之合。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   还有那些欠了一屁股债、天天被催收逼得要跳楼的人。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   除了极个别是因为绝症这种不可抗力，剩下的哪一个不是因为自己的虚荣心、赌徒心态作祟，非要扛着超出自己认知范围的盘子去瞎折腾？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们的破产，在事发前，几乎是可预见的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   老天爷只是在收回超出他们认知范围的金钱罢了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以他们要为自己过去的傲慢、无知和懒惰买单。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   而你，一个半吊子的“好人”，居然妄图用自己那点微博的力量，去替他们逆天改命。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我看你是泥菩萨过江，自身难保。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你这根本就是以救世主自居，去阻挡宇宙规律对他们的惩罚。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你不被
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   反噬
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   ，谁被反噬？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你挡了天道的鞭子，那鞭子自然就得抽在你的脸上。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 20px; font-weight: bold;">
   01
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   世间万事万物，皆有定数，有因必有果
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   一个人当下的处境，就是他过去十年认知、性格、选择的几何倍数叠加。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你只看到了一个老人凄惨的处境、一个落魄的残局，你却没有看到这个人年轻时是如何游手好闲、如何暴躁易怒、如何刻薄恶毒地对待身边所有人。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   每一个看似无辜的弱者，在他隐秘的私人生活里，必定是一个极其固执、狭隘、而且充满戾气的鬣狗。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你别看有些老东西现在那么可怜，那都是岁月对他们的恶劣秉性的
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   清算
  </span>
  <span style="font-size: 16px;">
   。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以，流半仙希望你能够看到「
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   因果链条
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   」
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   ，而不是「
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   当下的现状
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   」
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   当你具备了这种视角看待世界万物，你就会变得极其包容。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你会允许一切发生，你完全理解他们的一切惨状，但你绝不会插手半分。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 20px; font-weight: bold;">
   02
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   绝不干涉他人的因果，是成年人最高级的自保
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   别总想拯救身边的人，比如父母、朋友、亲戚、同学，每个人都有自己的人人生课题，都有自己的路要走。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你要做的，就是静静地看着，闭上你的嘴，把手插进口袋里。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为有的人，必须要亲自撞一撞南墙，撞得头破血流，只有这种痛苦才能把他们叫醒。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   如果他们没有被骗得倾家荡产，没有被恶人踩在地上反复摩擦，他们的无知将永远存在。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你要是心软，你帮他垫了钱，你帮他挡了灾，那你非但不是在救他，反而是在害他，同时也害了你自己。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为你这是剥夺了他“吃一堑长一智”的权利。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你让他错失了人生中非常宝贵的一次因痛觉醒的机会。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   再说了，能让自己陷入如此困境的人，大多也都是烂泥，而烂泥是扶不上墙的，他们只会把你一起拖进深渊。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以说，在面对一个正在遭受果报的人，你的任何干预，都会遭到反噬。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   别人的果报是他的旧债，你若是硬要替他免债，就是你欠了 “干预因果” 的新债，那你便要自己还。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   电影《大只佬》讲述的就是这么个故事，感兴趣的可以去看看。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <br />
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   不要再去抱怨遇到了烂人烂事，一切的遇见，都是你自身能量场的同频共振。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你是一块腐肉，才会招来苍蝇；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你是一把锋利的钢刀，招来的只会是磨刀石。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   把向外投射的廉价同情，全部收回来，都在放在自身的成长上。去
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   升级你的手段、
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   去
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   磨砺你的心智，去见识人性的幽暗面。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   最后，流半仙送你一句话：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   冷眼旁观，不渡他人，保全自身，方为大乘。
  </span>
 </span>
</section>
