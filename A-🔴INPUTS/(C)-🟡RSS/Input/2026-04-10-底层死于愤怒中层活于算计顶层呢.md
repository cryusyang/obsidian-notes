  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   完全不同的结果、截然不同的人生。

 </span>
</section>

  <span style="font-size: 16px; color: rgb(171, 25, 66); font-weight: bold;">
   01
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; color: rgb(171, 25, 66); font-weight: bold;">
   底层段位表现：用对抗来获取存在感
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这种人一般处于社会的最底层，戾气很重，而且非常喜欢抬杠。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我在《
  </span>
  <a class="normal_text_link mp_article_text_link" href="https://mp.weixin.qq.com/s?__biz=MzA3Mjk5ODcwOQ==&amp;mid=2247492800&amp;idx=1&amp;sn=fbe98fa0861f9ea2cfafd20744db562e&amp;scene=21#wechat_redirect" target="_blank">
   <span style="font-size: 16px;">
    玄学提醒：拉黑别人的速度一定要够快
   </span>
  </a>
  <span style="font-size: 16px;">
   》里提到的，就是这类人。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   究其根源，是由于他们一无所有，于是只能靠“情绪的爆发”来模拟一种虚假的强大。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   当一个人没有金钱、没有权力、没有社会地位作为筹码和底气时，他的自尊心就会脆弱得一碰就碎。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   别人随意的一个眼神、一句无心的话，在他看来那都是要人命的挑衅。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   于是呢，他必须像一头被踩了尾巴的野兽一样弹起来反咬一口。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这叫勇敢或者勇于反抗吗？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   并不是，这不过是生物学上的膝跳反射罢了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   流半仙常说：做人脸皮要厚，心要黑。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   而底层人恰恰相反，他们脸皮极薄，心肠极脆。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这种高频次、低价值的对抗，本质上是认知维度的贫困。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为你手里没有能够一击必杀的资源，没有能够绕开障碍的门路，你除了用肉身去撞南墙，用唾沫星子去淹死对手，你似乎别无他法。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   于是，底层人把这种原始的兽性叫做“血性”。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但在资本和泉力的眼里，这恰恰说明你很好被操纵。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们知道如何挑起你的情绪波动，让你为某件事生气，为某件事争回面子，比如他们非常擅长的操纵舆论方向等。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你看似是自己的言行，但你的一举一动都是受他们操控的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; color: rgb(171, 25, 66); font-weight: bold;">
   02
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; color: rgb(171, 25, 66); font-weight: bold;">
   中层段位表现：用克制进行资产保全
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   当你从底层里爬上来，手里开始有了一点筹码，比如一份不错的薪水、一个还算体面的头衔、一点积蓄、一个家庭，你的思维认知就会发生巨大的升级。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这时候，你面对冲突的本能不再是“干他”，而是“算账”。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   为什么那些穿西装打领带的中产阶级看起来总是温文尔雅、甚至有些懦弱呢？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   是因为他们怂、没种吗？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   并不是，是因为他们懂得了
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   沉没成本
  </span>
  <span style="font-size: 16px;">
   和
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   机会成本
  </span>
  <span style="font-size: 16px;">
   。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   一个流氓可以光脚不怕穿鞋的，为了两百块钱跟你拼命；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但如果你手里真有一两百万，你还会下车去跟一个流氓互殴吗？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   处于中层段位的人，还是算得清楚这笔账的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   当他们怒火冲冠、想要与人发生冲突的时候会想：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这烂人值得我搭上时间吗？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   跟他翻脸会影响我明天的晋升吗？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这一巴掌打下去，我的现金流会断了吗？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   算清楚了，他们就会把牙咬碎了咽进肚子里。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这并不是退让，这叫战略性蛰伏；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这表面的温和，是极度的理性在压制沸腾的兽性。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们明白，在这个世界上，面子是不值钱的，能够自己兜底的，永远只有攥在手里实打实的真金白银、利益。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但即便如此，克制依然是一种防御姿态。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你虽然避开了暗箭，但你依然在别人的棋盘上疲于奔命。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这就引出了下一个段位：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; color: rgb(171, 25, 66); font-weight: bold;">
   03
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; color: rgb(171, 25, 66); font-weight: bold;">
   顶层段位表现：用不对抗完成操盘
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这是真正的化境，是那些站在金字塔尖、拨弄风云的极少数人掌握的能力。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们处理冲突的方式，用四个字概括就是：
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   兵不血刃。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   最高维度的认知，是跳出三界外，不在五行中。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   也就是说，他们已经处于“规矩层”的认知。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   当你还在为了一把牌局的输赢而跟人拔刀相向时，这些顶级高手会做什么？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   他会微笑着给你倒茶，然后悄悄把赌场的规矩改了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   高层次的人，绝对不会跟你发生正面摩擦。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为在他们的字典里，直接对抗是最愚蠢的能量损耗。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们是怎么玩的？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   ① 结构性绞杀
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   假如，我是你的老板，你不听话是吧？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   没问题，我不会骂你，也不会开除你落人口实。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我会把你调到一个看似清闲但毫无核心资源的边缘岗位，让你的锐气在漫长的无聊中被岁月生生耗死。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你的斗志和雄心壮志会被我缓慢地阉割，等你回过头来，你已经变成了一条没有反抗能力且任人支配的软体动物。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   ② 借刀杀人
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我不需要亲自动手，只需要稍微调整一下利益的分配机制，把你的利益和另一个狠角色的利益绑定成对立面，然后坐在高台上看你们狗咬狗。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   最后呢，我装模作样地下来收拾残局，你们俩啊，还得对我感恩戴德。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   ③ 降维洗脑
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你带着满腔怒火来兴师问罪，我根本不接你的情绪，而是直接
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   拔高维度
  </span>
  <span style="font-size: 16px;">
   。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我会跟你谈行业大局、谈底层逻辑、谈历史进程，三言两语就把你那点委屈消解得连渣都不剩，让你觉得自己刚才的愤怒根本就是格局太小。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   大家看明白了吗？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   处于规则层的人，他们不需要发火，不需要争辩，不需要面红耳赤。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们就像水一样，看似柔软退让，却能在无形中渗透进每一个缝隙，最终把坚硬的岩石冻裂、粉碎。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你连他出招的残影都没看到，你的生存空间就已经被彻底剥夺了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这种人，看起来毫无棱角，对谁都和和气气，但手里握着的，全是看不见的“牛刀
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   ”，
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   杀你这种小鸡，简直是一刀一个。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <br />
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这个世界从来不奖励只会愤怒、只会起冲突的莽夫，那些能够笑到最后的人，永远是那些洞悉人心、掌握规则运作的狠角色。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   底层人死于愤怒，中层人活于算计，顶层人制定规则。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你要是处在别人设定的规则里打架，无论你把自己的等级练得有多高，你都是毫无还手之力的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   举个例子。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但等你苦哈哈地练到100级，人家规则一改：谁等级高，谁直接输掉游戏。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你又能怎样呢？
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以你该做的，是跳出别人设定的规则框架，尽量在“自己说了算”的地方搞事情。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   就比如说，你做自媒体账户如果选择某音、某红薯，无论你在上面做了多少内容、收获了多少粉丝，或者你有一点引流私域、想要变现的苗头，它说给你限流就给你限流、说封号就封号。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你是一点办法都没有的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   相比之下，微信公众号就自由得多，你随便在这里营销、宣传自己的付费产品和服务，只要不违法都是没有问题的。
  </span>
 </span>
</section>
