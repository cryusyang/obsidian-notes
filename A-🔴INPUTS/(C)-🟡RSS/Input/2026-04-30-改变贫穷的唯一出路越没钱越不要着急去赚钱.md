<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   1、改变贫穷的唯一出路：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   越没钱，越不要着急去赚钱；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   越没钱，越不要大方；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   越没钱，越要拒绝无效社交。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   很多时候，我们之所以穷，总是靠着惯性去做人、做事，不懂得变通和去改变自己的认知，总是习惯了在自己的认知范围之内做事，不懂得摆脱固有的思维模式，跳出原有的圈子，做一些上层的社交。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   或许，只有知道价值交换，才能换来更多价值，也是因为不懂得一些规则，才让自己赚不到钱。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   2、
  </span>
 </span>
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   永远不要去顾及所有人的关系，
  </span>
  <span style="font-size: 16px;">
   因为关系都是假象，利益才是真相。想办法让别人占你的便宜，这才是赚钱最大的套路。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   3、
  </span>
 </span>
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   人们容易看到这个世界上不对的东西，而忽视更多的对的东西。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   鞋里有个沙子的时候，你容易感受到那个沙子，但你感受不到这个整个鞋是很稳定，能支撑你很舒服的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   人类就是对负面信息会比较过度反应，所以，正确的做法是把沙子清理掉，而不是把鞋子丢掉。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   4、商人才是真正的慈善家。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   传统意义上的“慈善家”，大部分都靠不住。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他们可以偶尔会为你奉献一些好东西，但不可能长期坚持，因为那是违反人性的。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   这个世界上唯一愿意长期坚持为你提供好东西的，
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   只有一种人，那就是：商人。
  </span>
 </span>
</section>
<section>
 <section style="margin-left: 8px; margin-right: 8px;">
  <span>
   <span style="font-size: 16px;">
    商人唯一的缺点是：他们是收费的。
   </span>
  </span>
 </section>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   5、永远不要觉得尴尬和丢脸。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你要明白，人只要活着就会不断地犯错、出丑、搞砸。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以没必要每件事情都过度自我反思，放轻松一点儿，别让那些小事儿成为束缚你快乐的枷锁。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   6、很多人的一生都是这样度过的：
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   年幼时不天真；年轻时不勇敢；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   中年时没有钱；老年时没有智慧
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   ；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   婚姻里没有爱情；社会中没有尊严。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   在浑浑噩噩中，耗尽了白开水般的一生。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   7、穷人，一直都会看似很充实，其实很空虚，而且还特别的不踏实。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为，在无尽的糟心事接连发生之后，他们唯一获得快乐的源泉就是买买买了。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   8、动上层的利益如同夺他们的生命，改底层的观念如同掘他们的祖坟。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   底层人固有的观念，恰恰是上层利益的来源。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   试图说透这一切的人，是双方共同的敌人。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   9、有意义的吃苦是指自控、自制和深度思考。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   穷根本不是吃苦，穷就是穷。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   多数人因穷而苦，只是为自己的愚昧、狭隘、盲从承受的代价而已。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   10、所谓的法律、规矩、道德，只有在互相平等的基础上才能说的通。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你手里有枪，我手里也有枪，咱们讲法律；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你手里有刀，我手里也有刀，咱们讲规矩；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   你空手，我也空手，那咱们讲道理。
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但如果你有枪，而我手里是刀，那么真理就在你的手上；
  </span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   如果你有枪，我空手，那么你手里拿着的就是我的命。
  </span>
 </span>
</section>
