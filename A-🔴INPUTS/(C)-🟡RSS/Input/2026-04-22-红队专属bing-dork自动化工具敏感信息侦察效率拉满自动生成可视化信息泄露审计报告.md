> [!example] AI 摘要
> LeakDetector 是一款面向红队和安全研究员的自动化信息泄露侦察工具，基于 Bing 高级语法（Dork）与 Playwright 浏览器自动化技术，具备智能反爬、动态渲染抓取和验证码绕过能力。它支持多维度侦察策略（如 API 泄露、敏感文件、后台系统等），可自动识别并提取 Excel、PDF 等文档中的身份证、手机号、API 密钥等高危敏感信息，并按风险评分生成可视化审计报告。工具提供图形化界面，支持根域名批量扫描、模式定制（EDU/Gov、Enterprise、All）、浏览器手动验证绕过及关键词自定义管理，扫描结果含汇总详情页、风险统计与原始文件归档。
