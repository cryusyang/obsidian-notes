    <span>
     1. 余轶南：当AI有了身体
    </span>
   </span>
  </strong>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   下午场第一个环节，是我和Vbot维他动力创始人兼CEO余轶南博士的对谈。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他带着大头一起上的台。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   大头是维他动力的四足机器人，也是他们的吉祥物兼产品，我个人非常非常喜欢。
  </span>
 </span>
</p>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <span>
 </span>
</section>
<section style="margin-left: 8px; margin-right: 8px;">
 <img src="https://mmbiz.qpic.cn/mmbiz_png/2jjfQoZLoqWB888ju4FgrHxjSiaO1QCZAr0icJOtHc8kicyuHjQPdEakwJHa19YXibpqTJLf3VcezF98Xxgicqic7xbt89luiaxl7ibibE5AwtUkhkuI/640?wx_fmt=png&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=0" style="height: auto !important; width: 664px !important;" />
</section>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   余轶南做过十年自动驾驶，现在又出来创业做机器人。在他看来，自动驾驶本质上就是一个两自由度的机器人，从自动驾驶到具身智能是技术的自然跃升。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   聊到具身智能，说这个赛道看着热闹，但他认为其实并不卷。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   因为具身智能不是一个行业的产品，它可以渗透到千行百业。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   自动驾驶只对应汽车一个行业，而机器人面对的场景数量远大于此，所以看起来公司多，实际上并没有那么多真正的竞争。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   我最好奇的是家庭机器人这个方向。现在具身智能赛道里几乎所有人都在做工业，很少有人真正进入家庭。但我自己有一个特别强烈的痛点，我特别讨厌在家收拾衣服。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   余轶南说了一个区分，机器人真正的价值不是替你完成某一个动作，而是把整个服务链路跑通。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   拿洗衣服来说，不仅仅是洗衣服本身，应该是一整套流程，今天任何一个家电都完成不了，而这才是机器人真正该做的事，全流程的服务。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   更宏大的一个愿景是机器人能够对人去提供端到端的服务。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但要做到这一步，鸿沟还很大，他说了两个关键瓶颈。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   第一个是数据。第二个是硬件。不过他也说，进展会比预想的要快得多。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   整场对话里最让我兴奋的部分，是他聊到大头接入OpenClaw之后的变化。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   他说那个东西部署上去以后，第一感受就是机器人活了。它能帮你做事，能拆解长程任务，甚至会自己上网找代码部署到端侧把链路打通。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   它的意义在于有点像机器人的安卓，是操作系统，变成了一个入口级的东西。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   关于家庭机器人元年的说法，余轶南说今年确实有不少公司开始认真开始做家用机器人，但落地还需要两到三年。如果只做一个形态，他更倾向于双足人形，但相信
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   未来，机器人会有各种不同的构型，百花齐放。
  </span>
 </span>
</p>

<p style="margin-left: 8px; margin-right: 8px;">

 </span>
</p>
<section style="text-indent: 0px; margin-left: 8px; margin-right: 8px;">
 <span>
 </span>
</section>
<p style="text-indent: 0px; margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   蓝队有KK不设限，拿过戛纳、首尔等多个AI电影节大奖；STEAMCHI蒸汽姬，瓦卡奖2025金奖得主；上分吧pt，提示词大师，连AJ和小声比比的出场视频都是他抽的；岳天师，各大平台的超级创作者；泰Q，还是大学生，但已经是很多学校的AIGC导师。
  </span>
 </span>
</p>
<p style="text-indent: 0px; margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   规则很简单。三轮比赛，每轮现场抽题，10分钟限时创作AI视频，每队选出一条参赛作品，现场观众扫码投票，三局两胜。

 </span>
</p>
<section style="text-indent: 0px; margin-left: 8px; margin-right: 8px;">

<p style="text-indent: 0px; margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
</p>
<p style="text-indent: 0px; margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   第一轮是emoji赛，哈基咪加键盘加爆炸。两队都做了猫猫主题的短片，蓝队的猫猫谈恋爱放烟花拿下了第一轮。
  </span>
 </span>
</p>
<p style="text-indent: 0px; margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   第二轮是文字题，亦庄+机器人+相亲。红队的机器人相亲角脑洞很大，什么2000亿token、三套朝南快充房，台词全是AI时代的相亲黑话。红队拿下第二轮，扳回一城，1比1。
  </span>
 </span>
</p>
<p style="text-indent: 0px; margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   决胜轮的题目是牛加啤酒，中间还有个轮空选项。两队都不约而同做成了广告片风格。最终红队拿下第三轮，2比1夺冠。
  </span>
 </span>
</p>
<p style="text-indent: 0px; margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   颁奖的时候森海说，希望大家多去亲自动手做AI视频，你会有一个非常及时的正反馈，然后从中找到自己想要做的内容。
  </span>
 </span>
</p>
<p style="text-indent: 0px; margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   最主要的是先走出第一步，走出去之后，后面你自己就转起来了。
  </span>
 </span>
</p>

<p style="margin-bottom: 16px; text-align: left; margin-left: 8px; margin-right: 8px;">
 <span style="font-size: 20px;">

   <span style="font-size: 20px; letter-spacing: 0.578px; text-decoration: none; background-color: rgb(0, 0, 0); color: rgb(255, 255, 255);">
    <span>
     3. 神思远、华开天、鲁照华：真人演员越来越不可替代
    </span>
   </span>
  </strong>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   AI导演神思远主持，制片人华开天、演员鲁照华三个人刚好凑成一个小剧组的铁三角，聊了AI时代影视行业最真实的体感。
  </span>
 </span>
</p>
<section>
 <span>
 </span>
</section>
<section style="text-align: center; margin-left: 8px; margin-right: 8px;">
 <img src="https://mmbiz.qpic.cn/mmbiz_jpg/2jjfQoZLoqUQwYppoEUXS6BlGD4wcsPNuibj1YsBibq7owjgMf8lsDvbzPPstP1YrJ5CYneHg8L68swCJibGAJiaeq7auuG2OlSY2eeJjyvmwkw/640?wx_fmt=jpeg&amp;from=appmsg&amp;tp=webp&amp;wxfrom=5&amp;wx_lazy=1#imgIndex=3" style="height: auto !important; width: 664px !important;" />

<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   关于真人演员是否会被替代。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   鲁照华说要拥抱未来，认为执行力很重要，AI对于她来说意味着更多的可能性。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   神思远的态度变化更有意思。
  </span>
  <span style="font-size: 16px; font-weight: bold;">
   他以前觉得什么都能替代，现在每天在做AI剧之后，反而越来越觉得真人不可替代。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   因为人很难用语言去形容一些很微妙的东西，让AI出脱口秀大会那样的喜剧节奏很难。
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   AI
  </span>
 </span>
 <span>
  <span style="font-size: 16px;">
   出来的样子是标准化的，达不到想要的。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   所以他现在反而希望有两到三个跟组演员，用表演迁移的方式直接演出来再去生成，比一次抽卡等两个小时、等完又不知道能抽成什么样要好得多。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   华开天从制片人的角度补了一层。他说AI仿真人本身就是在追求像真人，所以真人演员的那种真人感目前还是不可替代的。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   但剧组瘦身是必然的，大量群演包括一些现场工作人员，这些岗位可能会减少。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   真正稀缺的是横跨AI和影视两个行业、都能懂并且能打通、能建立工作流的人才。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: normal;">
   最后聊到护城河。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
   华开天说了两个词，判断力和IP。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>

<p style="margin-left: 8px; margin-right: 8px;">
 <span>

<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

 </span>

<p style="margin-left: 8px; margin-right: 8px;">
 <span>

  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>

<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">

  </span>
 </span>

<p style="margin-left: 8px; margin-right: 8px;">
 <span>

 </span>

<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">

 </span>

<p style="margin-left: 8px; margin-right: 8px;">
 <span>

  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   陶芳波说AI创业比互联网多了一层残酷，上周成立的产品形态这周可能就不成立了。周期短到令人窒息。能活下来的公司，一定找到了某个不变的东西。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   杨海波强调要每天从零到一地思考，打破沉没成本。投入了就有感情，有感情就不舍得砍，这件事特别害人。资源紧缺有时候反而是优势，团队变大了反而容易走形。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   最后三位各留了一句话。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   快刀青衣说，少想多干，出来混先出来。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   陶芳波说，大部分创业者不是为了财富自由，是因为好玩，别忘了这个。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   杨海波说，围绕客户需求打磨产品，然后拥抱变化。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px;">
   三个完全不同赛道的创业者，最后都在强调同一件事。
  </span>
 </span>
</p>
<p style="margin-left: 8px; margin-right: 8px;">
 <span>
  <span style="font-size: 16px; font-weight: bold;">
