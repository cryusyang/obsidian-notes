<section>
 <span style="font-size: 16px; letter-spacing: 0.034em;">
  最近OPC 一人公司火了。
 </span>
 <br />
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   其实回想一下我自从2022年9月份把所有的我是大股东公司注销掉以后，我早就是个一人公司了，包括我写文章，拍视频号，举办张桓私塾课，包括最近搞的章鱼哥出海游学，甚至投资，一切都是我一个人。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   为什么当时那么斩钉截铁搞一人公司呢？
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   因为我发现自己搞了那么多年，最后就像毛大庆所说的一样，我们大部分创业者开公司的结果是给国家交了税收，给房东交了房租，给员工发了工资，自己所剩无几，甚至负债。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   我2010年公司开在广州体育东路创展中心，每个月交十几万的房租，交了6年12个月，你看一年多少？将近150万，6年就1,000万，因为创展涨到二十几万，所以2016年搬到北岛创意园，也是十几万的房租，也交了6年将近1,000万，两个公司的房租加起来2,000万，那员工更不用说了，我记得我开包子铺的时候，每个月的固定成本100万，干了两年多。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   如果你各方面非常规范，税收和福利等一个不少，假设你不能取得特别大的成功，那你就是给房东、员工打工。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   因为毕竟像马云、马化腾等真正赚大钱老板是少数人，少之又少。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   普通的老板一年到头下来可能就赚了碎银几两，而且还承担极高的风险，大家看看你周围的老板这几年但凡有点上进心的是不是都负债累累了？
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   我记得在第7期张桓私塾课的时候，遇到了一个我当时还打工的时候一个客户，一个照明客户。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   她就说张老师，哎呀，我们干了十几年品牌，开了十几年工厂之后想明白了，现在我就一个人接这单，再去找工厂代工，我一个人一年赚200多万，比那么多年我和老温一起开公司，干了十几年，还过得舒服，还赚的更多，因为现在我赚的每一分钱都是利润。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   原来呢，要交房租，要发工资，还要承担这个所谓的这个债务风险等等。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   你看，其实这个叫张娟的也早早的做了一人公司，一人公司并不局限于所谓的小龙虾，所谓的互联网人士。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   我现在每天早上8点就会醒，为什么呢？
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   兴奋，激动。
  </span>
 </span>
</section>
<section>
 
 
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   我是被迫做的一人公司，但是有了小龙虾之后，我就可以极低的成本来指挥千军万马。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   有人会做软件，有人会做调研，有人会做设计，有人会写文案，有人会做运营，那么恐怖的一件事情。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   据说以后真正的老板，不是说那种执行力特别强的人。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   是谁？
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   是会定义问题，定义需求，发号施令的人，这才是未来最稀缺的OPC一人公司的特质。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   我这两年做视频写公众号，因为我就一个人，就倒逼着我找有没有更好的，更简单的，更方便的软件，让我拍完之后就会剪，就会自动剪字幕，配画面，自动配滤镜，自动的剪掉那些语气词等等。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   所以我应该2年之前就用了开拍，现在我看到很多所谓的博主刚开始知道。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   一人公司的好处是，倒逼你把所有东西都自动化，降本增效。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   我经常和一些传统老板聊，说试着把你公司人数减掉一半，看看业绩会不会掉，减一半的人业绩不掉就意味着多高的利润。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   我应该四五年之前也说过，
  </span>
  <a class="normal_text_link mp_article_text_link" href="https://mp.weixin.qq.com/s?__biz=MzI1NDkxNDg3OQ==&amp;mid=2247488349&amp;idx=1&amp;sn=464b1c79e723a486f1112a9e45c116d1&amp;scene=21#wechat_redirect" target="_blank">
   未来是平台+个人的时代，公司这种组织形式早晚会被淘汰！
  </a>
  <span style="font-size: 16px;">
   企业这种组织形式可能未来就不会存在，因为它是一种工业时代的这种组织，AI 时代就是OPC一个人带领无数个小龙虾军团作战。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   未来会专业分工越来越细，无数的agent之间相互协作。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   只要你会发现需求，定义需求，发现问题，定义问题。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   有无数的agent会帮你“解决”问题。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   无论有没有小龙虾，一人公司真的比很多企业更加的高效，因为人人都是老板，一人公司一定是大势所趋，未来都是合作的时代，而不是雇佣的时代，用token、股权、分红结算即可。
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   突然想到现在的00后不结婚算不算一人公司呢？
  </span>
 </span>
</section>
<section>
 <span>
  <span style="font-size: 16px;">
   好像也算！
  </span>
 </span>
</section>
