> [!example] AI 摘要
> Tolaria 是一款开源、AI 原生的桌面级 Markdown 知识管理工具，以“AI 时代的第二大脑”为定位，所有数据以纯文本 Markdown + YAML frontmatter 形式本地存储，并原生集成 Git 版本控制与 Model Context Protocol（MCP）协议，使 Claude Code 等 AI 工具可直接读写知识库。它区别于 Obsidian、Logseq 等竞品，强调从设计之初即面向 AI 协作，而非后期添加 AI 功能，并采用 AGPL 许可证践行本地优先、数据自主理念。作为 2026 年新一代“思维工具”（TfTs）代表，Tolaria 的核心主张是：开放、可检视、LLM 可无障碍推理的知识库才是未来 PKM 的关键基础设施。

## 中文译文

这是我的公开笔记中的一则笔记。查看权威版本：Tolaria。

Tolaria 是一款免费、开源的桌面应用，用于管理基于 Markdown 的知识库，由《Refactoring》通讯作者 Luca Rossi 开发。它定位为“AI 时代的第二大脑”，所有数据均以纯文本 Markdown 文件形式存储于本地磁盘，并附带 YAML 前置元数据（frontmatter）；内置支持双向链接与斜杠命令（slash commands）的块式编辑器；原生集成 Git，实现版本控制与跨设备同步；并提供一个模型上下文协议（Model Context Protocol, MCP）服务器，使 Claude Code 能够直接读写你的知识库（vault）。

Tolaria 进入了一个竞争激烈的领域——该领域长期由 Obsidian、Logseq、Notion 和 Roam Research 等产品主导。但 Tolaria 明确树立了自己的差异化定位：以文件为中心、从诞生第一天起即为 AI 原生（AI-native）、采用 AGPL 开源许可证，并围绕 MCP 集成这一核心叙事构建整体架构，而非将 AI 功能作为后期追加的附加特性。

为何重要？

Tolaria 属于 2026 年涌现的新一代个人知识管理（PKM）工具浪潮——这些工具自设计之初便深度面向 AI 原生场景：它们并非在封闭格式之上强行嫁接 AI 代理，而是通过 MCP 协议，赋予 AI 代理对知识库的一等访问权（first-class access），同时保持底层存储完全开放、可检查。其核心判断是：下一代“思维工具”（Tools for Thought, TfTs）必将是那些大语言模型（LLM）能够无障碍地读取、写入与推理的知识系统。

开源 AGPL 许可证 + 纯文本文件 + Git 的组合，强烈传递出“本地优先”（local-first）的价值主张——你的数据，运行于你的设备，版本历史亦由你自主掌控。
